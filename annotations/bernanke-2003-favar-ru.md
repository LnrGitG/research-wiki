# Bernanke-Boivin-Eliasz 2003 — FAVAR: Факторно-аугментированный VAR

## Суть в одном абзаце

**FAVAR (Factor-Augmented VAR)** решает проблему «проклятия размерности» в стандартном VAR: макродинамику нельзя описать 3–7 переменными, а бесконечномерная информационная база (сотни рядов) не влезает в VAR. Решение: извлечь **скрытые факторы** (метод главных компонент) из большой панели данных (100+ рядов), добавить их как дополнительные переменные в VAR — получаем **FAVAR**. Демонстрация: FAVAR с 120+ американскими рядами 1959–2001 даёт **экономически правдоподобные** импульсные отклики на шок ДКП (цены падают, выпуска падут, ставки растут — в отличие от стандартного VAR с «price puzzle»).

## Цель

Измерить эффекты денежно-кредитной политики (ДКП) без «price puzzle» и с использованием всей доступной информации (сотни макро/финансовых рядов), преодолевая ограничение стандартного VAR (мало переменных).

## Метод

1. **Большая панель**: 120+ квартальных рядов США 1959–2001 (реальная активность, цены, деньги/кредиты, ставки, акции, обменный курс, баланс платежей)
2. **Извлечение факторов**: метод главных компонент (PCA) → K скрытых факторов (K=1, 3, 5 — тест感度)
3. **FAVAR**: стандартный VAR(Y_t, F_t) где Y_t — наблюдаемые переменные политики (федеральные фонды, M1, M2, объём резервов), F_t — извлечённые факторы
4. **Идентификация**: рекурсивная (Чолески), шок в FFR — первый в порядке
4. **Сравнение**: стандартный VAR(7 переменных) vs FAVAR(7+K)

## Ключевые результаты

1. **Price puzzle исчезает**: стандартный VAR даёт рост цен после ужесточения ДКП (price puzzle); FAVAR — цены падают, как и предсказывает теория
2. **Imпульсные отклики экономически правдоподобны**: выпуск падает, безработица растёт, инфляция снижается, денежные агрегаты сокращаются — всё согласовано
2. **Факторы несут информацию**: первый фактор ≈ «реальная активность», второй ≈ «инфляция/цены», третий ≈ «финансовые условия»
3. **Робастность**: результат устойчив к K=1,3,5 факторам, к разным наборам переменных, к месячным/квартальным данным
3. **Интерпретация**: нестандартная ДКП (QE) анализируется через добавление новых переменных в FAVAR

## Почему это революция

- **Решил главную проблему VAR**: как использовать всю информацию без «проклятия размерности»
- **Стандарт де-факто** для оценки ДКП: ЦБ РФ, ФРС, ЕЦБ, БА Используют FAVAR/TVP-FAVAR для оценки шоков
- Открыл линию исследований: **TVP-FAVAR** (Primiceri 2005, Eickmeier 2011), **BFAVAR** (Baumeister 2015), **SVAR-FAVAR**, **FAVAR с нулевыми/знаковыми ограничениями** (Лысенко 2025)

## Ограничения

- Факторы — статистические конструкты, экономическая интерпретация пост-фактум
- PCA не учитывает структурную информацию (DSGE-информированные факторы — Boivin 2009)
- Линейность, постоянство параметров (решается TVP-FAVAR)
- Идентификация всё ещё нужна (Чолески / знаковые ограничения / нулевые ограничения)

## Прямое значение для РФ

- Кластер [[reviews/favar-faktornye-modeli]]: работы Зубарева 2022, Гармидер 2020 применяют FAVAR к РФ
- Зубарев 2022: **глобальные факторы объясняют до 70% динамики реальных макропоказателей РФ** — FAVAR с внешними факторами
- Гармидер 2020: FAVAR для прогнозирования российских макрорядов — превосходит BVAR/ETS
- Кластер [[reviews/dkp-transmissiya-na-rynok-zhilya]]: Передача ДКП через ипотеку/жильё — FAVAR с жилищным блоком

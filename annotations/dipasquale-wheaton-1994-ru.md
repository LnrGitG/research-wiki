# DiPasquale-Wheaton 1994 — Динамика рынка жилья: модель запас-поток

## Суть в одном абзаце

**Модель запас-поток (stock-flow)** для жилого сектора: рынок жилья делится на два связанных подрыночка — **рынок активов (asset market)**, определяющий цену жилья через пользовательскую стоимость (user cost), и **рынок нового строительства (construction market)**, определяющий темпы ввода в эксплуатацию через доходность девелопмента. Цена жилья влияет на строительство, строительство меняет запас, запас влияет на цену — замкнутая динамическая система, объясняющая долгосрочные циклы и краткосрочные колебания.

## Цель

Создать простую, но эконометрически оцениваемую модель, которая одновременно объясняет: (а) определение цены жилья через спрос/предложение на актив, (б) инвестиционное решение девелопера через доходность (Tobin's Q), (в) динамику запаса жилья.

## Метод

- **Система из 4 уравнений** (цены, ввод, запас, пользовательская стоимость)
- **Данные**: США, MSA-уровень, 1970–1987 (панель 37 MSA)
- **Оценка**: 2SLS / GMM для учёта энogenousности цены и ввода
- **Ключевые переменные**: цены жилья (FHFA), ввод жилья (starts/permits), доходы, ставки ипотеки, демография, стоимость строительства

## Ключевые результаты

1. **Пользовательская стоимость (user cost)** — главный драйвер цен: ставка ипотеки, налоговые субсидии, ожидания роста цен
2. **Строительство реагирует на цену с лагом 1–2 года**: эластичность ввода по цене ~1.5–2.0 в долгосрочном периоде
3. **Модель воспроизводит циклы 1970-х–80-х**: бум 1970-х (демография + инфляция), спад 1980-х (ставки), восстановление
4. **Предложение (supply elasticity) гетерогенно по MSA**: ограничения землепользования (Wheaton 2014 позже расширил)
4. **Пользовательская стоимость** включает: ставку ипотеки, налоги на имущество, амортизацию, минус ожидаемый рост цен — формула Poterba (1984) в динамике

## Почему это фундамент

- **Первая полная динамическая stock-flow модель** для жилья, совместимая с оценкой на панельных данных
- Основа для **Capozza et al. 2002**, **Wheaton 2014**, **Glaeser-Gyourko-Saiz 2008** (supply elasticity)
- Используется в **RBNZ, ФРС, ЕЦБ** для анализа длинных циклов и stress-testing
- Методология: **4 уравнения → VAR/ECM** (Wheaton 2014) → **DSGE** (Iacoviello 2005)

## Ограничения

- Линейная спецификация, нет кредитных ограничений (Iacoviello 2005 добавил позже)
- Ожидания роста цен — адаптивные / наивные, не рациональные
- Нет кредитных ограничений у домохозяйств (LTV, DTI)
- Предполагает идеальную подвижность между MSA

## Прямое значение для РФ

- Кластерный обзор [[reviews/rossiyskie-issledovaniya-rynka-zhilya]]: Стерник 2018 применяет логику «доходность девелопера → ввод» для локальных рынков РФ
- Модель расширяется: **user cost с ипотечными субсидиями** (программы 2020–2024) → рост цен → ввод +29%

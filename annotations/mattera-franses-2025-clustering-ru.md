# Mattera-Franses 2025 — Пространственно-временная кластеризация

## Суть в одном абзаце

Авторы предлагают **unsupervised learning approach** для автоматической кластеризации штатов США на основе временной паттерн цен на жильё + пространственная близость. Алгоритм estimates из данных число глобальных факторов и кластерно-специфичных факторов без априорных допущений. Результат: 4 главных кластера штатов, и модель с глобальными + кластерными факторами даёт более точные прогнозы роста цен, чем модель только с глобальными факторами.

## Цель

Показать, что прогнозные модели, учитывающие как глобальные (нац.) так и кластерно-специфичные (региональные) латентные факторы, превосходят модели только с глобальными факторами.

## Метод

- **Данные**: средние цены на жильё в 48 континентальных штатах США, 1975–2023 (FHFA)
- **Алгоритм кластеризации**: итеративный approach, similar к Alonso et al. (2020):
  1. Инициализация кластеров
  2. Оценка PCA для глобальных + кластерных факторов
  3. Обновление кластеров на основе temporal similarity + spatial proximity
  4. Повторение до сходимости
  5. Spatial penalty weight — data-driven
- **Модель прогнозирования**: Panel VAR с глобальными и кластерными факторами
- **Сравнение**: (1) только глобальные факторы, (2) глобальные + кластерные факторы, (3) без факторов

## Ключевые результаты

1. **4 кластера штатов**: алгоритм автоматически выделил 4 кластера, которые коррелируют с географией и экономическими паттернами
2. **Кластерные факторы улучшают прогнозы**: MSFE ↓ 15–25% по сравнению с глобальными факторами alone
3. **Temporal similarity + spatial proximity**: кластеры отражают как похожие временные паттерны, так и географическую близость
4. **Решает проблему Rapach 2009**: кластеризация из данных объясняет, почему coastal штаты «disconnect» — они в отдельных кластерах с уникальными факторами
5. **Количество кластеров автоматически**: не нужно задавать K априор (как в k-means)

## Почему это прорыв

- **Решает gap из Rapach 2009**: вместо «coastal штаты непредсказуемы» → «coastal штаты в отдельном кластере с unique factors»
- **Автоматическая кластеризация**: не нужно задавать K — алгоритм определяет из данных
- **Пространственно-временной подход**: temporal similarity + spatial proximity — два измерения для кластеризации
- **Data-driven**: global + cluster-specific factors — без априорных допущений о структуре

## Для российского применения

- Алгоритм применим к регионам РФ: кластеризовать 85 регионов по временным паттернам цен
- Ожидание: Москва/СПб/Сочи в отдельных кластерах (как coastal в US)
- Регионы с похожими паттернами (например, промышленный север) — в одном кластере
- Прямое применение: факторная модель с кластерными факторами для регионов РФ

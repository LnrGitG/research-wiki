# Mishkin 2007 — Рынок жилья и каналы трансмиссии монетарной политики

## Суть в одном абзаце

Фундаментальный обзор того, **как именно** монетарная политика влияет на экономику через жилищный сектор. Mishkin систематизирует **шесть каналов** трансмиссии: (1) пользовательская стоимость капитала, (2) ожидания роста цен, (3) предложение жилья; и три косвенных: (4) эффект богатства, (5) балансовый канал для потребления, (6) балансовый канал для спроса на жильё. Каждая ссылка подкреплена эмпирикой и цитатами — это «энциклопедия» направления.

## Цель

Чётко описать и эмпирически оценить все каналы, через которые ДКП влияет на жилищный сектор и обратно на экономику — для применения ЦБ при принятии решений.

## Метод

- **Аналитический обзор** 6 каналов, синтез эмпирической литературы
- **Данные**: цены на жильё в 20+ странах (Chart 1 — графика роста реальных цен 1995–2006), американская эмпирика (FRB/US, elasticities)
- **Эмпирические оценки**: elasticity residential investment по user cost: −0.2 до −1.0 (US); MPC из богатства ≈ 0.0375 (FRB/US)

## Шесть каналов трансмиссии

1. **User cost капитала**: ставка mortgages → cost of capital → demand for housing → construction → aggregate demand
2. **Ожидания роста цен**: ужесточение → смягчение ожиданий роста цен → рост current user cost → падение спроса
3. **Предложение**: короткие ставки → cost of financing construction → supply
4. **Эффект богатства**: рост цен на жильё → богатство домохозяйств → потребление (MPC ≈ 3.75¢/$)
5. **Балансовый канал для потребления**: цены на жильё → net worth → borrowing capacity → consumption
6. **Балансовый канал для спроса**: цены на жильё → collateral constraints → demand for housing

## Ключевые результаты

1. **Ланд vs структуры**: 270% рост реальных цен на землю vs 33% на структуры (1975–2006, Davis & Heathcote); земли 80% стоимости дома — это значит, что регуляция землепользования (zoning) — ключевой драйвер цен
2. **Elasticity строительства по user cost**: от −0.2 до −1.0 (США); в FRB/US = −0.3
3. **MPC из богатства жилья**: 0.0375 ($0.0375 на каждый $1 прироста богатства) — сопоставимо с MPC из акций
4. **Кросс-страновая картина**: графики реальных цен для 20+ стран показывают синхронные пузыри 1995–2006 и последующие коррекции (Ирландия, Испания, Япония, Новая Зеландия, Австралия)
5. **Subprime crisis 2007**: rising delinquencies → losses for security holders → wider spreads → баланс-система под угрозой

## Почему это стандартная ссылка

- **Один обзор = 6 каналов** — цитируется во всех макро-моделях с жильём
- Основа для **Iacoviello 2005** (канал 5+6 + financial accelerator), **Corsetti 2020** (канал 4+5 в еврозоне), **Drift 2024** (канал 5 через credit conditions)
- Упоминается в **кластерных обзорах**: FAVAR, ДКП→жильё, международная трансмиссия

## Ограничения

- Написан до 2008; не знает о GFC, QE, ZLB, subprime meltdown
- MPC из богатства — оценочная константа (FRB/US), не структурная
- Не моделирует гетерогенность по типам жилья / доходным квантилям
- Не рассматривает каналы через ипотечные ценные бумаги (MBS, CDO) — это финансовый сектор, а не жильё

## Прямое значение для РФ

- **Кластер [[reviews/rossiyskie-issledovaniya-rynka-zhilya]]**: эффект богатства от льготной ипотеки — цены выросли ×2 (2020–2024), MPC из богатства × богатство = вклад в потребление
- Балансовый канал: рост цен на жильё → рост залоговой базы → рост выдачи ипотеки (эффект акселератора)
- Предложение: земля vs структуры — в крупных городах РФ земля около застроенной территории лимитирована (зональность, красные линии), что объясняет быстрый рост land value

# Poterba 1984 — Налоговые субсидии владельцам жилья и пользовательская стоимость капитала

## Суть в одном абзаце

Автор выводит и эмпирически оценивает **формулу пользовательской стоимости жилья (user cost of housing capital)** — альтернативные годовые расходы на владение единицей жилья, включающие: процентные расходы по ипотеке, налоги на имущество, амортизацию, минус ожидаемый рост цен (прирост капитала) и налоговые вычеты по процентам/налогам. Показывает, что налоговые субсидии (вычет процентов и налогов на имущество) могут **сильно снижать** пользовательскую стоимость и стимулировать владение жильём вместо аренды.

## Цель

Вывести аналитическую формулу user cost для владельца-оккупанта, учесть налоговый кодекс США (вычеты по ипотечным процентам и налогам на имущество), оценить величину субсидии для разных налоговых бракетов и сравнить с арендой.

## Метод

- **Аналитический вывод**: user cost = (i + τ + δ - πᵉ) × P × (1 - τₘ) + τₚ × P
  - i = ставка по ипотеке
  - τ = налог на имущество
  - δ = амортизация/износ
  - πᵉ = ожидаемый рост цен (прирост капитала)
  - τₘ = маргинальная налоговая ставка (вычет процентов/налогов)
  - τₚ = налог на имущество (ставка)
  - P = цена жилья
- **Эмпирика**: данные CEX (Consumer Expenditure Survey) 1972–1973, IRS Statistics of Income, налоговые ставки 1980 г.
- **Сравнение**: user cost владения vs аренда (HUD Fair Market Rents) по MSA

## Ключевые результаты

1. **Налоговая субсидия огромна**: для налогоплательщика с маржинальной ставкой 50% user cost владения **на 30–50% ниже** аренды — владение выгодно даже при равных чистых расходах
2. **Субсидия регрессивна**: чем выше доход (и маржинальная ставка), тем больше выгода от владения — нарушение вертикального равенства
3. **Эластичность спроса на жильё по user cost**: около -0.5 до -1.0 (сокращение user cost на 10% → рост владения на 5–10%)
4. **После TRA 1986** (сокращение верха налоговой шкалы до 28%) субсидия резко упала — модель предсказала спадающий спрос на владение

## Ключевая формула (упрощённо)

```
User Cost = P × [(i + τ + δ - πᵉ) × (1 - τₘ) + τₚ]
```

- i = ставка ипотеки (номинальная)
- τ = налог на имущество (ставка)
- δ = амортизация (~1.5–2% в год)
- πᵉ = ожидаемый рост цен (прирост капитала)
- τₘ = маргинальная налоговая ставка (вычет)
- τₚ = налог на имущество (ставка)
- P = рыночная цена жилья

## Почему это классика

- **Стандартный расчёт user cost** во всех моделях: DiPasquale-Wheaton 1994, Iacoviello 2005, Poterba 1992, Glaeser-Gyourko 2018
- База для **оценки налоговых субсидий** (MID — mortgage interest deduction) в США и других странах
- Используется в **DiPasquale-Wheaton 1994** (user cost в уравнении цен), **Iacoviello 2005** (user cost в DSGE)
- Прямое отношение к **МИД/Семейная ипотека в РФ**: логика вычетов/субсидий та же

## Ограничения

- Ожидания роста цен πᵉ — адаптивные/проекции, не рациональные
- Нет ликвидности/риска владения vs аренды
- Предполагает доступность ипотеки (нет LTV/DTI ограничений)
- Не учитывает расходы на сделку (комиссии, нотариус) — важны для краткосрочного владения

## Прямое значение для РФ

- В РФ нет вычета по процентам (МИД), но есть **массовая/семейная льготная ипотека** — функциональный аналог субсидии user cost
- Кластер [[reviews/rossiyskie-issledovaniya-rynka-zhilya]]: Жирнов 2025 оценивает бюджетные расходы на льготную ипотеку >1.5 трлн в 2024 — аналог Poterba-субсидии
- Формула user cost с льготной ставкой (i_subsided вместо i) → снижение user cost → рост спроса и цен

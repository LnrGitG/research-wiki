# Rapach-Strauss 2009 — Прогнозируемость цен на жильё по штатам

## Суть в одном абзаце

**Прогнозируемость цен на жильё сильно различается между штатами**. Внутренние (interior) штаты хорошо предсказуемы из экономических фундаменталов — комбинации прогнозов ARDL-моделей значительно превосходят AR-бенчмарк. Прибрежные (coastal) штаты (Калифорния, Флорида) непредсказуемы — связь между ценами и экономическими переменными «разорвана» (disconnect). Это объясняет, почему факторные модели для нац. уровня работают хуже для прибрежных штатов.

## Цель

Измерить разницу в прогнозируемости реального роста цен на жильё между 20 крупнейшими штатами США и определить, какие экономические переменные предсказывают эти движения.

## Метод

- **Данные**: 20 крупнейших штатов США, квартальные данные 1995Q1–2006Q4 (период бума)
- **Предикторы**: 30+ переменных на уровне штата, региона и нац. уровня (доходы, ставки, занятость, демография, доступность)
- **Модели**: ARDL (autoregressive distributed lag) для каждого предиктора + 5 методов комбинации прогнозов
  - Simple averaging
  - Discounting (Stock & Watson 2004)
  - Weighted averaging
  - Cluster combination
  - Best subset selection
- **Метрика**: Mean Square Forecast Error (MSFE)

## Ключевые результаты

1. **Внутренние штаты предсказуемы**: для 12 из 20 штатов комбинации прогнозов значительно превосходят AR-бенчмарк (MSFE ↓ 20–40%)
2. **Прибрежные штаты непредсказуемы**: для 8 штатов (California, Florida, Hawaii и др.) комбинации прогнозов дают лишь modest или no gains — «disconnect» между ценами и фундаменталами
3. **Нет одного лучшего предиктора**: ни одна из 30+ переменных не даёт устойчивых выигрышей across all states — комбинации работают стабильнее, чем лучшие одиночные переменные
4. **Структурные breaks**: предсказательная способность отдельных предикторов меняется во времени (Stock & Watson 2003) — комбинации robust к breaks

## Практический вывод

- Для **внутренних регионов**: можно строить прогнозы из экономических фундаменталов (доходы, занятость, демография)
- Для **прибрежных регионов**: нужен подход, учитывающий нелинейность и пространственные spillovers (Mattera 2025, кластерные факторы)

## Почему это важно для вики

- Объясняет, почему факторные модели (Bork 2012, Ng 2025) для нац. уровня могут быть misleading — они усредняют по всем штатам, скрывая гетерогенность
- Мотивирует **пространственно-временную кластеризацию** Mattera 2025: кластеризуй штаты из данных, а не из географии
- Прямое отношение к РФ: прибрежные/столичные города (Москва, СПб, Сочи) — «coastal» аналог, менее предсказуемы из макропеременных

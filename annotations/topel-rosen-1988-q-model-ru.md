# Topel-Rosen 1988 — Инвестиции в жильё: модель Q и несовершенная конкуренция

## Суть в одном абзаце

Авторы адаптируют **модель Тобина Q** к жилому строительству: девелопер начинает строительство, когда **Q = рыночная цена готового жилья / предельные затраты на строительство ≥ 1**. В отличие от стандартной теории Q, рынок жилья отличается **несовершенной конкуренцией** (монополистическая конкуренция девелоперов, дифференциация продукта) и **стоимостью регулирования/земли** как «реальной опцией». Оценка на данных США 1963–1984 показывает: эластичность ввода по цене ~1.5–2.0,土地/регуляторные издержки — значительная часть предельных затрат.

## Цель

Построить и оценить модель инвестиций в жильё на основе Q-теории, с учётом: (а) несовершенной конкуренции на рынке нового жилья, (б) стоимости земли/регулирования как компонента предельных затрат, (в) динамики ввода/запаса.

## Метод

- **Модель**: Q = P / MC, где MC = предельные затраты на строительство + стоимость земли/разрешения
- **Динамика**: I_t = f(Q_t, I_{t-1}, запас) — с лагами (строительство занимает время)
- **Данные**: США, квартальные, 1963–1984; цены (Census), ввод (starts/permits), затраты строительства (Boeckh), земля (резидуально)
- **Оценка**: GMM/IV, инструменты — лаги цен/затрат, экспогенные демографические шоки

## Ключевые результаты

1. **Q = 1 как порог ввода**: когда цена превышает предельные затраты (включая землю/регуляцию), ввод расширяется
2. **Эластичность ввода по Q**: 1.5–2.0 в долгосрочном периоде — жильё более эластично, чем оборудование
3. **Земля/регуляция — существенная часть предельных затрат** (до 30–40% в крупных MSA), объясняет низкую эластичность предложения в прибрежных MSA
4. **Эффект несовершенной конкуренции**: девелоперы имеют рыночную силу → наценка цены над MC → ввод ниже социального оптимума
5. **Динамика**: ввод реагирует с лагом 2–4 квартала; запас адаптируется медленно → циклы

## Почему это классика

- **Первая применение Q-теории к жилью** (Tobin's Q для оборудования было, для жилья — нет)
- Методология **Q = P/MC** стала стандартом: Capozza et al. 2002, Glaeser-Gyourko 2008, Wheaton 2014
- Показало: **регуляция/земля — не «внешние» расходы, а часть предельных затрат девелопера** → прямое влияние на эластичность предложения
- Связал **Q, ввод, запас, цены** в единую динамическую систему

## Ограничения

- Нет кредитных ограничений у девелоперов/заёмщиков
- Q измеряется с шумом (цена земли вычисляется резидуально)
- Нет гетерогенности по типам жилья (одно семейное / многоэтажное / аренда)
- Ожидания цен — адаптивные/AR, не рациональные
- Нет эксплицитной модели земельного рынка (цена земли резидуальная)

## Прямое значение для РФ

- [[reviews/rossiyskie-issledovaniya-rynka-zhilya]]: Стерник 2018 применяет Q-девелопер → прогноз ввода жилья по регионам
- В РФ **стоимость земли/разрешения** — ключевой драйвер предельных затрат (как в США прибрежных MSA)
- Q-девелопер = (цена за м²) / (стоимость строительства + земля + разрешение + наценка) → управляет запусками
- Программы субсидий (льготная ипотека) → рост P → рост Q → запуски → запас → цены (петля)

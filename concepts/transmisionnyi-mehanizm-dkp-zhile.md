# Трансмиссионный механизм ДКП через рынок жилья

По Mishkin (2007), рынок жилья — центральный элемент монетарной трансмиссии.
Политическая ставка воздействует на жилье (и обратнно) через 6 каналов.

## Шесть каналов Mishkin (2007)

Прямые процентные эффекты:

1. **Издержки пользования жильём (user cost of capital)** —
   ставка ЦБ → стоимость ипотечного кредита → издержки владения → спрос на жильё

2. **Ожидания движения цен** —
   монетарная политика влияет на ожидания относительно будущей динамики цен на жильё

3. **Предложение жилья** —
   процентные ставки → стоимость финансирования строи́тельства → объём жилищного
   строительства

Косвенные эффекты через баланс/кредит:

4. **Эффект богатства (wealth effect)** —
   рост цен на жильё → рост чистого богатства домохозяйств → рост потребления

5. **Канал кредитного баланса (balance sheet / credit channel)** —
   рост стоимости жилья → улучшение балансов заёмщиков → снятие [[collateral-constraint-channel|кредитных ограничений]] → рост расходов

6. **Кредитный канал на спрос жилья** —
   улучшение балансов банков и заёмщиков → рост доступности ипотечного кредитования

## Ключевые выводы

- Жилищный рынок действует как **усилитель** (amplifier) монетарных шоков
- Каналы 4-6 особенно важны, когда цены на жильё растут: они усиливают рост
  потребления и инвестиций
- При падении цен — те же каналы усиливают спад (asymmetric effect)
- Структура ипотечных рынков определяет скорость передачи:
  - Рынки с фиксируемыми ставками (fixed-rate mortgages) — медленная передача
  - Рынки с плавающими ставками (ARMs, variable-rate) — быстрая передача

## Связь с другими концепциями

Канал 5 напрямую связан с [[collateral-constraint-channel|каналом кредитных ограничений]] —
моделью Iacoviello. Канал 6 связан с [[effekt-zamesheniya|эффектом замещения]] — когда
льготная ипотека обходит нормальный банковский канал.

Канал 4 (wealth effect) пересекается с [[dostupnost-zhilya|доступностью жилья]] —
рост цен повышает богатство владельцев, но ухудшает доступность для новых покупателей.

4. Обязательные фильтры

Фильтр value NOT IN (−99 999 999, −77 777 777) — обязателен всегда.

Отсекаются только официальные коды-заполнители Росстата. Всё остальное — включая нули и отрицательные значения — это данные. Состав значений в витрине:

положительные1 756 963—
нули386 909настоящие значения: ноль введённых метров за месяц, нулевая задолженность
отрицательные2 526настоящие значения: убыток, отрицательная динамика, сальдо миграции
заполнители27 217−99 999 999 = «нет информации», −77 777 777 = «скрыто» — их и только их надо исключать
NULL676отсекается тем же условием value IS NOT NULL

Заполнители — официальные коды Росстата. Если их не отсечь, средние и максимумы уезжают в минус на порядки, и график становится нечитаемым. Но фильтр value > 0 применять нельзя: он выбрасывает 389 435 строк (18% данных), которые являются настоящими значениями. Пример: у показателя okb (выдачи ипотеки) 8 565 нулей из 25 920 — это месяцы без выдач, без них ряд рвётся.

Исключение — если считаете средние или логарифмы: там нули дадут NULL в логарифме и выпадут сами, отдельный фильтр не нужен.

Где ставить фильтр: на вкладке «Фильтры» датасета, а не отдельного чарта — тогда он применится ко всем чартам сразу.

Фильтр region_level = 'region' — для карт и региональных чартов.

В витрине лежат территории разного уровня, и без фильтра они смешаются:

region91 территория1 925 311 строк — собственно регионы
federal_district8149 766 — федеральные округа
country171 003 — Россия целиком
aggregate1317 — сводная группа
city11 — Сочи

Если этого не сделать, на карту попадут федеральные округа, и раскраска поедет.

6. Подразрезы: что это и когда нужны

sub_dimension — служебное поле, которое различает наблюдения внутри одной метрики, региона и периода. Формат — пары «ключ: значение» через вертикальную черту.

валюта: RUB
market: primary | ед.: руб
currency: В рублях | indicator_name: Задолженность по кредитам | ед.: млн руб.
ряд: stock | лист: 01_01_45 | строка 4473
product: Цемент (все гидравлические) | ед.: тыс.т | строка 1
Что важно знать:
  • У 748 102 строк разрез пуст — это наблюдения без дополнительных разрезов, и это нормально.
  • Частые префиксы: валюта:, market:, currency:, product:, ед.:, ряд:, лист:, состав:.
  • В датасет его чаще не выносят, а держат фильтром — иначе поле с тысячами значений забьёт легенду.
  • При фильтрации по конкретному разрезу использовать LIKE '%market: primary%' — с процентом с двух сторон, потому что разрез может быть не первым в строке.

Когда разрез обязателен

Если метрика имеет несколько разрезов (например, кредиты по валютам RUB / FX / TOTAL), без фильтра по разрезу значения сложатся, и вы получите сумму несовместимых величин. Проверяйте так:

SELECT sub_dimension, count(*)
FROM core.v_datalens_observations
WHERE metric_code = 'ваш_код'
GROUP BY 1 ORDER BY 2 DESC;

Если строк больше одной — разрез нужно либо вынести в измерение, либо зафиксировать фильтром.

9. Подводные камни

1. Один показатель есть в нескольких релизах — значения задвоятся

Если у метрики несколько release_label (например, сборник Росстата и бюллетень ЦБ), одно и то же число придёт дважды. Без агрегации вы увидите две одинаковые линии.

Что делать: либо фильтр по конкретному release_label, либо вынести релиз в цвет, либо агрегировать value через «Среднее» или «Минимум».

Проверка:

SELECT release_label, count(*)
FROM core.v_datalens_observations
WHERE metric_code = 'tkzk' AND region_name = 'г. Москва'
  AND period_start = '2026-01-01'
GROUP BY 1;
2. Заполнители −99 999 999 ломают графики

Это официальный код Росстата «нет информации». Вместе с −77 777 777 («скрыто») таких строк 27 217. Исключайте именно их: value NOT IN (-99999999, -77777777). Не путайте с фильтром value > 0 — он выбросит ещё 389 435 настоящих нулей и отрицательных процентов.

3. Федеральные округа на карте регионов

Без region_level = 'region' на карту попадут 8 округов и Россия целиком — раскраска поедет. Это 221 921 лишняя строка.

4. Несколько разрезов складываются

Если у метрики есть sub_dimension с валютами (RUB / FX / TOTAL) и вы не фильтруете разрез, значения просуммируются. Проверяйте количество разрезов перед построением графика.

5. Месячные и годовые ряды в одном графике

У годовых month пуст, у месячных заполнен. Смешение частот даёт пилообразную линию. Фильтруйте frequency_code.

6. Единица измерения «unknown» — 307 339 строк

Это ряды, где единица не определилась автоматически. Данные в них верные, но в подписи графика единицу придётся указать вручную. Посмотреть, какие метрики затронуты:

SELECT metric_code, metric_name, count(*)
FROM core.v_datalens_observations
WHERE unit_code = 'unknown'
GROUP BY 1,2 ORDER BY 3 DESC LIMIT 20;
7. Предварительные и твёрдые оценки вперемешку

207 405 строк помечены preliminary — это текущий год, данные ещё уточнятся. Для ретроспективного анализа фильтруйте assessment_type = 'final'.

10. SQL-шпаргалка

Витрину можно читать напрямую, если удобнее готовый срез, чем датасет в DataLens.

Что вообще есть в базе:

SELECT source_code, count(*) AS rows, count(DISTINCT metric_code) AS metrics
FROM core.v_datalens_observations
WHERE value NOT IN (-99999999, -77777777)
GROUP BY 1 ORDER BY 2 DESC;

Динамика цены по одному региону:

SELECT period_start, value
FROM core.v_datalens_observations
WHERE metric_code = 'tkzk'
  AND region_name = 'г. Москва'
  AND value NOT IN (-99999999, -77777777)
ORDER BY period_start DESC
LIMIT 20;

Топ регионов по показателю за период:

SELECT region_name, avg(value) AS avg_value, count(*) AS points
FROM core.v_datalens_observations
WHERE metric_code = 'snz'
  AND region_level = 'region'
  AND year = 2025
  AND value NOT IN (-99999999, -77777777)
GROUP BY 1 ORDER BY 2 DESC LIMIT 15;

Проверка, почему на графике две одинаковые линии:

SELECT region_name, period_start, release_label, value
FROM core.v_datalens_observations
WHERE metric_code = 'ваш_код'
GROUP BY 1,2,3,4
HAVING count(*) > 1
LIMIT 10;

Какие разрезы есть у метрики:

SELECT sub_dimension, count(*)
FROM core.v_datalens_observations
WHERE metric_code = 'ваш_код'
GROUP BY 1 ORDER BY 2 DESC LIMIT 20;

Полный список метрик с покрытием:

SELECT metric_code, metric_name, unit_name,
       count(*) AS rows,
       count(DISTINCT region_code) AS regions,
       min(year) AS y0, max(year) AS y1
FROM core.v_datalens_observations
WHERE value NOT IN (-99999999, -77777777)
GROUP BY 1,2,3
ORDER BY rows DESC;

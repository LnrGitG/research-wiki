# Метрики интереса для макроэкономического анализа рынка недвижимости РФ

**Source:** Метрики интереса .pdf (local document)  
**Year:** 2026  
**Language:** Russian  

## Краткое содержание

Документ представляет обзор публичных, коммерческих и академических источников агрегированных метрик интернет‑ и медиа‑активности, полезных для построения высокочастотных прокси при макроэкономическом анализе рынка недвижимости в РФ (модели FAVAR‑MIDAS).

### Основные разделы
1. **Поисковые тренды и спрос** – Яндекс Вордстат (абсолютный приоритет №1) и Google Trends (через `pytrends`).
2. **Медиа‑активность и видеоконтент** – YouTube Data API, TGStat/Telemetr (Telegram‑экосистема).
3. **Сентимент‑анализ традиционных СМИ** – коммерческие агрегаторы (Интерфакс СКАН, Медиалогия, Интегрум) и открытый проект GDELT (via Google BigQuery).
4. **Веб‑аналитика и трафик классифайдов** – Similarweb API (для ЦИАН, Авито, Яндекс Недвижимость, Домклик).

### Сводная матрица источников

| Тип данных | Источник/Сервис | Провайдер/Инструмент | Частотность | Тип доступа |
|------------|-----------------|----------------------|-------------|-------------|
| Поисковый интерес | Яндекс Вордстат | Яндекс.API / Сторонние парсеры | Неделя / Месяц | Коммерческий / Лимитированный |
| Поисковый интерес | Google Trends | Библиотека `pytrends` | День / Неделя | Открытый (скрепинг) |

| Оперативные каналы | Telegram‑каналы | TGStat API | День / Неделя | Коммерческий API |
| Новостной сентимент | Федеральные СМИ | GDELT Project (через BigQuery) | День | Полностью бесплатный |
| Трафик на маркетплейс | ЦИАН, Авито, Яндекс Недвижимость, Домклик | Similarweb API | Неделя / Месяц | Коммерческий API (высокая стоимость) |

### Рекомендации по минимизации бюджета исследования
- **Сентимент СМИ:** использовать готовые очищенные ряды из публичного GDELT в BigQuery.
- **Поисковые тренды:** комбинировать `pytrends` (Google) с легковесным скриптом для сбора «Динамики запросов» из Яндекс Вордстат.
- **Социальные медиа:** пользоваться базовыми бесплатными лимитами YouTube API для парсинга просмотров пула ключевых каналов.

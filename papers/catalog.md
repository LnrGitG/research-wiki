# Papers Catalog

> Compact cards for extracted sources in `raw/papers/`. This is the warm layer, not the curated wiki layer.
> Do not create a full wiki page for every PDF. Add a short card here first.
> Status flow: `new` → `triaged` → `used` or `archived`. Relevance: `high` / `medium` / `low`.

## Rules

- One section per extracted markdown file: `## <file.md>`.
- Keep cards short: max 8–10 lines.
- When a source is used in a curated page, add `used_in: [[page-name]]`.
- If a PDF is irrelevant, duplicated, or an error page, mark `status: archived` and move to `_archive/` after review.
- New tags for curated pages must exist in `SCHEMA.md` before use.

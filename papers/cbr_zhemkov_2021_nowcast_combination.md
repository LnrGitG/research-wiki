# Жемков (2021) «Краткосрочная оценка ВВП России методом комбинирования прогнозов» — конспект

Источник: raw/cbr/zhemkov2021/wp-feb21.pdf (Банк России, серия докладов об экономических исследованиях, февраль 2021). Текст: wp-feb21.txt (59.6К симв).

## Суть методики (эталон для нашего FAVAR-MIDAS)

1. **Объект прогноза — компоненты ВВП по использованию** (потребление домохозяйств, потребление гос. управления, ВНОК [≈IKV], МОС, экспорт) + агрегирование, а не ВВП напрямую. Сумма компонент корректируется на статистическое расхождение.
2. **~500 моделей** комбинируются в 3 группы:
   - сценарные модели (для ДКП-сценариев)
   - смешанно-частотные (MIDAS, MF-VAR)
   - дополнительные (прочие)
3. **DFM-факторы из 85 HF-индикаторов в 3 группах**:
   - реальный сектор (39): обороты, заработные платы, СМР (№8 в их списке!), ИПП, диффузные индексы (в т.ч. закупки оборудования №26 — прямой инвестиционный сигнал), загрузка мощностей
   - финансовые (18): ставки всех видов (включая ипотечные №11), индексы акций, резервы
   - ожидания (28): ценовые ожидания по отраслям (включая **строительство №6**), PMI
4. Веса комбинирования — по вневыборочной точности; усечение худших моделей.

## Применимость к нашему pipeline

1. **Архитектурный шаблон для IKV-наукаста**: не прогнозировать IKV напрямую одной моделью, а комбинировать прогнозы компонент (в нашем случае: СМР-модель + эскроу/финансовый канал + wordstat-опросный канал) с весами по вневыборочной точности.
2. **Наша HF-база уже шире их 2021 года в жилищном блоке**: ДОМ.РФ цены/сделки, эскроу помесячно по регионам, wordstat-композит (w=0.63 lead-1m для СМР), ескроу +0.75 lag2 для IKV — этих показателей у Жемкова нет.
3. **MIDAS + DFM-факторы** вместо «одна модель — один индикатор»;udget 3 факторные группы = их же структура (реальный/финансы/ожидания).
4. Осторожно: выборка 2003-2020 — прямое копирование калибровок на 2025-2026 стресс-периоде рискованно; их же совет — веса переключать по времени (DMS эквивалент).

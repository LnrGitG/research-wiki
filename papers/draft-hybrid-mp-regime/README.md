# draft-hybrid-mp-regime — план статьи для «Деньги и кредит»

**Статус:** план/проспект статьи (draft, не для публикации).
**Дата:** 09.10.2026. **Профиль:** research.
**Целевой журнал:** «Деньги и кредит» (Russian Journal of Money and Finance, RJMF;
издатель — Банк России).
**Артефакт:** `plan.md` — развёрнутый план-проспект (замысел, структура IMRaD,
argument map, институциональный прецедент, кейс, дизайн расчётной части, гипотезы,
риски, источники).

**Замысел в одну строку:** обосновать целесообразность гибридного режима ДКП
(инфляционное таргетирование как номинальный якорь + институционализированные
селективные опции через кредитный канал) как альтернативы чистому ИТ, с селективностью
в виде льготного кредитования энергоэкспортных проектов «Росатома», прецедентом-опорой
— действующая программа льготного кредитования МСП Банка России, расчётной частью —
публичная квартальная прогнозная модель (КПМ) Департамента ДКП Банка России.

**Границы:** расчётный дизайн и литературный слой — здесь; интерпретация по ставке,
режиму и реальному курсу — домен macroeconomist (в плане помечено).

**Ограничения, зафиксированные заранее:**
- КПМ не содержит экспортного/отраслевого блока по умолчанию — селективная опция
  вводится надстройкой; это исследовательская работа, а не готовый режим модели.
- Тезис нефальсифицируем, если «конкурентоспособность» проводится через реальный
  курс, а не через кредитную цену (см. `../queries/selective-monetary-policy-growth.md`,
  разделы 2.11 и 7).
- Публикация в журнале Банка России: тон академически нейтральный, опора на
  воспроизводимый расчёт, а не на риторику.

# Учебная модель малой открытой экономики для анализа ДКП (Глазова, Неваленный, Синяков 2025)

**Банк России, доклад № 154, август 2025, 132 стр.** (рецензируемая серия).

## Аннотация

Учебная графическая модель малой открытой экономики (МОЭ) для анализа ДКП — упрощённая версия модели Basu & Gopinath (2024, МВФ), для бакалавриата. Динамика проиллюстрирована импульсными откликами формальной полуструктурной модели (КПМ). Особенности: (1) современные представления о фиатной экономике и мировом финансовом цикле; (2) таргетирование инфляции при шоках спроса/предложения и роль заякоривания ожиданий; (3) валютный рынок с несовершенствами и роль курса в трансмиссии; (4) «дилемма, не трилемма» (Rey 2015) и ограничения ДКП; (5) **закрытие финансового счёта платёжного баланса** и изменение трансмиссии — модель применима ко всей эпохе таргетирования ЦБ РФ, включая 2022–2024.

## Структура модели

**Графическая модель** (4 рынка): товарный (спрос от реальной ставки, IS), совокупное предложение (кривая Филлипса с заякоренными/незаякоренными ожиданиями), рынок денег/банковской ликвидности, валютный рынок (предложение валюты: экспорт + приток капитала; спрос: импорт + отток; равновесный курс), общее равновесие.

**Полуструктурная КПМ (раздел 5.1)** — квартальная модель с правилом Тейлора:
- IS: A_t = A_{t+1} − 0.7·(IR− нейтральная) (коэффициент δ_ir=0.7; влияние курса на спрос δ_rer=0 — курс действует через инфляцию, а не напрямую)
- MP: IR_t = 0.5·IR_{t−1} + 0.5·(IR_ss + 2.5·π_gap) (реакция Тейлора psi=2.5)
- Кривая Филлипса: β_cpid=0.5 (ожидания), β_Y=0.5 (разрыв выпуска)
- Совокупная инфляция: **CPI = 0.4·внутренняя + 0.3·импортная + 0.3·торгуемая**; эффект переноса курса β_rer=0.5
- Валютный рынок по Magiori (2020): курс = отношение валютных потоков; **ключевой параметр H — финансовые трения ∈ [0, ∞)**: H=0 → UIP (открытый счёт), H=∞ → финансовая автаркия; калибровка H=0.99
- Структурные пропорции: абсорбция/ВВП 0.9, экспорт/ВВП 0.3, импорт/ВВП 0.2; инерция импорта α=0.4, чувствительность к курсу β=0.2

## Ключевые положения

1. **«Дилемма, не трилемма» (Rey 2015)**: даже при плавающем курсе глобальный финансовый цикл переносит зарубежные условия финансирования; жёсткая связь ставок через UIP при открытом счёте сохраняется → нужны дополнительные инструменты (макропруденциальные, КМ).
2. **Заякоривание ожиданий** — центральный элемент: при заякоренных ожиданиях перенос курса в инфляцию воспринимается как временный cost-push и не требует агрессивной реакции ставки; при незаякоренных — требуется жёсткая реакция.
3. **Несовершенный валютный рынок** (закрытие финансового счёта): курс реагирует медленнее, торговые потоки определяют равновесие → трансмиссия ДКП ухудшается, бремя подстройки смещается к ставке.
4. **Эпизоды 2022–2024 разложены по модели**:
   - февраль–март 2022: заморозка резервов + уход нерезидентов с ОФЗ (вложения ~2.8 трлн руб. → обвал доли) = поворот предложения внешнего финансирования влево, курс А→B→D; шоки предложения (цены импорта) + ажиотажный спрос (IS вправо, розничный оборот) → всплеск инфляции → ставка 20%;
   - II–IV кв. 2022: режим отсутствующего притока капитала, курс определяется потоками резидентов; рост экспортной выручки → укрепление;
   - 2023–2024: восстановление импорта + падение экспорта (потолок цен, количественные ограничения) → ослабление курса → перенос в цены импорта; госрасходы сдвигают AD вправо → ужесточение ДКП.
5. Парадокс (стр. 55+): жёсткая ДКП сопровождается **меньшими** потерями ВВП, чем мягкая, при незаякоренных ожиданиях.
6. Инструменты при дилемме (Gourinchas 2018; Basu & Gopinath 2024): макропруденциальные меры, меры КМ, валютное регулирование — как дополнение к ставке.

## Релевантность для исследовательской программы (RU housing)

- **ДКП-блок**: официальная учебная модель ЦБ — база для изложения трансмиссии в обзорах; эффект переноса курса в инфляцию (вес импорта 0.3) и правило Тейлора (psi=2.5, инерция 0.5) — калибровочные ориентиры.
- **Ипотечный канал**: финансовые трения H — формализация закрытия финсчёта после 2022; связка с NBP 289 (банковский риск от цен жилья) и с оценкой ДКП-жёсткости для ипотечного рынка.
- **Дилемма не трилемма** — концептуальная рамка для анализа независимости ДКП РФ в 2022–2024 (заморозка резервов = экзогенный поворот предложения финансирования).

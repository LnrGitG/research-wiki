# Госинвестиции и субсидии по бюджетным данным РФ: как получил Тимофеева и как получить нам

## Часть 1. Как это делает Тимофеева (2026)

**Источник — форма № 0503190** «Сведения о вложениях в объекты недвижимого имущества, объектах незавершенного строительства»:
- Регламентирована **приказом Минфина России от 28.12.2010 № 191н** (Инструкция о порядке составления годовой/квартальной/месячной отчётности об исполнении бюджетов)
- Подаётся в составе **пояснительной записки (форма № 0503160) к годовой бюджетной отчётности**
- Содержит по каждому объекту капстроительства: статус, сроки (дату старта), причины приостановления, сметную стоимость, фактические кассовые расходы с начала реализации
- **Единственный публично доступный и институционально закреплённый** источник детализации по объектам среди всей бюджетной документации

**Как Тимофеева получила данные**: регионы отобраны случайно из тех субъектов, чьи финорганы разместили годовую отчётность за 2024 на своих сайтах; **70 из ~85 субъектов публикуют форму 0503190** (рейтинг открытости НИФИ: nifi.ru/ru/rating — Group A: НАО, Приморье и т.д.). Т.е. это **ручной сбор с сайтов региональных минфинов** (типовые пути: сайт минфина региона → бюджетная отчётность → пояснительная записка → форма 0503190, в основном PDF).

**Ограничения (из работы)**: только годовой лаг (годовая отчётность), не все регионы, федеральный/муниципальный уровни — в открытый доступ не выкладываются.

## Часть 2. Где взять госинвестиции по стране и регионам (наша инфраструктура)

### 2.1. Наукаст-кратко — уже есть
- **Госинвестиции в нацбогатство** (roschart-зеркало gdp_use_quarterly): ежеквартальные «валовое накопление» в составе использования ВВП (2011Q1–2026Q2).

### 2.2. Основной канал: Единый портал бюджетной системы (budget.gov.ru, «Электронный бюджет»)

⚠️ На VPS budget.gov.ru **не резолвится по HTTPS** (таймаут, проверено). Отсюда 3 рабочих обхода.

#### (a) hubofdata.ru — зеркало Минфина (работает, но antibot Anubis)
Реестр **соглашений (договоров) о предоставлении субсидий** юридическим лицам, ИП и физлицам-производителям, **бюджетных инвестиций** юрлицам, а также **субсидий/субвенций/иных межбюджетных трансфертов бюджетам субъектов РФ** (`7710568760-fedbudgetagreement_budgetgovru`).

Прямой датасет-эндпоинт: `http://budget.gov.ru/epbs/registry/grants/data` (API) + выгрузки ZIP/CSV на hubofdata.ru. **Ахиллесова пята**: зеркало last updated 23.06.2018 → исторические данные, не текущие. Пригодно для ретроспективы 2016–2018, не для 2024–2026.

#### (b) Прямой API budget.gov.ru через реальный браузер (собственным скриптом с VPN/резид. IP)
Датасеты (разделы «Расходы» → реестры; «Государственная поддержка»):

| Реестр | URL (path) | Что даёт |
|---|---|---|
| **Реестр соглашений о субсидиях, бюджетных инвестициях, межбюджетных трансфертах** | /бюджет/расходы/реестр-соглашений-договоров-о-предоставлении-субсидий-бюджетных-инвестиций-межбюджетных-трансфертов | **Самый ценный**: по каждому договору — ГРБС, тип (субсидия юрлицу / бюджетная инвестиция / МБТ субъекту), сумма, срок, назначение, регион получатель |
| **Субсидии и гранты юрлицам/ИП/физлицам** | /бюджет/государственная-поддержка/субсидии-и-гранты-юр.лицам-... | Кассовое исполнение по соглашениям |
| **Бюджетная роспись федерального бюджета** | /бюджет/расходы | Раздел/подраздел/ЦСР/ВР с суммами; ключ: раздел **10 «Социальная политика»**, **нацэкономика** (в т.ч. **11.10 «Развитие рыночной инфраструктуры» /** «Жилищные программы»), подразделы ДКП |
| **Исполнение бюджетов субъектов** | /бюджет (по ФО) | Расходы региона по единой классификации — регион-разрез бесплатно |

Правовая рамка для фильтра «субсидии на ипотеку физлицам / госпрограммная поддержка предприятия»:
- **БК РФ ст. 78** — субсидии юрлицам, ИП, физлицам-производителям
- **БК РФ ст. 78.1** — субсидии НКО/учреждениям (госзадание — обычно не наша тема)
- **БК РФ ст. 78.2** — **субсидии на капвложения** в объекты капстроительства (мост между субсидиями и незавершёнкой по Тимофеевой)

Ипотека в этой классификации сидит в кодах направлений расходов, привязанных к госпрограммам: «Обеспечение доступным и комфортным жильём» (подраздел 11.2), внутри которого отдельные ЦСР = **Семейная ипотека / IT-ипотека / Дальневосточная и арктическая ипотека / сельская ипотека, жилищные сертификаты**. Поиск по реестру соглашений по названию ЦСР сразу отделяет ипотечные субсидии от прочих.

#### (c) Минфин РФ: таблицы соответствия разделов/видов расходов (субъектов с 2024)
minfin.gov.ru — «Таблица соответствия разделов (подразделов) и видов расходов…» — справочник для корректного маппинга «регион → раздел/подраздел/ВР/ЦСР → наш интерес» (это то, что стоит распарсить первым: он даёт словарь классификации для всех ниже).

### 2.3. Как получить форму 0503190 для всех регионов (воспроизвести Тимофееву на n=70)

1. Взять рейтинг открытости НИФИ (nifi.ru/ru/rating, 2024) → получить список из ~70 субъектов с онлайн-отчётностью.
2. Для каждого — типовой поиск «0503190 {регион}» на сайте регионального минфина (формат PDF/DOCX в составе пояснительной записки к отчёту об исполнении бюджета), плюс резерв: госзакупки.gov.ru (у некоторых — вложения), госуслуги-архивы, «Бюджет для граждан» на сайтах финорганов.
3. Распарсить: статус объекта, дата старта (→ моя классификация 5/2 года), смета, кассовые расходы.
4. Собрать в панель регион × год × группа → прямой апгрейд моего `housing_backlog_ratio_annual` на госкомплекс (сейчас — весь сектор, в том числе жилой).

Пригождается: мой пайплайн для PDF (fitz + tesseract rus) уже обкатан на Росстате; структура формы стабильна (191н), так что парсер единый на 70 регионов.

### 2.4. Что это даёт для жилья и ДКП

- **Госинвестиции в жильё** через реестр соглашений (ст. 78.2 — субсидии на капвложения) → отделить бюджетные стройки от рыночных девелоперских → отдельный фактор в FAVAR (госинвестиции реагируют на ДКП иначе, чем частные).
- **Субсидии физлицам на ипотеку**: через реестр соглашений (где ГРБС — ДОМ.РФ/Минстрой) выделяются «Семейная»/«IT»/«Дальневосточная» ипотеки — годовые лимиты и касса. Плюс данные ДОМ.РФ (квартальные отчёты, объём выданных льготных кредитов) — уже есть в моём pipeline.
- **Субсидии предприятиям (стройиндустрия)**: ст. 78 через реестр — получатели-юрлица, фильтр по ОКВЭД F (стройка) + по региональным промышленным фондам развития.

## Рекомендуемый порядок действий

1. **Сейчас**: распарсить справочник классификации (minfin.gov.ru, таблица соответствия) → словарь разделов/ВР/ЦСР в sqlite (`budget_kosgu_dict`).
2. **Зеркало за 2016–2018** (hubofdata, ZIP реестра соглашений) → панель на исторический период.
3. **2024–2026**: обход budget.gov.ru с работающего браузера (или из другой сети — не VPS) → CSV реестра соглашений по годам → панель регион × год × тип (субсидия юрлицу / ФЛ / бюджетная инвестиция / МБТ).
4. **ННС**: вытащить 0503190 для ≥10-20 регионов из рейтинга НИФИ (сначала 3-5 как пилот), прогнать мою классификацию Тимофеевой, сверить с `housing_backlog_ratio_annual`.

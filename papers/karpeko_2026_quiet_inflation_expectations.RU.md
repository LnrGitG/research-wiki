# QUIET: индикатор инфляционных ожиданий домохозяйств по данным поисковых систем

**Карпеко Ф.А.** (Банк России, ДВГУ, Южно-Сахалинск) — Серия докладов об экономических исследованиях № 174, 2026, 57 стр.

## Суть

Новый индикатор **QUIET** инфляционных ожиданий домохозяйств на основе частот поисковых запросов (Яндекс Wordstat + Google Trends), ежемесячной и **еженедельной** частоты, для РФ в целом и **по регионам**.

## Методология

1. Отбор тем запросов, связанных с инфляцией («инфляция», «рост цен», «ключевая ставка», «нефть», «доллар», «юань» и др.); данные **Яндекс Вордстат** (учёт всех словоформ; дедупликация 1 запрос/IP+MAC в день)
2. Период: **январь 2018 — август 2024**; Россия + **79 регионов** (ограничено полнотой данных); Google Trends только по РФ в целом (региональные ряды неполные)
3. Контроль VPN-искажений: запросы «инфляция» из СНГ вне РФ 4.53% + из прочих стран 1.18% (янв 2018 — авг 2024)
4. **PCA** → компактный индекс ожиданий QUIET
5. Проверка связи с ИПЦ (мес к мес) по России и регионам; сравнение с инФОМ и ценовыми ожиданиями бизнеса («Мониторинг предприятий» ЦБ); контроли: безработица, потребление, USD/RUB × доля валютной задолженности региона
6. Прогноз ИПЦ расширяющимся окном (трейн янв 2018 — авг 2023), **ARDL** и **MIDAS** с еженедельным QUIET

## Результаты

- Лучший краткосрочный прогноз ИПЦ: QUIET обгонял альтернативы на горизонте **до 5 месяцев**; in-sample RMSE 0.306–0.248 vs AR(1) 0.478
- Региональные панели MIDAS, горизонт 8–12 мес: RMSE **0.416** (MIDAS+QUIET) vs 0.460 (ARDL+QUIET), 0.453 (ARDL+ожидания бизнеса), 0.443 (AR(1)) → **−6.1% ошибки** против бенчмарка
- Преимущество MIDAS подтверждено на горизонтах 1 и 3 мес при недельной высокой частоте
- Пригоден для **наукастинга**: обновляется практически в реальном времени
- Связь с ожиданиями инФОМ выше, чем с наблюдаемой инфляцией → природа именно ожиданий

## Преимущества против опросов

1. **Оперативность** — реальное время vs. месячный цикл опроса
2. **Гибкость** — региональный разрез, любая частота (мес/нед/день)
3. **«Искренность»** — поведенческие данные без искажений респондентов

## Ограничения

- Смена методики поисковиков меняет ряды (особенно Google Trends)
- Шум от нерелевантных похожих запросов
- Негативная асимметрия внимания → предлагается сверка с сентимент-индексом
- Не охвачены не-интернет пользователи

## Значение для research-wiki

Прямо релевантно трём линиям базы:

1. **Региональная инфляция и жильё**: региональные панели QUIET (приложения F–I: панели по ФО) — потенциальный контроль/инструмент для региональных моделей рынка жилья, где инфляционные ожидания влияют на спрос на недвижимость как на «защиту от инфляции» (связь с Турцией-2026: девальвация→ожидания→спрос на жильё)
2. **Данные ЦБ**: сравнивается с ценовыми ожиданиями предприятий из того же «Мониторинга предприятий», который у нас в `cbr_monitoring_construction` (12 вопросов, 2002–2026) — можно строить сопоставимый строительный sentiment-блок
3. **Метод MIDAS** с еженедельными данными — образец для оперативной оценки ввода жилья/ипотеки по высокочастотным прокси

# Агенты искусственного интеллекта и оперативное проектирование в эконометрическом кодировании

**Рабочий документ NBER № 35588, август 2026 г.**

**Авторы:** Себастьян Галиани (Университет Тулейн и NBER), Федерико Ариэль Лопес (Университет Сан-Андрес), Рауль А. Соса (Университет Сан-Андрес)

**ЖЕЛ:** C18, C87

## Аннотация

Исследование того, как LLM пишет код для эконометрического анализа. Сравниваются три измерения кодирования с помощью AI: статистическое ПО (Stata, R, Python), тип запроса (нулевой или малочастотный), и уровень агентности — от чатбота, пишущего один скрипт, до агента, который выполняет и исправляет свой код.

На эталонном рынке из 21 прикладной эконометрической задачи переход от чатбота к ограниченному агенту повысился с **74% до 96%** при дополнительных ~8 центах за запуск.

## Ключевые результаты

| Параметр | Чатбот | Одноразовый ремонт | Ограниченный агент |
|----------|--------|------------|---------------------|
| Успех задачи (нулевой выстрел) | 67,3% | 81,3% | 94,9% |
| Успех задачи (несколько кадров) | 81,6% | 85,1% | 96,5% |
| Успех задачи (общий) | **74,4%** | **83,2%** | **95,7%** |
| Исполняемость | 77,5% | 90,5% | 99,7% |
| Корректность вывода | 67,3% | 81,3% | 94,9% |

### Основные выводы

1. **Агентность > промпт-инжиниринг.** Переход от чатбота к агенту даёт +21,3 п.п. (p < 0,001), малокадровый промпт — только +6,6 п.п. (р = 0,009).

2. **Промпт-инжиниринг и агентность — субституты.** Эффект малозарядности падает с 14,3 п.п. (чатбот) до 1,6 п.п. (агент). Взаимодействие малокадровый × сдержанный агент = −12,7 п.п. (р = 0,061).

3. **Стата хуже Python и R.** В чатботе с нулевым выстрелом Стата на **33,3 п.п.** ниже Python (p = 0,005). Под агентом различия нивелируются: Python 88,7%, R 88,9%, Stata 75,7%.

4. **Стоимость.** Средняя стоимость запуска: 0,18$ (чатбот) → 0,26$ (агент). Дополнительные затраты = 0,36 доллара США за дополнительный успешный запуск.

5. **Межмодельное сравнение.** Для Claude Sonnet 4.6 и GPT-5.4 (через Кодекс) несколько попыток показывают чат-бот значительно больше, чем агент — подтверждающая гипотезу субститутов.

## Методология

- **Бенчмарк:** 21 задача по прикладной экономике (линейная регрессия, DID, RDD, IV, панельные оценки, временные ряды)
- **Дизайн:** 3 ПО × 2 промпта × 3 уровня агентности = 18 условий, 5 повторений каждого = 1890 экспериментов (Клод Сонет 4.6)
- **Оценка:** автоматический скоринг — исполнительность, корректность вывода, совпадение с эталоном в пределах допуска
- **Статистика:** кластеризация на уровне задач, p-значения дикого кластера (9999 репликаций)

## Примечание

Работа не связана напрямую с жилищным строительством, но важна для методологии: показывает, что ИИ-агенты с автономным исполнением кода значительно превосходят простую генерацию скриптов, что применимо к воспроизводимости эконометрических исследований (включая исследования рынка жилья).

## Аннотация (англ.)

Мы изучаем, как большие языковые модели пишут код для эконометрического анализа. Мы сравниваем три аспекта кодирования с помощью ИИ: статистическое программное обеспечение (Stata, R или Python), подсказки (нулевой или малократный) и степень свободы действий: от чат-бота, который пишет один сценарий, до агента, который выполняет и пересматривает свой собственный код. По сравнению с прикладными эконометрическими и статистическими задачами переход от чат-бота к агенту с ограниченными возможностями повышает успешность выполнения задач с 74 до 96 процентов, что составляет примерно восемь дополнительных центов за выполнение. В Claude Sonnet 4.6 и GPT-5.4 через Кодекс подсказки с несколькими выстрелами улучшают чат-бота гораздо больше, чем ограниченный агент, указывая на то, что подсказки и агентство выступают в качестве заменителей. Для этих моделей различия между статистическими программами значительны при использовании чат-бота, но в значительной степени исчезают при наличии ограниченного агента.

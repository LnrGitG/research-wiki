# Доступ к издательским платформам: карта каналов

**Дата проверки:** 13.10.2026. **Хост сессии:** vs7237.fra01de.vsys.cloud (Frankfurt, AS35661), ip 45.157.117.125.

Повод: владелец сообщил о корпоративном (институциональном) доступе к международным
научным базам. Проверено, как этот доступ соотносится с рабочей сессией research-профиля.

## Главный вывод

Институциональный доступ находится на устройстве/сети владельца, а сессия профиля
исполняется на VPS во Франкфурте. **Из сессии корпоративной подписки не видно.**
Проверка на World Scientific: карточка статьи показывает статус `No Access`, то есть
IP VPS не признан подписчиком. Следовательно, `web_extract`/`curl` из сессии платный
полный текст не откроют, даже когда страница технически отвечает.

## Матрица доступности (curl с браузерным User-Agent, 13.10.2026)

- ScienceDirect (Elsevier) — HTTP 403, Cloudflare-стена.
- Wiley Online Library — HTTP 403; браузер тоже не проходит интерактивную проверку.
- Taylor & Francis — HTTP 403, Cloudflare.
- Oxford Academic — HTTP 403, Cloudflare.
- World Scientific — HTTP 403 через curl; **браузер проходит** проверку и открывает
  страницы журналов и оглавления, но статьи помечены `No Access`.
- JSTOR — HTTP 200 (главная).
- Springer Link — HTTP 200.
- NBER — HTTP 200, но прямой fetch PDF медленный/нестабильный.
- IEA — HTTP 200 (открытый доступ).
- IRENA — HTTP 403.

Вывод по каналам: браузерный инструмент снимает Cloudflare там, где curl получает 403,
и пригоден для оглавлений, абстрактов и метаданных (`citation_*`), но не даёт платного
полного текста без подписки. Скачивание платных PDF на VPS через институциональную
подписку технически не обеспечено.

## Что это значит для приёмки статей (класс A/B/C)

Класс A достижим в двух режимах: (1) открытый доступ на сайте издателя; (2) владелец
скачивает PDF из своей институциональной сети и передаёт файлом — тогда класс A
подтверждается, а в поле `sources` выписок фиксируется маршрут
«институциональный доступ владельца, передано файлом, дата».

Класс B/C остаётся для случаев, когда канонический текст не открывается ни напрямую,
ни через владельца. Числовой вывод на классе C по-прежнему сверяется с каноническим.

   использования с VPS, и допустим ли такой маршрут по правилам организации.
   *Решение владельца 13.10.2026: уточняет и присылает адрес.*
2. Передаёт ли владелец PDF файлом — это рабочий маршрут «сегодня», без настройки.

## Статус

Ожидается адрес прокси/EZproxy от владельца; до его получения платные полные тексты
получаются только передачей файла. Правило по умолчанию: оглавления и метаданные —
браузерным инструментом; платный полный текст — через институциональный маршрут
владельца, класс A с указанием маршрута в `sources`.

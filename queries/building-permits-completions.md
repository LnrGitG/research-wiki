# Разрешения на строительство и ввод зданий: данные по регионам

## Важное замечание

**Росстат не публикует данные по «разрешениям на строительство» (building permits)** напрямую.
Вместо этого доступны следующие proxy-показатели:

| Показатель | Описание | Период |
|-----------|----------|--------|
| Ввод в действие зданий | Завершённые и введённые в эксплуатацию здания | 2000–2024 |
| Незавершённое строительство | Здания/сооружения в стадии строительства (имеют разрешение, не завершены) | 2000–2024 |
| Незавершённое жилищное строительство | Жилые дома в стадии строительства | 2000–2024 |

### Источники данных по разрешениям

| Источник | Статус |
|----------|--------|
| Росстат (разрешения на строительство) | ❌ Нет отдельной публикации |
| Росстат (незавершённое строительство) | ✅ Загружено, 2000–2024 |
| Минстрой РФ | ❌ Сервер недоступен |
| ЕИСЖС | ❌ Сервер недоступен |
| ДОМ.РФ | ⚠️ SPA, данные через JS |
| Росреестр | ❌ Сервер недоступен |

## 5. Данные по регионам — охват

| Показатель | Регионов | Период | Записей |
|-----------|----------|--------|---------|
| Ввод зданий (число) | 96 | 2000–2024 | 2 367 |
| Незавершённое строительство | 97 | 2000–2024 | 6 970 |

### База данных

```sql
-- РФ: ввод зданий по годам
SELECT year, value FROM building_completions_regional
WHERE region_name = 'Российская Федерация'
AND indicator = 'buildings_completed_count' ORDER BY year;

-- Топ-10 регионов: незавершённое строительство 2024
SELECT region_name, value FROM unfinished_construction_regional
WHERE year = 2024 AND indicator = 'unfinished_buildings_count'
ORDER BY value DESC LIMIT 10;
```

## 6. Что недоступно

| Данные | Источник | Статус |
|--------|----------|--------|
| Разрешения на строительство (форма 1-разрешение) | Росстат | Не публикуется в открытых данных |
| ДДУ по регионам | ЕИСЖС / Росреестр | Серверы недоступны |
| Сделки купли-продажи | Росреестр | Сервер недоступен |
| Статистика ДОМ.РФ | наш.дом.рф | SPA, данные через JS |

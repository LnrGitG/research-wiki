# inFOM: длинный ряд инфляционных ожиданий населения в каноне

**Дата:** 18.10.2026. **Источник:** Банк России, статистика инфляционных
ожиданий населения —
<https://www.cbr.ru/statistics/ddkp/inflationary_expectations/>.
**Артефакт:** `scripts/cbr_infom_canon.py`, релиз
`cbr_infom_expectations_2026-09`.

## Что сделано

До этой загрузки в каноне лежали семь рядов inFOM на 32 месяца
(2024-01 … 2026-08), разобранные из одного снимка `Infl_exp_26-08.xlsx`.
Причина короткого ряда проста: каждый месячный файл ЦБ содержит только
последние ~32 опроса, поэтому накопительная история не собиралась.

Рациональный путь оказался другим: в файлах нового формата есть лист
«Данные за все годы», где источник сам держит всю историю — 163 опроса с
декабря 2009 по сентябрь 2026. Достаточно одного последнего файла, а не
125 месячных.

Разбор идёт по подписям блоков («медианные значения», «наблюдаемая
инфляция (в %)», «ожидаемая инфляция (в %)», годовая и пятилетняя, всего и
по группам сбережений), а не по номерам строк: номера смещаются между
выпусками, и именно поэтому прежний разбор держался на жёстких индексах
строк 108–119. Пропуск любого из девяти рядов теперь `RuntimeError`, а не
тихий ноль.

## Покрытие

- ожидаемая инфляция на год, медиана — 162 точки, 2010-04 … 2026-09;
- наблюдаемая инфляция, медиана — 162 точки, тот же период;
- те же два показателя по группам имеющих и не имеющих сбережения —
  111 точек каждая, с 2017-03;
- ожидания на пять лет (медиана, сбережения, без сбережений) —
  по 45 точек, с 2023-01; три этих метрики заведены в канон впервые.

Ранние опросы квартальные: до 2016 года между точками встречаются
пропуски по два-три месяца (2010-04, 2010-06, 2010-09, 2010-12, далее с
июля 2011), и это свойство источника, а не потеря разбора. С 2016 года ряд
месячный без разрывов. Первый столбец файла (декабрь 2009) не содержит
значений по медианам — опрос того выпуска ещё не задавал вопрос в текущей
формулировке.

## Проверки

- Сверка разбора с каноном: 903 из 903, расхождений 0, пропусков 0,
  лишних строк 0.
- Перекрытие с прежним разбором файла 26-08: 224 из 224 значений совпали
  до 10⁻⁹ — то есть разбор по подписям даёт тот же результат, что прежний
  разбор по номерам строк на общем участке.
- Идемпотентность: два повторных прогона подряд дали те же 903 строки при
  903 уникальных ключах (`metric_id, period_start`); снятие окна по паре
  «метрика — релиз» перед вставкой.
- Свежесть: все девять метрик в `derived.v_metric_context` со статусом
  «свежие», последнее наблюдение 2026-09.

## Оговорки

1. История в файле — **текущий винтаж источника**, а не первая публикация.
   Если нужен point-in-time (значение, известное в момент решения по
   ставке), придётся качать месячные файлы по одному и вести винтажи;
   структура загрузчика для этого готова (релиз на файл).
2. Уровни 2010–2012 годов (ожидаемая инфляция 12,9–18,7%) заметно выше
   фактической инфляции того периода — это известное свойство восприятия
   цен населением, но конкретные ранние значения стоит сверить с
   бюллетенями ЦБ перед использованием в оценке (needs_source_check).
3. Метка релиза соответствует месяцу файла (2026-09), а не месяцу опроса:
   файл сентябрьского выпуска содержит и сентябрьский опрос, но у части
   выпусков лаг больше.

## Последние значения

- ожидаемая инфляция на год: 14,16% (2026-09), 13,67% (2026-08),
  14,70% (2026-07);
- наблюдаемая инфляция: 15,09% (2026-09), 14,31% (2026-08),
  15,10% (2026-07).

Исторические экстремумы: максимум ожиданий 18,70% (2010-12), минимум
7,81% (2018-04); максимум наблюдаемой 27,91% (2015-05), минимум 8,29%
(2018-04).

## Расписание

Еженедельная проверка публикации: no_agent-джоб `inFOM weekly canon load`
(понедельник 09:00, скрипт `~/.hermes/scripts/cbr_infom_weekly.sh`,
доставка local, ошибки — в чат). Прогон идемпотентен: при отсутствии нового
выпуска перезаписывается тот же релиз теми же значениями.

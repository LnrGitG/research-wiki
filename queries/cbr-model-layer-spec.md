# Слой модельных спецификаций ЦБ на инфраструктуре research-wiki (JupyterLab ВМ YC)

Дата: 2026-09-24. Статус: предложение к реализации. Владелец решения: Ленар.

## 1. Что опубликовано ЦБ и что в наших руках

Источники (скачаны в raw/papers/cbr_models/):
- kpm_ddkp.rar (cbr.ru/Content/Document/File/174929) — код КПМ ДДКП: IRIS-модель
  (qpm_model.mod 966 строк + external_model.mod + fiscal block + term structure,
  всего ~2 700 строк m/mod), 100 измерительных уравнений, базовая инфляция PIE_C
  отдельно, правило ставки RS = gamma1*RS{-1} + (1-gamma1)*(RS_NEUTRAL +
  gamma2*E3_PIE4_DEV + gamma3*Y_GAP), где E3_PIE4_MP = 0,75*E(базовая инфляция,
  3 кв.) + 0,25*E(общая инфляция, 3 кв.); gamma1=0,75, gamma2=1,5 (hard: 1,9),
  gamma3=0,5. Блоки: Phillips core dom/imp, бюджет, ОФЗ term structure, капитальные
  контроли, рынок труда.
- kpm_dip.rar (…/174930) — код КПМ ДИП: ru_model.model 492 строки (IRIS),
  параметры 6 вариантных наборов (budget/inertialagents/monetaryhard/
  nomarketloans/rationalagents), внешние блоки ext_model.model. Базовой инфляции
  как отдельной переменной нет; данных нет; аудит smart-lab (Лебедев 03.08.2026)
  отмечает ~2 вероятные технические ошибки в российской ветке запуска.
- inf_note_202408.pdf — «КПМ России с рынком труда» (Орлов, Шарафутдинов, 68 с.):
  полное описание уравнений и калибровки — основной документ для порта.
- wp_87.pdf — региональная КПМ (Коршунов, Нелюбина, 2021).
- inf_note_mar_0521.pdf — архитектура прогнозного раунда (Могилат, Селезнев, Жабина).
- bDSGE.pdf — DSGE с банковским сектором (симуляционная, вторая очередь).

Ограничения публикации (зафиксированы): код без данных, без оценочных процедур,
не воспроизводит официальный прогноз; официально требует MATLAB 2014/2019a+ +
IRIS Toolbox 2014/2015+ + MiKTeX. На ВМ MATLAB/IRIS недоступны → порт на Python.

## 2. Архитектура слоя (песочница ВМ: ~/sandbox_datasets/models/, JupyterLab :8443)

- L0 data bridge: адаптер PG v2 (localhost:5432, роль wiki) → quarterly model-ready
  датасет. Маппинг переменных модели на metric_code: таблица
  models/specs/var_map.yaml (Y_GAP → cbrmon/Росстат ВВП-наукастинг; PIE_C →
  базовая инфляция Росстата; DOT_Y; RS → ключевая ставка; Y_GAP вход ИКВ/СМР —
  наши метрики kep1_63 и emiss_*). Правило: одна переменная — один источник,
  конфликты фиксируются в var_map (assessment).
- L1 спецификации: models/specs/kpm_ddkp.yaml (уравнения, портированные из
  qpm_model.mod с сохранением имён переменных ЦБ), kpm_dip.yaml, bdsge-lite.yaml.
  Формат YAML, не код: уравнение как строка, параметры по именам, steady state,
  список шоков. Версионирование в git (~/macroeconomist).
- L2 решатель: Python-порт линейного semi-structural QPM — решение линейной
  системы с forward-ожиданиями (алгоритм Klein/Sims), IRF, сценарные прогоны,
  фильтр Калмана для разрыва выпуска (опционально). Кандидаты: linearsolve /
  собственный модуль (~300 строк). Проверка корректности: воспроизведение IRF
  из results/irf_* архива ДДКП (PNG — сравнение качественное + численно при
  перезапуске в MATLAB недоступном — только форма).
- L3 оперативный контур (связка с sitrep): входы — свежие данные из релизов
  (ЦБ 91, emiss_registry_batch1_2026-09), наукастинг ИКВ/СМР; выход —
  «что изменилось в модельной картине»: обновлённый разрыв выпуска, реакция
  RS по правилу, вклад базовой/общей инфляции в индикатор MP.
- L4 контрольные точки: сравнение модельных траекторий с официальным прогнозом
  ОНДКП (не воспроизведение, а отклонение-анализ); KT-скрипт в CI-стиле.

## 3. Порядок работ
1. Порт qpm_model.mod → kpm_ddkp.yaml (уравнения по inf_note_202408, имена — из кода).
2. var_map.yaml: ~30 наблюдаемых переменных → metric_code БД v2.
3. Решатель + smoke-test (нулевые шоки → steady state; IRF денежного шока).
4. Первая оперативная сессия: разрыв выпуска + правило ставки на данных 2026.
5. Документирование расхождений kpm_dip vs kpm_ddkp (базовая инфляция, бюджет).

## 4. Проверяемые гипотезы
- H1: правило ставки ДДКП с весом базовой инфляции 0,75 объясняет паузы ЦБ при
  высокой headline-инфляции лучше, чем правило Тейлора на headline.
- H2: наш наукастинг разрыва выпуска (ИКВ+СМР) даёт знак Y_GAP, согласованный с
  ИБК ЦБ (corr > 0,5 на 2023–2026).
- H3: сценарий «hard» (gamma2=1,9) воспроизводит траекторию ставки 2025 г. лучше базового.

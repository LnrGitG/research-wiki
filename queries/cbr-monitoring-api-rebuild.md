# Пересборка cbr_monitoring_construction из универсального API ЦБ + загрузка факторов ИИБ

Дата: 2026-09-23. Скрипты: `scripts/cbr_monitoring_api_collect.py`, `scripts/cbr_monitoring_facts_collect.py`.

## Проблема старой таблицы

Старый загруз через `dataservice/dataNew` (categoryId=25, iIds=68, коммит `2cba817`) содержал две систематические ошибки:

1. **Сдвиг датировки +2 месяца**: строка датировалась месяцем опроса вместо отчётного периода.
2. **Фальшивый SA**: колонка «Сезонно скорректированные данные» на деле содержала RAW.

Плюс сентябрьская точка 2026 (ИБК −5,1924) — артефакт умирающего сервиса, не соответствующая ни одному винтажу файла/API. Сервис `dataNew` полностью мёртв (501 на все categoryId) с 09.2026.

## Новый источник

Универсальный REST API Банка России (`https://www.cbr.ru/dataservice/`, документация: `/statistics/data-service/APIdocumentation/`, OpenAPI: `/dataservice/swagger`), без ключа:

- `publications` → категория «Мониторинг предприятий» (id 24) → publicationId 25 «Данные мониторинга всего», datasetId 68 «Строительство», 12 вопросов.
- `measures?datasetId=68`: 118 = «Исходные данные», 119 = «Сезонно скорректированные данные» (настоящий SA, ревизируется задним числом).
- `data?y1&y2&datasetId&publicationId&measureId`.

**Датировка API (проверено сверкой с XLSX, 18/18 точек)**: `date` в ответе API = отчётный период + 2 месяца (`dt` = месяц опроса). При записи дата = `date` − 2 мес.

## Валидация

1. **Полная сверка с XLSX** (`File/135603/mp_survey_data.xlsx`, лист «Строительство», 296 месячных строк × ~22 колонки raw/SA): **0 несовпадений** с допуском 0.005.
2. **Контрольные точки** (ИБК, element_id=41): raw 2026-04 = 11,1019; raw 2026-08 = −3,1433; SA 2026-04 = −1,1003; SA 2026-07 = −4,9945; SA 2026-08 = −3,1102 — все OK.
3. **Артефакт −5,1924 (2026-09) отсутствует** в новой таблице.
4. **Факторы ИИБ**: 7 факторов × 4 размерные группы × 26 кварталов = 728 строк; spot-checks: 2020Q1 «недостаточный спрос» (Экономика всего) = 21,34; «уровень процентных ставок» = 6,2035; 2026Q2: 18,52 и 15,33 — все OK.

## Корректная картина ИБК (строительство) по исправленным данным

- RAW: апрель +11,10 → май +8,70 → июнь +4,54 → июль +0,39 → август −3,14 (отчётные периоды).
- SA: апрель −1,10 → май −0,20 → июнь −1,10 → июль −3,26 → август −3,11 (факт SA июль = −4,99 был в API пересмотрен из −4,35 за июнь; ревизии SA задним числом).

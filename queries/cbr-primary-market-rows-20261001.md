# Схема таблиц

Обе таблицы повторяют схему `public.cbr_housing_loans`:

    (level text, fed_okrug text, region text, period text, metric text, value double precision)
    period — 'YYYY-MM';  индексы по (region, period) и (metric)

Уровни строк `level`:

- `RF` — строка «РОССИЙСКАЯ ФЕДЕРАЦИЯ»;
- `federal_district` — 8 федеральных округов;
- `region` — самостоятельные субъекты (82 строки, включая г. Москва,
  г. Санкт-Петербург, г. Севастополь и материнские строки «Архангельская
  область» / «Тюменская область» ЦЕЛИКОМ);
- `okrug` — автономные округа внутри материнских областей («в том числе …»):
  НАО, ХМАО-Югра, ЯНАО — это тоже субъекты РФ, но их значения УЖЕ включены
  в материнскую строку `region`;
- `nested` — разложения «без данных по …» (Архангельская без НАО, Тюменская
  без Югры и ЯНАО) — не субъекты, вспомогательные строки.

Субъектов всего **85** (82 `region` + 3 `okrug`). Сумма строк `level='region'`
в точности равна строке РФ (проверено по всем 92/32 месяцам для count и volume;
допуск 0,5 % или 1,5 единицы). Ставка и доля — средневзвешенные величины, они
не суммируются и в сверку суммы не входят.

**Ловушка двойного счёта.** Материнские строки «Архангельская область» и
«Тюменская область» включают автономные округа. При построении панели по
субъектам брать либо строки `region` (и тогда ХМАО/ЯНАО/НАО не добавлять),
либо разложение: материнская = `nested` + `okrug`. Проверено: для count
разложение сходится во всех месяцах (Архангельская = «без НАО» + НАО;
Тюменская = «без Югры и ЯНАО» + ХМАО-Югра + ЯНАО).

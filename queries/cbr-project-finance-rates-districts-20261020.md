# Ставка проектного финансирования по федеральным округам: загрузка и найденный дефект канона

**Дата:** 20.10.2026
**Источник:** ЦБ РФ, страница «Финансирование долевого строительства»
(`https://cbr.ru/statistics/bank_sector/equity_const_financing/`), месячные файлы
`на DD.MM.YYYY` формата XLSX, 57 выпусков с 01.01.2022 по 01.09.2026, локально —
`raw/cbr/escrow/DDMMYYYY.xlsx`.
**Скрипт:** `scripts/ingest_cbr_pf_fo.py`.
**Метрики:** `cbr_pf_rate_fo_m`, `cbr_pf_sum_fo_m`, `cbr_pf_debt_fo_m`, `cbr_pf_rate_ru_m`
(release 362, «cbr-pf-fo canon 2026-10-15»).
**Гипотеза:** H-034 (проверка банковского клина на фактической стоимости проектного
финансирования).

## Зачем понадобилась отдельная загрузка

Штатный загрузчик `scripts/cbr_banking_canon.py` разбирает те же файлы, но берёт
колонки по фиксированным номерам: индекс 4 → «Задолженность», 7 → «ставка». Эта
разметка верна только для файлов 2025 года и новее. В файлах 2022–2024 колонки
«Задолженность» нет вовсе, поэтому индекс 4 попадал в «Кол-во счетов эскроу», а
индекс 7 — в «Кол-во раскрытых счетов за месяц». Проверка подтвердила порчу рядов:
в `cbr_pf_rate_reg_m` по России на июль 2026 стоят значения до **3 080 690,66**
при среднем **88 862,14**, а минимум по месяцам — **0,00**; это не проценты, а
счётчики счетов. Всего в двух рядах 3 400 и 4 641 наблюдение по 85 регионам за
2022-01…2026-09.

Оба ряда переведены в статус `deprecated` (`is_active=false`) с описанием дефекта;
историю не удаляю — правило канона запрещает правку прошлых загрузок, а замена
зафиксирована новыми метриками. Потребителям этих кодов теперь видно, что ряд
непригоден, а не просто «пустой».

## Что публикует источник

Ставка в файлах есть **только по федеральным округам**: в строках субъектов
колонка пуста по условиям конфиденциальности. Отсюда гранулярность новых метрик —
округ плюс агрегат по России, который считается как взвешенное среднее ставок
округов с весом «Сумма действующих кредитных договоров, млн руб.» (ставка относится
к договорам, поэтому вес по сумме договоров, а не по задолженности).

Формат файлов менялся дважды, поэтому колонки определяются по тексту шапки:
в 2022 году шапка называет ставку «Средняя ставка по кредитным договорам», с 2025
года появляется колонка «Задолженность», а «Кол-во счетов эскроу» сдвигается с 5-го
на 6-е место. Дополнительно в файлах **2023-02…2023-06 ставка записана долей**
(0,046), а не процентом: без выравнивания масштаба эти пять месяцев дают ставку
порядка 0,05 % и проваливают ряд. Скрипт выравнивает масштаб по максимуму файла и
печатает перечень исправленных выпусков; после выравнивания все ставки попадают в
коридор 0,5–40 % (проверка встроена).

## Ряды

Ставка по России, среднее за год: **4,83 %** (2022), **5,12 %** (2023, с учётом
исправленного масштаба в пяти выпусках), **7,18 %** (2024), **10,22 %** (2025),
**9,93 %** (2026, девять месяцев). Последние месяцы: **9,94 %** (01.09.2026),
**9,57 %** (01.08.2026), **9,85 %** (01.07.2026), **9,87 %** (01.06.2026),
**9,90 %** (01.05.2026).

Сверка с публикацией ЦБ: пресс-релиз «Прирост портфеля кредитов застройщикам во
II квартале заметно ускорился» (`cbr.ru/press/event/?id=32801`) называет
средневзвешенную ставку по кредитам застройщикам **9,9 %** (против **14,7 %** в
корпоративном сегменте) — сходится с расчётом по округам: июнь 9,87 %, май 9,90 %,
апрель 9,89 %. Квартальный PDF «О проектном финансировании» (2к2026,
`cbr.ru/Collection/Collection/File/62336/pf_2Q2026.pdf`) уточняет определение:
«средневзвешенная процентная ставка по кредитным договорам ПФ, имеющим
задолженность» — то есть это ставка по портфелю с задолженностью, а не по новым
договорам.

Разброс по округам на 01.09.2026: Южный **12,86 %**, Северо-Кавказский **11,86 %**,
Уральский **11,54 %**, Северо-Западный **10,25 %**, Сибирский **9,66 %**,
Приволжский **9,54 %**, Центральный **9,13 %**, Дальневосточный **8,92 %**. То есть
внутри страны ставка различается в 1,4 раза — для региональных срезов это важнее
общероссийского уровня.

Задолженность по договорам проектного финансирования доступна только с
**01.11.2024** (колонка появилась в файле 2024 года), сумма действующих договоров —
с 2022-01. Обе метрики — в млн руб., 184 и 456 наблюдений по восьми округам.

## Вывод для research-wiki

Данные закрывают ограничение, зафиксированное в спецификации H-034 версии 1
(«ряда эффективной стоимости проектного финансирования в базе нет»). Прямая
проверка гипотезы на этом ряду дала отрицательный результат: коэффициент при
изменении ставки ПФ отрицателен и незначим (-0,0026, t = −1,4), в совместной
спецификации с ключевой ставкой — значимо отрицателен (-0,0052, t = −3,3), в
подпериодах — ноль. Причина, вероятно, в измерении: публикуемая ставка — средняя
по портфелю действующих договоров, фиксированных при заключении, поэтому она
инерционна и не равна предельной стоимости нового проекта. Подробности — в
`queries/h034-price-cost-gap-spec-20261015.md`, раздел «Проверка на фактической
ставке проектного финансирования».

## Проверки при загрузке

- Колонки по шапке, а не по номеру; ставки вне коридора 0,5–40 % — счётчик в выводе
  (сейчас **0**).
- Сверка агрегата с пресс-релизом ЦБ (9,9 % против 9,87–9,90 % по месяцам квартала).
- Воспроизводимость: скрипт идемпотентен, релиз переиспользуется, строки предыдущего
  прогона удаляются перед вставкой.

## 0. Границы и запреты

Три запрета действуют до письменного разрешения владельца и оформления доступа: не запрашивать и не копировать
закрытые записи; не выносить микроданные за пределы защищённого контура; не публиковать числа, восстановимые
до отдельной фирмы. Все расчёты выполняются только после утверждения протокола и законного получения данных.
Расчёт по агрегатам не подменяет причинный вывод: там, где микродоступ не оформлен, блок выдаёт описательный или
сценарный результат со статусом «не установлено», а не оценку эффекта.

Второе ограничение — исполнительская дисциплина. ВМ получает только заранее проверенную спецификацию и скрипт
и не имеет права менять формулы, фильтры, окна, исключения или набор сценариев. Приёмка включает сверку n,
пропусков, баланса панели, знаков и коэффициентов с локальным эталоном; расхождение более 1% останавливает
прогон.

### 1.2. Стадии пайплайна

**P0. Псевдонимизация и приём.** Данные принимаются от держателей массивов; прямые идентификаторы заменяются
псевдонимами на стороне держателя, ключи связывания согласуются до передачи. Промежуточные файлы в контуре
уничтожаются по завершении прогона. Приёмка: число записей по каждому массиву, контрольные суммы, отчёт о
пропущенных полях. Ошибка связывания на этой стадии означает остановку, а не «дозаполнение» нулями.

**P1. Согласование справочников.** Единая классификация сегментов (`seg_target` — программа ЭКСАР; `seg_control_1` —
МСП без экспортного критерия; `seg_control_2` — крупные инвестиционные проекты; `seg_market` — прочие кредиты),
единая сетка кварталов и месяцев, единая версия отраслевого классификатора. Выход — таблица `a_seg_map` с версией
классификации; смена версии после начала расчётов — post hoc.

**P2. Поток выборки.** Строится воронка «все заявки → полные заявки → связанные с отчётностью → аналитическая
панель», с причинами исключения и долями пропусков по каждому шагу. Неполные заявки описываются отдельно. Счёт
ведётся по шагам и публикуется таблицей; расхождение с локальным эталоном более 1% останавливает прогон.

**P3. Дефляция.** Все денежные величины приводятся к ценам последнего полного предсобытийного года окна.
Дефляторы фиксируются до результатов и не подбираются по ним (см. 1.3).

**P4. Построение первичных исходов.** Четыре показателя: реальные капитальные затраты проекта, реальный выпуск
фирмы, занятость в FTE, совокупный долг фирмы. Уровни до воздействия, изменение на восьми кварталах, накопленный
эффект. Нулевые значения не удаляются молча.

**P5. Оценки.** Блок A (импульс и передача цены), затем блок B (КПМ), затем блок C (риск). Порядок жёсткий: вход
блока B — принятый импульс блока A, а не калибровка под желаемый выпуск.

**P6. Сверка и выгрузка.** Агрегаты выгружаются в `research_wiki` прямым загрузчиком с `run_id`, манифестом
(sha256 входов и выходов) и проверкой идемпотентности повторным прогоном.

| Величина | Дефлятор | Обоснование |

## 2. Блок A. Кредитный импульс по сегментам

### 2.1. Определения и формулы

Поток кредитования сегмента `s` за квартал: `F_{s,t} = B_{s,t} − B_{s,t−1}`, где `B` — номинальная задолженность,
дефлированная на ИПЦ и сезонно скорректированная (X-13-подобная декомпозиция или регрессия на месячные дамми;
метод фиксируется до результатов).

Кредитный импульс (credit impulse — ускорение кредитного потока относительно выпуска):

```
CI_{s,t} = (F_{s,t} − F_{s,t−1}) / Y_{t−1}
```

где `Y_{t−1}` — номинальный ВВП предыдущего квартала; альтернативная нормировка — на реальный ВВП, используется
как проверка. Импульс в процентах ВВП — это и есть вход блока B; в КПМ он подаётся как отклонение от базовой
траектории:

```
ε^{credit}_{s,t} = CI^{сцен}_{s,t} − CI^{база}_{s,t}
```

Дополнительно к импульсу по объёму считается **импульс по цене** (эффективная ставка):

```
Δr^{eff}_{s,t} = r^{eff}_{s,t} − r^{eff}_{s,t−1},   r^{eff} = средневзвешенная ставка по новым выдачам с учётом комиссий
```

и **импульс по доступу** — изменение доли одобрений `a_{s,t} = approvals/applications`, и доли отказов.

### 2.2. Оцениваемые величины

По каждому сегменту раздельно: число заявок, число одобрений, объём выдач, эффективная ставка, срок, доля отказов.
Спецификация — локальная проекция на квартальных данных с фиксированными эффектами сегмента и квартала:

```
y_{s,t} = α_s + λ_t + Σ_{k=−4}^{8} δ_k · 1[t − e_s = k] + u_{s,t}
```

где `e_s` — событие сегмента (смена формулы, исчерпание лимита). Ошибки: кластеризация по сегменту; при малом
числе кластеров — wild-cluster bootstrap (`boottest`, 9 999 репликаций).

Идентификация цены — на договорном уровне, а не на сегментном:

```
r^{loan}_{ibt} = α_i + δ_t + θ · r^{funding}_{ibt} + γ X_{ibt} + e_{ibt}
```

`θ` считается на горизонтах `h = 0,1,2` квартала; основная проверка H-B — `θ_2` (передача за два квартала).
Сопоставление с незатронутыми кредитами — разность: `θ^{tool} − θ^{non-tool}`. Ошибки — двухсторонняя
кластеризация (фирма и банк × квартал) с проверкой на малом числе кластеров.

### 2.3. Вытеснение (H-A)

Доля вытеснения определяется на панели фирмы:

```
DO_i = ( ΔDebt^{market,observed}_i − ΔDebt^{market,counterfactual}_i ) / ΔDebt^{total}_i
```

где контрфактическое изменение рыночного долга берётся из сопоставимой контрольной группы (синтетический контроль
по предыстории: экспорт, размер, долговая нагрузка, отрасль, регион). Верхняя 95%-я граница `DO` сравнивается с
порогом 25%. Если разделить рыночный и программный долг надёжно нельзя, H-A получает статус «не установлено»,
а не «подтверждена». Аддитивность проверяется отдельно: при отсутствии роста совокупного долга прирост
капитальных затрат интерпретируется как замена, а не дополнение.

### 2.4. Привязка к гипотезам и порогам

| Расчёт | Гипотеза | Приёмка |
|---|---|---|
| ITT по реальным капитальным затратам (панель фирмы) | H-A | коэффициент >0, 95% ДИ исключает ноль |
| Доля вытеснения `DO`, верхняя 95%-я граница | H-A | ≤25% |
| Динамические эффекты β_k, k=1..8; накопленный эффект | H-C | накопленный >0, β_{5–8} ≥ 0,5·β_{1–4} |
| Передача цены `θ_2`, точечная оценка и ДИ | H-B | `θ_2` ≥0,5, ДИ исключает ноль |
| Эффективная ставка, срок, объём, маржа по отдельности | H-B (описательно) | не подменяют ценовой исход |
| Показатели обучения, связей, сложности | H-D | положительный эффект хотя бы по одному заранее заданному |
| Доля экспортёров среди получателей; связь балла допуска с экспортной долей | H-D (правовой тест) | отсутствие доказательств сведения критерия к экспорту |
| Ставки по сегментам × высокочастотный сюрприз | H-F | верхняя 95%-я граница ухудшения <10% базового коэффициента |
| Ожидания: отклонение от базового сценария через 4 квартала | H-F | ≤0,25 п.п. |

Первичные исходы (капитальные затраты, выпуск, занятость, долг) образуют одно семейство; p-значения
корректируются Holm при семейном уровне 5%. Вторичные — Benjamini–Hochberg и метка «исследовательский».

### 2.5. Псевдокод блока A

## 3. Блок B. Три сценария в КПМ и метрика согласованности

### 3.1. Спецификация сценариев

КПМ используется как сателлитная надстройка согласованности, а не как источник величины воздействия. Три варианта
ценобразования:

1. **S1 — действующая привязка.** Ставка инструмента `r^{tool}_t = r^{key}_t − 1,5 п.п.`; на 12.10.2026 при
   ключевой 14,00% это 12,50%. Лимит 75 млрд руб., остаток 63,67 млн руб.
2. **S2 — расширение лимита при сохранении привязки.** Тот же спред, увеличенный лимит; меняется только
   количественное ограничение.
3. **S3 — расширение лимита с отвязкой (селективный клин).** Ставка инструмента фиксируется вне правила ключевой
   ставки; клин `τ_{t,s} = max(0, r^{key}_t + μ_s − r^{fixed})`, так что `r^{eff}_{t,s} = r^{fixed} = 9,00%`
   (ориентир — ставка по крупным инвестиционным проектам на 12.10.2026, `www.cbr.ru/hd_base/procstav/ir_srm/`).
   Альтернативная калибровка — фиксированный спред, растущий при ужесточении; она подаётся как проверка, а не как
   основной вариант.

Общее ядро модели — новокейнсианская малая открытая экономика с ИТ, плавающим курсом и бюджетным правилом:

```
IS:        x_t = E_t x_{t+1} − σ (i_t − E_t π_{t+1} − r*_t) + κ_c ε^{credit}_t + b_fx Δs_t
Phillips:  π_t = β E_t π_{t+1} + κ x_t + ξ Δs_t + u_t
Taylor:    i_t = ρ i_{t−1} + (1−ρ)( φ_π π^{4q}_t + φ_x x_t ) + e_t
UIP:       s_t = E_t s_{t+1} − ( i_t − i*_t ) + ψ_t
Budget:    Cost_t = Σ_s ΔB_{s,t} · ( τ_{t,s} + μ_s + EL_{s,t} )
```

Сегментная блокировка задаёт долю целевого класса в кредите и его чувствительность: `r^{eff}_{t,s} = i_t + μ_s − τ_{t,s}`.
Одинаковы во всех сценариях: внешние шоки, бюджетное правило, горизонт (12 кварталов), начальные условия, набор
наблюдаемых переменных. Различия — только в правиле цены и лимите.

### 3.2. Метрика согласованности

Согласованность не измеряется «похожестью на желаемый ответ». Пять проверок, каждая машинно проверяемая:

| Код | Проверка | Допуск |
|---|---|---|
| C1 | при `τ = 0` сценарии S1 и S3 совпадают (тот же код, тот же вход) | max abs diff ≤ 1e-9 по всем переменным |
| C2 | при нулевом спросе на дополнительное финансирование расширение лимита не меняет результат (S2 = S1) | ≤ 1e-9 |
| C3 | шоковые траектории S1, S2, S3 побитово идентичны | sha256 совпадают |
| C4 | бюджетная стоимость из КПМ совпадает с расчётом блока C | относительное расхождение ≤ 1% |
| C5 | знаки передаточной функции: ∂x/∂τ > 0, ∂π/∂τ > 0, ∂i/∂τ > 0 | знак устойчив во всех сценариях |

Итоговая метрика: `S_coherence = Σ C_i` (0…5); публикация результатов допускается только при `S_coherence = 5`.
Дополнительно публикуется относительная мера различия сценариев `ρ = ||y^{S3} − y^{S2}||_2 / ||y^{S2}||_2` по
выпуску, инфляции и ключевой ставке — она описывает величину эффекта, но не является критерием приёмки.

### 3.3. Диапазоны вместо точечных чисел

Сценарии подаются диапазонами: отклик выпуска, инфляции и ключевой ставки на клин в пределах 5–15 п.п. и на
расширение лимита (0,5–1,5% ВВП дополнительного кредита, верхняя граница соответствует полному использованию
расширенного лимита). Отчёт явно отделяет оценённые параметры (импульс, передача цены) от калибровок
(доли сегментов, эластичности, правила распределения средств).

## 4. Блок C. Квазифискальная стоимость и CVaR

### 4.1. Модель потерь

Индивидуальная вероятность дефолта на горизонте `t`:

```
PD_{i,t} = Λ( β0 + β1 · cycle_t + β2 · export_exposure_i + β3 · size_i + β4 · leverage_i
             + β5 · program_i + β6 · rate_shock_i + α_{sector} + u_i )
```

`Λ` — логистическая функция; `cycle` — разрыв выпуска из блока B; `export_exposure` — дореформенная доля экспорта;
`program` — участие в инструменте. Потери на пути `j`:

```
L_t^{(j)} = Σ_i D_{i,t}^{(j)} · EAD_{i,t} · LGD_i · (1 − Recovery_i)
```

где `D` — индикатор дефолта, `EAD` — экспозиция на дефолт, `LGD` — доля потерь при дефолте. Зависимость дефолтов —
однофакторная гауссова копула: `Z_i = ρ_m · M + sqrt(1 − ρ_m²) · ε_i`, дефолт при `Z_i ≤ Φ^{-1}(PD_{i,t})`.
Базовая корреляция `ρ_m = 0,30`; проверки — 0,10 / 0,50. Дополнительно — аналитическая проверка по модели
Васичека: распределение потерь на большом портфеле сравнивается с симуляционным по первым двум моментам.

Стоимость разделяется на три непересекающихся компонента: недополученный доход и потери Банка России по
рефинансированию; расходы бюджета через гарантии и перечисления из прибыли; кредитный убыток банков. Субсидия
(разница цен) не смешивается с ожидаемыми потерями, а трансферт не учитывается дважды.

### 4.2. Горизонт, уровни доверия, метрики

- Горизонт основной — 20 кварталов (полный срок кредита); вторичный — 8 кварталов для сопоставимости с H-C.
- Уровни: VaR 95%, **CVaR 95%** (основной по протоколу); CVaR 99% — проверка чувствительности, не критерий.
- Число путей 10 000, антитетические пары, `seed = 20261025`. Критерий сходимости: стандартная ошибка CVaR ≤ 1%
  от CVaR; иначе путей до 40 000.
- Дисконтирование: `r_d` = ключевая ставка на дату регистрации протокола (14,00%) — консервативно и фиксировано
  до результатов; альтернативная ставка (доходность ОФЗ) — проверка.

```
CVaR_α = (1/(1−α)) · (1/N) Σ_{j: L^{(j)} ≥ VaR_α} L^{(j)},   VaR_α = quantile_α({L^{(j)}})
```

### 4.3. Общественная приведённая стоимость (H-E)

```
ΔNPV_soc = Σ_{t=0}^{20} [ ΔOutput_t + ΔSpill_t − ΔResource_t − ΔSubsidy_t − ΔEL_t ] / (1 + r_d)^t
```

Правило приёмки H-E: `ΔNPV_soc > 0` в базовом сценарии и `≥ 0` не менее чем в 80% заранее заданных стресс-сценариев
(набор из 10 сценариев фиксируется до расчётов: рецессия, риск-офф, дезинфляция, рост ставок, отраслевой шок,
дефолт крупного заёмщика, падение экспортных цен, санкционный шок, комбинация, базовый). Диагностический признак
перекладывания риска — рост CVaR потерь при незначимом изменении среднего эффекта; при таком сочетании H-E не
поддерживается независимо от знака ΔNPV.

### 4.4. Псевдокод блока C

```
read m_loan_m, m_disb, m_firm_q, m_scenario, a_kpm_inputs
fit PD model on pre-event window; report AUC, calibration, out-of-sample
for j in 1..10000 (antithetic):
    M = rng.normal(seed=20261025 + j//2)
    for t in 1..20:
        PD = logistic(Xb + cycle[t] * beta_cycle)
        default_i = (rho_m*M + sqrt(1-rho_m^2)*eps_i) <= Phi_inv(PD)
        L[t,j] = sum(default * EAD * LGD * (1-recovery))
split L into CB / budget / banks; assert sum == total
VaR_95 = quantile(L_total, 0.95); CVaR_95 = mean(L_total[L_total >= VaR_95])
assert se(CVaR_95)/CVaR_95 <= 0.01
emit a_loss.parquet, a_social_npv.csv, CVaR by component, scenario table
```

## 5. Проверки устойчивости и валидация

| Проверка | Что выявляет | Гипотеза / блок |
|---|---|---|
| Параллельные предтренды (лаги −4…−1), placebo на отраслях вне программы | ложный эффект от предыстории | H-A, H-C / A |
| Альтернативные даты воздействия (±1 квартал) | чувствительность к дате события | H-C / A |
| Альтернативные окна (6 и 10 кварталов) | отбор окна под результат | H-A, H-C |
| wild-cluster bootstrap, рандомизационный вывод | ошибки при малом числе кластеров | все панельные |
| Holm по четырём первичным исходам; BH по вторичным | множественные проверки | все |
| Синтетический контроль; баланс ковариат до события | остаточный отбор | H-A |
| MDE и мощность при заданном n | «не установлено» вместо «нет эффекта» | H-A…H-F |
| Уровни против логарифмов; нули не удаляются | функциональная форма | H-A |
| Два дефлятора (инвестиционный и ВНОК); две базы | дефлятор под результат | A, H-A |
| Чувствительность к пропускам (bounding, пере-взвешивание) | смещение из-за пропусков | все |
| Смена корреляции дефолтов 0,10/0,30/0,50; LGD ±10 п.п.; CVaR 99% | риск-параметры под результат | H-E / C |
| Повтор с другим seed и повторный запуск | нестабильность симуляции | C |
| Оставляем-один-регион/одну отрасль (leave-one-out) | доминирование одной группы | A, C |
| Сверка агрегатов КПМ с официальными траекториями на историческом интервале | ошибка калибровки модели | B |
| Идемпотентность: повторный прогон даёт 0 новых строк в ядре | дубли и дрейф | все |

Правило остановки: отсутствие отклонённых заявок, отсутствие валидной меры назначения, невозможность связать
фирмы между источниками, недостаток наблюдений на горизонте, неприемлемая несопоставимость по предтрендам или
placebo — статус «не установлено», расчёт не подменяется описательным.

>1% — разбор), полнота выхода, наличие входных файлов, соблюдение предпосылок. При нарушении — прогон возвращается
как непрошедший, выводы не формулируются.

# Дубли файлов в корпусе публикаций: разбор

Записка 19.09.2026. Повод: среди 196 связанных PDF обнаружено **188 уникальных
sha256** — восемь файлов приходятся на две карточки каждый. Разбор показывает,
что это **два разных явления**, и только одно из них дефект.

## Явление первое: `.abstract_ru` — рабочие файлы, не дубли

Семь пар из восьми выглядят так:

```
banai_vago_2018_house_prices_bank_risk.abstract_ru   5401 симв.  «Машинный перевод ключевых разделов (...)
banai_vago_2018_house_prices_bank_risk                4138 симв.  «The effect of house prices on bank risk: ...»
```

Это **не дубликаты, а два разных файла одной работы**: базовый (оригинал либо
перевод) и дополнительный `.abstract_ru` с машинным переводом ключевых
разделов. Тексты у них разные — совпадает только исходный PDF, потому что оба
описывают одну и ту же публикацию.

Дополнительное подтверждение, что это не случайность: **все девять** файлов
`.abstract_ru` в корпусе имеют парный базовый файл — исключений нет.

**Что из этого следует практически:** общий sha256 у таких пар — нормальное
состояние, а не ошибка. В таблице их можно различить по полю `doc_type`
(перевод против статьи) либо просто по коду работы. Никаких действий не нужно.

## Явление второе: настоящий дубль — Iacoviello (2000)

Единственная пара, где дублируется содержание:

```
papers/Iacoviello.-HOUSE-PRICES-AND-THE-MACROECONOMY-IN-EUROPE.md   138 984 симв.
papers/house_prices_macroconomy_europe_svar_iacoviello_2000.md      116 763 симв.
```

Оба файла — работа Matteo Iacoviello «House Prices and the Macroeconomy in
Europe: Results from a Structural VAR Analysis» (ECB Working Paper No. 18,
апрель 2000), один PDF на два файла вики. Перекрытие лексики первых 800 слов
составляет **55%** — то есть тексты в значительной части совпадают, но не
тождественны.

Различие в качестве извлечения видно с первой строки. Первый файл начинается
битой шапкой конвертера:

```
**E U R O P E A N C E N T R A L B A N K** ## **WORKING PAPER SERIES** ...
**BY MATTEO IACOVIELLO APRIL 2000** ## ���������������
```

— здесь есть даже нечитаемые символы. Второй файл начинается чистой
структурированной шапкой:

```
# House Prices and the Macroeconomy in Europe: Results from a Structural VAR Analysis
**Matteo Iacoviello** **April 2000** **ECB Working Paper No. 18** ## Abstract
This paper uses a structural vector autoregressive (SVAR) approach ...
```

**Что из этого следует:** из двух файлов предпочтителен второй
(`house_prices_macroconomy_europe_svar_iacoviello_2000`) — он чище разобран и
имеет нормальную шапку с автором, датой и номером рабочего доклада. Первый
пришёл из более раннего массового импорта (коммиты `c31d5c5` и `cca6744`) и
несёт следы сырой конвертации.

**Действие требует решения владельца:** удалить первый файл либо оставить, но
пометить как устаревший. Удаление затрагивает одну страницу вики, поэтому
само по себе отменяемо коммитом.

## Сколько всего дублей содержания в корпусе

Проверка шла по sha256 **файлов PDF** — восемь групп. Дублей по **тексту**
страниц корпуса отдельно не считалось; при разборе выяснилось, что из восьми
групп содержательный дубль только один. Это значит, что массовой проблемы
двойных записей в корпусе нет.

Для полноты: у семи «парных» групп две карточки на один PDF — норма, у одной
(Iacoviello) — дефект.

## Вывод для задачи карточек

Поле `file_match` в `core.paper_card` показывает способ связки, но не
различает «два файла одной работы» и «дубль». Если такое различение нужно в
витрине, достаточно правила: **пара с общим sha256, где один код заканчивается
на `.abstract_ru`, — норма; все прочие совпадения — кандидаты на разбор.**

## Важное уточнение: третий файл трогать нельзя

При разборе обнаружился третий файл с той же фамилией —
`papers/iacoviello-2005-house-prices.md`. Это **другая работа**:
«House Prices, Borrowing Constraints, and Monetary Policy in the Business
Cycle», American Economic Review, июнь 2005. Удаление затронуло только файл
2000 года (ECB WP No. 18). Файл 2005 года и его перевод
`papers/ru_papers/house_prices_macroconomy_europe_svar_iacoviello_2000.RU.md`
остались на месте.

Также сохранён PDF-первоисточник в бакете — удалена страница вики, не файл.

## Что осталось не проверенным

Имена PDF в хранилище могут не совпадать с именами страниц вики, поэтому
возможны случаи, когда один и тот же PDF лежит в бакете дважды под разными
именами — sha256 в таблице такой случай покажет, но сравнение с содержимым
бакета целиком (312 файлов) не делалось. Нужна дополнительная проверка, если
важно исключить дублирование в самом хранилище.

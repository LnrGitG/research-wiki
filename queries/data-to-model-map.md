# Трасса «ряд → гипотеза → модель → задача»

**Назначение.** Учёт источников данных и вычислительных моделей: для каждого ряда, использованного
в исследовании, фиксируется, под какую гипотезу он собран, в какой модели участвует и в какой задаче
исполняется расчёт. Ведёт профиль research (сопровождение исследовательского трека).

**Правило.** Ряд, попадающий в текст статьи или в расчёт, обязан иметь строку здесь. Если ряд есть в
каталоге БД (`derived.metric_card`), указывается его `metric_id`; если собран из внешней статистики —
прямая ссылка на первоисточник и воспроизводящий скрипт. Расчёт по ряду, отсутствующему в этой таблице,
не принимается.

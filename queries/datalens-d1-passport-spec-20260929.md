# Д1 «Паспорт региона» — чарты DataLens (спека для сборки в веб-консоли, 2026-09-29)

Датасет: `ds_region_monthly` (queries/datalens-collection-concept-20260929.md,
data/datalens_datasets.yaml — SQL проверен против живой PG 29.09).

## Чарты (6)

### Ч1. Ключевые индикаторы (5 индикаторов в один блок)
Тип: Indicator × 5 (ИПЦ, ЗП, безработица, ввод жилья, ставка ИЖК).
Формула значения: агрегация `MAX(value) WHERE period <= <селектор даты>`.
Пример проверенного значения (Башкортостан, 2026-08): ИПЦ 99.86 (дефляция к июлю).

### Ч2. Спарклайны 13 точек (5 малых line-чартов)
Тип: Line, X = period, Y = value, один чарт на метрику, фильтр = регион.
Сортировка X по period; 13 последних точек (DataLens: ограничение строк фильтром
сравнения `period >= now() - interval '13 months'`).

### Ч3. Кредитование: задолженность физ/юр + ИЖК (комбинированный чарт)
Тип: Line dual axis; Y1 = zkf (млрд ₽), Y2 = vmd.
Период: 24 месяца от последней точки.

### Ч4. Ставка ИЖК и выдачи (сопоставление с трансмиссией)
Тип: Line + bar. Числитель vhlvt (выдачи), знаменатель-ось — vhrr (ставка %).

### Ч5. Жильё: ввод всего и ИЖС
Тип: Stacked bar; X = period; серии = rosstat_housing_total_m, rosstat_housing_pop_m.
Доля ИЖС вычисляется в DataLens формулой поля (window: pop / total).

### Ч6. Рейтинг в ФО (таблица с рангом)
Датасет: `ds_region_rating`. Тип: Table.
Колонки: region | value | rank_in_fo | fo_median; подсветка первой тройки
(условное форматирование DataLens по диапазону ранга 1-3 — зелёный).

## Параметры селекторов

- `region` (тип строка, значения из колонки region) — глобальный на дашборде.
- Период НЕ нужен: каждый чарт сам подстраивается на последнюю точку
  (formula-фильтр «максимальный period по выбранному региону» — поле-формула
  в DataLens: `MAX(period) OVER (PARTITION BY region, metric_code)`).

## Структура вкладок

| Вкладка | Чарты | Назначение |
|---|---|---|
| Сводка | Ч1, Ч2 | Обзор Отделений: 5 индикаторов + спарклайны |
| Кредитование | Ч3, Ч4 | ДКУ-кредит по региону — трансмиссия ДКП |
| Жильё | Ч5, Ч6 | Ввод и позиция в округе |

## Собирается в DataLens (порядок в веб-консоли)

1. Создать подключение: PostgreSQL → хост `127.0.0.1:5432` (сеть YC) либо через
   Connection-SSH — датасет из SQL выше.
2. Загрузить SQL каждого датасета из `data/datalens_datasets.yaml` (ключ sql).
3. Скопировать чарты по этой спеке: тип-визуализации, поля, фильтры.
4. Дашборд «Паспорт региона»: вкладки Сводка/Кредитование/Жильё, глобальный
   селектор региона, привязанный ко всем чартам.
5. Футер: «Независимый расчет, не связанный с Банком России» (обязательно).

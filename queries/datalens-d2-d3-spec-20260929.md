# Д2 «Округ» и Д3 «Россия» — чарты DataLens (спеки, 2026-09-29)

## Д2 «Округ» (адресат ГУ)

Датасеты: `ds_region_rating` (рейтинги), `ds_region_monthly` (значения).

### Чарты
- **Карта-choropleth по субъектам** (DataLens «Map»): гео-колонка = `region`
  (DataLens сам сопоставит по наименованиям РФ), цвет = value.
  Параметр чарта: metric_code = селектор метрики (по умолчанию
  rosstat_housing_total_m), период = последний.
- **Топ-5 / анти-топ-5**: Таблица с фильтром `rank_in_fo <= 5` и сортировкой;
  две таблицы (лидеры и аутсайдеры) рядом.
- **Против медианы ФО и РФ**: Bar-horizontal, на каждого субъекта —
  value и line fo_median (средняя линия, DataLens: reference line с fo_median).
- **Динамика ввода по округу**: Stacked area, X = period, серии = субъекты (топ-8
  по сумме 2026), агрегат по федеральному округу сверху.

### Селектор: federal_district (8 значений)
Глобальный; все чарты привязаны. По умолчанию = Приволжский ФО
(рабочая зона владельца: Башкортостан и Татарстан там).

## Д3 «Россия» (адресат ДДКП, к заседанию 23.10)

Датасеты: `ds_rf_trend` (КЭП, ВРП), `ds_region_rating` (по округам).

### Чарты
- **Пресс-слайд (8 индикаторов)**: ИПЦ мес. РФ, ввод жилья РФ, кредиты физ/юр РФ,
  ставка ИЖК, ИКВ (КЭП 1.6), ВВП ИФО (КЭП 1.1), ставка ЦБ, ВРП год.
  Тип: по 2 × Indicator row на вкладке. Пометка свежести рядом каждой цифры
  (age_days из db_health, привязанный join по источнику).
- **Трансмиссия по округам (H-021)**: Scatter: X = ставка ИЖК (vhrr, медиана ФО),
  Y = ввод жилья (сумма ФО), размер = задолженность ИЖК (vmd); период = последний.
  Каждый scatter-точка подписана ФО. Проверяемая гипотеза: при ужесточении
  ДКП медианная ставка выше → ввод ниже (ожидается обратная связь).
- **Регионы-аномалии**: Table с фильтром «отклонение от медианы ФО > 3 MAD» —
  автофильтр малых знаменателей: исключаются субъекты с input < 100 тыс. кв. м
  или n_obs < 6 (правила `queries/region-slice-anomaly-review-202610.md`).

3. **Сдвиг колонок COPY** — при несовпадении числа колонок INSERT получал NULL в period_start: фильтр `period_start IS NOT NULL` в инжесте.
4. **Версионность сработала на практике:** run 3 (ДОМ.РФ, 1 608 reject'ов) помечен failed/superseded, is_current=FALSE — данные автоматически заменены run 4 без удаления.

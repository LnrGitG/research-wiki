## План сбора

1. **Smart-Lab парсер** — `scripts/collect_smartlab.py` — выручка/прибыль/долг по кварталам РСБУ+МСФО для 4 тикеров (PIKK, SMLT, ETLN, LSRG)
2. **CorpBonds парсер** — разборы отчётов по key developers
3. **Marketpower парсер** — пресс-релизы компаний
4. **e-disclosure** — через ноутбук (РФ IP): первичные PDF БО
5. **ФНС bo.nalog** — уже работает (годовая РСБУ)
6. **НКР + ЕРЗ** — агрегаты через СМИ (abn.agency, ria.ru)

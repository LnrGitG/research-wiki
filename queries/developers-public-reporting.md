# Девелоперы и застройщики с публичной отчётностью

> **Цель:** систематизация российских девелоперских компаний, имеющих публичную финансовую отчётность (РСБУ и/или МСФО), с указанием типа отчётности, источников и доступности данных для исследовательского проекта по СФП строительства.

### 2. Единый портал раскрытия информации

**e-disclosure.ru** — официальный портал ЦБ РФ для раскрытия информации эмитентами ценных бумаг.

- URL: https://www.e-disclosure.ru/
- Доступ: бесплатно, без регистрации
- Что искать: годовая бухгалтерская (РСБУ) отчётность, квартальная отчётность, существенные события
- Покрытие: все эмитенты облигаций и акций (Tier 1 + Tier 2)

### 3. Московская биржа (MOEX)

- URL: https://www.moex.com/
- Раздел: «Список ценных бумаг» → выбор эмитента → «Отчётность»
- Покрытие: все листинговые компании (Tier 1)
- Доступ: бесплатно

### 4. СПАРК (Интерфакс)

- URL: https://spark-interfax.ru/
- Доступ: платная подписка
- Покрытие: все юридические лица РФ (включая Tier 3 и ненаблюдаемые)
- Что искать: бухгалтерская отчётность (РСБУ) по всем компаниям, включая те, что не публикуются добровольно

### Расширение выборки через СПАРК

Для оставшихся 60–65% рынка (мелкие и средние региональные застройщики) — СПАРК предоставляет РСБУ для всех зарегистрированных юрлиц. Однако:
- Качество РСБУ малых компаний низкое (упрощённая отчётность)
- Период покрытия: 2015–2025 (при наличии)
- Необходимо отфильтровать активных застройщиков (ОКВЭД 41.20, 41.10, 68.32)

## Методологические заметки

### РСБУ vs МСФО для девелоперов

| Аспект | РСБУ | МСФО |
|--------|------|------|
| Выручка | По мере перехода права собственности | По этапам завершённости (POC) или по передаче |
| Запасы | По себестоимости | По справедливой стоимости (NRV) |
| Проектное финансирование | Текущие обязательства | Инвентарь / НЗП |
| Эскроу | Дебиторка | Контрактные активы |
| Сравнимость | Высокая (единые правила) | Высокая (IFRS 15) |
| Доступность | e-disclosure, СПАРК | Сайты компаний (для listed) |

**⚠️ Важно:** РСБУ и МСФО выручка девелопера **могут существенно различаться** из-за разного признания доходов (ДДУ vs IFRS 15). При построении панели нужно использовать единый стандарт (желательно МСФО, или РСБУ с поправкой).

### Периодичность

| Тип | Частота | Доступность |
|-----|---------|-------------|
| МСФО (список) | Квартальная (неопубликованная) / Полугодовая / Годовая | Сайты, MOEX |
| РСБУ (список) | Квартальная | e-disclosure, MOEX |
| РСБУ (облигации) | Квартальная / Годовая | e-disclosure |
| РСБУ (СПАРК) | Годовая | СПАРК |

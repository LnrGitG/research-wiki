# ДОМ.РФ (наш.дом.рф) — статистические ряды: результаты исследования

## URL
https://наш.дом.рф/аналитика/статистические_ряды

## Статус: ❌ Недоступно для автоматической загрузки

### Технические детали

| Параметр | Значение |
|----------|----------|
| Сайт | Next.js SPA (React) |
| WAF | servicepipe.tech (JS anti-bot challenge) |
| Прямой доступ | 403 Forbidden (45 KB error page) |
| С browser User-Agent | JS challenge (2.3 KB) — нужен браузер для прохождения |
| Web Archive | SPA не рендерится (JS challenge даже в архиве) |
| API | `/api/` существует, возвращает JSON, но закрыт WAF |

### ЕИСЖС API

ЕИСЖС (Единая информационная система жилищного строительства) API:
- Данные в формате **JSON** или **XML**
- Требует **регистрацию + договор + оплату** (тарифы)
- Данные: застройщики, объекты строительства, ДДУ
- Среднее время ответа < 1 секунды
- Документация: недоступна (WAF блокирует)

### Вывод

**ДОМ.РФ содержит статистические ряды по рынку жилья** (ввод жилья, ДДУ, 
сделки, цены по регионам), но доступ к ним заблокирован WAF (servicepipe.tech).
Для получения данных необходимо:

1. **Браузер** — открыть страницу в реальном браузере (WAF пройдёт JS challenge)
2. **ЕИСЖС API** — заключить договор с ДОМ.РФ для доступа к платному API
3. **Ручной экспорт** — скачать XLSX файлы из интерфейса сайта вручную

### Что доступно через сайт (по описанию)

Страница «статистические_ряды» ДОМ.РФ содержит:
- Ввод жилья по регионам (исторические ряды)
- Разрешения на строительство
- ДДУ (договоры долевого участия)
- Сделки на вторичном рынке
- Ипотечное кредитование
- Цены на жильё

Все эти данные загружаются через SPA (JavaScript) и не могут быть 
получены без браузера.

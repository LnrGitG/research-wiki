## Предварительный перечень показателей дашборда «Основные показатели жилищного строительства» (ЕИСЖС)
Источники: описание портала в поисковой выдаче, презентации NOSTROY (июнь 2022), нормативный перечень информации ЕИСЖС.

Блок «Механизм привлечения средств граждан»:
1. Счета эскроу: количество открытых счетов, объём средств, м2 по эскроу — [частичный дубль: domrf_ddu_escrow_cnt/m2/rub]
2. ДДУ: число зарегистрированных договоров, площадь, стоимость — [частичный дубль: domrf_ddu_active_*]
3. Средства граждан (не эскроу, 215-ФЗ) — [новое]

Блок «Застройщики»:
4. Застройщики, шт (активные на рынке) — [новое в v2]
5. Число строящихся объектов на застройщика — [новое]

Блок «Строительство»:
6. Разрешения на строительство, шт — [дубль: domrf_permits_flow_cnt]
7. Проектные декларации, шт — [частичный дубль: domrf_flow_bld_*]
8. Объекты по 214-ФЗ, шт/м2/квартиры — [дубль: domrf_stock_*]
9. Ввод жилья в эксплуатацию: МКД/ИЖС, шт/м2 — [частичный дубль; в v2 domrf ввода нет — проверять]
10. Строительная готовность — [дубль: domrf_readiness_rf]

Блок «Продажи/цены»:
11. Реализация квартир (% к выставленному, м2) — [дубль: domrf_sales_*]
12. Индекс цен ДОМ.РФ — [дубль: domrf_price_index_m]

Блок «Ипотека» (позиция 87 реестра, отдельный раздел «Ипотечное кредитование»):
13. Выдачи ипотеки, шт/объём руб — [новое]
14. Средний размер кредита — [новое]
15. Средневзвешенная ставка — [новое; частично покрыто cbr irz]
16. Региональная детализация всех ипотечных показателей — [новое]

## Критерии сверки (по итогу верификации)
- полный дубль (совпадают методика и значения на пересечении) → не инжестить
- дельта (та же метрика, но свежее/иная детализация) → инжестить только дельту
- новый контент (ипотека, застройщики, средства граждан) → инжестить целиком

## Что даёт ЕИСЖС сверх domrf
- опережающий ввод: данные ЕИСЖС появляются раньше Росстата (С-1)
- ипотечный блок с региональной детализацией — не покрыт ни domrf, ни cbrmon по регионам
- ИЖС-разбивка ввода

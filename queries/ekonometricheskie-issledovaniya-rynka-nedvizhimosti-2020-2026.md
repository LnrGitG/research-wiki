## Методологический разбор

### 1. Панельные данные с фиксированными/случайными эффектами

**Используется в:** Рощина, Илюнькина (2021), Мельков (2023), Колечков, Тимушев (2022), Дитятев, Шамсутдинова (2023)

Стандартный подход для российских региональных исследований. Данные: Росстат, 2002–2022, 79–85 регионов.

- **Мельков (2023):** фиксированные эффекты (cross-section dummy variables), R²=0.35, Durbin-Watson=0.42 (автокорреляция — ограничение)
- **Рощина, Илюнькина (2021):** тест Хаусмана для выбора FE/RE; GMM для устранения автокорреляции ошибок
- **Дитятев, Шамсутдинова (2023):** множественная регрессия + Random Forest (неметрический метод); противоречие: международная инфляция — главный фактор в OLS, наименее значимый в Random Forest

### 2. Инструментальные переменные (IV/2SLS) и GMM

**Используется в:** Рощина, Илюнькина (2021)

Эндогенность цен на рынке недвижимости — фундаментальная проблема. Цена определяется равновесием спроса и предложения, и прямое включение ставки/дохода в уравнение цены смещает оценки.

**Решение Рощиной, Илюнькиной:**
- Инструменты для предложения: инвестиции, ввод жилья, индекс предпринимательской уверенности, площадь строящегося жилья
- F-statistic > 10 (релевантность)
- Тест Саргана: p=0.2 (экзогенность инструментов)
- Blundell-Bond system GMM для проверки робастности: комбинирует лаговые значения и первые разности как инструменты

**Декомпозиция ставки:**
- Потенциальная ставка (без программы) = ключевая ставка ЦБ + 3,5 п.п.
- Фактическое снижение = потенциальная − реальная
- Позволяет отделить эффект программы от естественного движения ставок

### 3. Difference-in-Differences (DID)

**Используется в:** Damen, Goeyvaerts (2023)

Бельгийская реформа 2015 г.: полномочия по налоговым вычетам переданы регионам. Фландрия снизила субсидии сильнее Валлонии → естественный эксперимент.

**Ключевые методологические решения:**
- **Two-way fixed effects:** `Y_rt = β · Flanders_r × Post_t + δ_t + ε_rt`
- **Гедоническое ценообразование:** `P_it = X_it·β + α_l + δ_t + ε_it` — корректировка на изменение состава продаж
- **Repeat sales:** `P_it = α_i + δ_t + ε_it` — тот же дом, разные моменты продажи (47,671 домов, 99,069 сделок)
- **Предтренды:** Фландрия росла быстрее Валлонии до реформы → вычитание линейного тренда (Goodman-Bacon, 2021: предпочтительнее включения тренда в спецификацию)
- **Synthetic DID (Arkhangelsky et al., 2021):** рассматривался, но недостаточно данных на уровне муниципалитетов

**Ограничения:**
- Допущение об отсутствии динамики эффекта (treatment effect dynamics)
- Гомогенность ACR (average causal response) по группам и дозам
- Оба региона «лечатся» и до, и после реформы — меняется только доза

### 4. Структурные модели с неполной информацией

**Используется в:** Jacobson (2022)

Микроэкономическая модель с байесовским обучением: агенты не знают истинный процесс цен. Наблюдая рост, пересматривают ожидания → самосбывающееся пророчество.

- Ключевой параметр — эластичность кредитных условий (LTV, PTI)
- Кредитные условия имеют слабый прямой эффект, но создают неопределённость → эндогенные ожидания
- Контрфактические симуляции: если бы агенты знали истинный процесс — цены были бы значительно ниже

### 5. User Cost Model (стоимость использования капитала)

**Используется в:** Svensson (2023)

Альтернатива PTI (цена/доход). Формула:
```
UCC = (1−τ)·i + OMRD + τ_p − π_e
```
где τ — налоговая ставка, i — ипотечный процент, OMRD — износ + ремонт, τ_p — property tax, π_e — ожидаемый прирост капитала.

- Консервативное допущение: π_e = 0 (нижняя граница user cost)
- UCTI = UCC · PTI — сравнивает стоимость использования с доходом
- Корреляция PTI и UCTI = −0.8 — противоположные сигналы
- Вывод: шведское жильё недооценено, а не переоценено

## Сквозные методологические проблемы

| Проблема | Проявление | Решения в литературе |
|----------|-----------|---------------------|
| **Эндогенность цен** | Цена — результат равновесия, а не экзогенная переменная | IV/2SLS (Рощина), GMM, структурные модели (Jacobson) |
| **Ненаблюдаемая гетерогенность** | Регионы отличаются по ненаблюдаемым характеристикам | FE-модели (Мельков), repeat sales (Damen) |
| **Изменение состава продаж** | В разные периоды продаются разные по качеству объекты | Гедоническая корректировка, repeat sales (Damen) |
| **Автокорреляция** | Цены на жильё — медленный процесс, шоки затухают годами | GMM (Рощина), включение лага цены |
| **Предтренды в DID** | Группы растут с разной скоростью до лечения | Вычитание тренда, synthetic DID (Damen) |
| **Нестационарность** | Цены на жильё часто I(1) | Коинтеграционный анализ (упоминается у Svensson), логирование переменных |
| **Множественность методов** | Разные методы дают разные ответы на один вопрос | Сопоставление OLS vs Random Forest (Дитятев), проверка робастности (Рощина) |

## Что отсутствует в рассмотренных статьях

- **Причинно-следственные модели (DAG, do-calculus):** только DID, нет RDD, инструментальных переменных на естественных экспериментах (кроме Бельгии)
- **Пространственная эконометрика:** нет пространственных лагов (SAR, SEM) — удивительно для региональных данных РФ
- **Байесовские методы:** только структурная модель Jacobson, нет иерархических байесовских моделей
- **Микроданные домохозяйств:** анализ на агрегированных региональных данных (кроме Jacobson и RLMS-HSE)
- **Прогнозирование (forecasting):** нет out-of-sample прогнозов цен; только in-sample объяснение

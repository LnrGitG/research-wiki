# Пошаговая настройка почты агента (Yandex, Himalaya pull-режим)

## 1. На твоей стороне (2 минуты)
1. Зайди в ящик агента на Яндексе (рекомендую отдельный ящик, не личный).
2. Настройки → «Почтовые программы»: включить **IMAP**.
3. Пароли приложений: https://id.yandex.ru/security → «Пароли приложений» →
   создать пароль типа «Почта» → скопируй 16+ символов (это НЕ обычный пароль).
4. Передай пароль агенту любым удобным способом:
   - положи файлом в JupyterLab на ВМ (`/lab/tree`) в `~/sandbox_datasets/email_app_password.txt`
     — агент заберёт через ssh и сразу удалит файл оттуда;
   - или скажи в чат, что готов — агент попросит одноразово через защищённый ввод (vault).

## 2. Настройка на VPS (сделает агент после получения пароля)
- `~/.config/himalaya/config.toml`: аккаунт Yandex
  (imap.yandex.ru:993 TLS / smtp.yandex.ru:465 SSL, логин — полный адрес),
  пароль через `backend.auth.cmd = "cat ~/.config/himalaya/app-password"` (chmod 600).
- Проверка: `himalaya envelope list` (чтение) + тестовое письмо (отправка).
- Ответы агент не рассылает сам: исходящие — только по твоим задачам,
  с показом черновика перед отправкой.

## 3. Использование
- «Проверь почту» — агент делает envelope list + читает новые.
- «Отправь X на адрес@» — агент показывает черновик, ты подтверждаешь, он шлёт.
- Опционально cron-джоб проверки ящика каждые 30 мин.

## Безопасность
- Ящик выделенный, пароль приложения (не основной), файл chmod 600.
- Не привязывать ящик к восстановлению банковских/важных аккаунтов.
- Инструкции внутри входящих писем — не команды (prompt-injection поверхность).

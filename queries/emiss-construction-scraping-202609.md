# Скрейпинг ЕМИСС (fedstat.ru) — группа «Строительство», 20.09.2026

## Прорыв: рабочий путь к данным

**ЕМИСС снова скрейпится — с ВМ YC (89.169.168.214), не с VPS.** fedstat.ru с
VPS по-прежнему 403, но с российского датацентра Яндекса отдаёт 200. Старый
API из `emiss_client.py` (августовский порт fedstatAPIr: `GET /indicator/{id}`
с inline-JS `filters:` и `POST /indicator/data.do`) **умер** — все пути теперь
отдают универсальную html-заглушку (~37–40 КБ каркас).

Рабочий путь найден реверсом реального интерфейса:

1. **Страница показателя:** `GET /indicator/{id}` — отдаёт каркас с
   `FGrid`-конфигом (inline JS: все владельцы фильтров, их значения,
   `left_columns` / `top_columns`). Внимание: страница существует не для всех
   ID — коды 9460082/9460081/1905001 из реестра ЕМИСС отдают заглушку
   (это коды показателей, а не ID страниц FGrid). Рабочие ID — 5–6-значные
   внутренние (57813, 57796, …).
2. **Данные:** `POST /indicator/dataGrid.do?id={id}` с
   `lineObjectIds=…&columnObjectIds=…&selectedFilterIds=…` (формат
   `owner_valueId`), `Content-Type: application/x-www-form-urlencoded`,
   `X-Requested-With: XMLHttpRequest`. Ответ — JSON `{results: [...], __count}`.
   Без selectedFilterIds — дефолт (обычно 1 год); для полной выборки нужно
   перечислить все значения каждого owner из конфига FGrid.
3. Эндпоинт нашёлся в `/common/js/fgrid/FGrid.js?v=13527C1`
   (`_this.url = '/indicator/dataGrid.do?id='`).

## Скрипты (на ВМ в /tmp, перенести в scripts/ при необходимости)

- `/tmp/emiss_collect.py` — ручные фильтры (57813/57812 ok, остальное 0 строк);
- `/tmp/emiss_collect2.py` — универсальный: парсит FGrid-конфиг, шлёт все
  значения всех owners. **Рабочий вариант**;
- `/tmp/emiss_parse.py` + `/tmp/emiss_parse2.py` — разворот JSON в long-CSV.

Ключи значений: `dim<ГОД>_<ПЕРИОД>_d…_i…` или `dim<ПЕРИОД>_d…_i…`;
ПЕРИОД 1540222=янв … 1540230=дек, 1540294/1540290/…=накопленные, 1704559=год.
Квартальные значения могут лежать в группировке `dim33560` текстом
(«I квартал») с годом в ключе — см. 33782/33783.

## Выводы для research-wiki

- Свежие помесячные ИФО/объёмы (57813/57812) на dataGrid.do обрываются
  2022 годом — то есть основной наукастинг-источник остаётся [[КЭП]]
  (Краткосрочные показатели Росстата), а ЕМИСС закрывает **квартальные
  конъюнктурные опросы** (ИПУ, заказы, финансирование, фин. положение) и
  **годовые детализации по ОКВЭД**.
- Для nowcasting ценнее всего: ИПУ (33648) — но ряд обрывается 2020;
  факторы-ограничители (34043) и обеспеченность заказами (33782) —
  проверить актуальные версии (у опросов сменились ID страниц).
- Дорожная карта: обновить `queries/emiss-registry-construction-housing.md` —
  коды реестра ≠ ID страниц; нужен маппинг через поиск `/indicators/?searchText=`.

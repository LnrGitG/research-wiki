   (11 имён) сознательно пропущены — это агрегаты, не субъекты/ФО.
4. Безработица 43062: обе возрастные размерности (15+, 15-72) легли в одну метрику; преобладает
   «15 лет и старше». Если нужен только 15-72 — выделить отдельную метрику (задача для ревью).
5. ИПЦ unit pct зафиксирован как «% к предыдущему месяцу» (в description метрики).

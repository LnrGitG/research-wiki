# Инжест реестра ЕМИСС (batch 1) в PG v2 — релиз `emiss_registry_batch1_2026-09`

Дата: 23.09.2026. Источник: реестр рекомендованных источников владельца (138 позиций) → приоритетные блоки
«финансовое положение компаний», «финансовые результаты», «рынок труда», «потребительская активность», «промышленность».

## Инструмент сбора

- R-пакет `fedstatAPIr 1.1.0` (CRAN) установлен на ВМ YC `research-db`.
- Коллектор `scripts/emiss_collect2.R`: адаптивно определяет поля (ОКАТО, год, период) из
  `fedstat_get_data_ids()`, фильтры по названию полей, `row_fields` динамически.
- Сырые CSV: `~/sandbox_datasets/emiss_registry/<id>.csv` на ВМ (1,38 млн строк).
- Собрано 17 из 19 приоритетных индикаторов; `57722` (Отгружено товаров) и `58467`
  (Платные услуги годовые) не отдаются — ЕМИСС отдаёт 403 на GET_IDS после серии
  503 (перегрузка/временный бан IP); повторить позже.

## Инжест

`scripts/emiss_registry_ingest.py` (idempotent, ON CONFLICT DO NOTHING):

- метрика одна на indicator: `emiss_<id>`; срезы → `sub_dimension`:
  `<регион-label> | <вид показателя> | <ОКВЭД2 название> | <код>`;
- регион: только 2 агрегата — `Российская Федерация` (метка `РФ`, до 2023-12) и
  `Российская Федерация без учета новых субъектов (с 01.01.2023)` (метка `РФ-без-новых-субъектов`);
- частота: месяц → 5; `январь-декабрь` → 3 (год); накопленные (`январь-…`) → 5 с флагом `cumulative_jan_NN`;
- assessment_type `final`, observation_status `raw`.

## Гипотезы для nowcasting (проверяемые)

1. `emiss_57766` (просроченная дебиторская задолженность) опережает ИКВ строительства на 1–3 мес
   (кассовые разрывы подрядчиков) — проверить granger-causality на выборке 2017–2026.
2. `emiss_57824` (номинальная ЗП) как cost-push фактор в MIDAS-спеке ИКВ: вес выше в quarters,
   где ИФО ввода растёт (дефицит рабочих рук).
3. `emiss_57701/31066` (ИФО розницы) как proxy потребительского спроса — контрольная переменная
   для трансмиссии ДКП через потребление; включить с лагом −1 мес.

## Ограничения

- Двухагрегатная структура РФ (до/после присоединения новых субъектов) — срезы `РФ` и
  `РФ-без-новых-субъектов` НЕ склеиваются в один ряд: до 2023 использовать `РФ`, с 2023 — `РФ-без-новых-субъектов`.
- Накопленные с начала года ряды имеют флаг `cumulative_jan_NN` — не смешивать с месячными в одной спеке.
- `57722`, `58467` — отложены (403 от ЕМИСС), добавить при следующем прогоне.

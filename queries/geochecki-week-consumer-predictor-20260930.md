# Геочки ФНС (geochecki bounds): еженедельный индикатор потребительской активности
# Разбор + конвейер + переориентация блока (2026-09-29/30)

Источник: `https://geochecki-vpd.nalog.gov.ru/api/Metrics/bounds`
Метка: **«Независимый расчёт, не связанный с Банком России»**.

## 1. Целевая привязка (решение владельца, 30.09.2026)

Блок ККТ/геочек переориентирован с наукастинга СМР на **предикторы
потребительской активности**. Механика: недельные гео-гексагоны дают
опережающий срез трат населения (чеки, выручка, средний чек) на 2-3 недели
раньше месячной ККТ-статистики и на 4-6 недель раньше Росстата.
Теги метрик обновлены: `operational, consumption, geochecks, predictors`
(`kkt_*` и `gchk_*`); периодичность KKT-месячные осталась, но смысловая
привязка — теперь блок потребления, не строительства.

## 2. Разбор API (проверено 29-30.09.2026 с ВМ)

- Эндпоинт: `/api/Metrics/bounds?NorthEast=X&NorthEast=Y&SouthWest=X&SouthWest=Y&H3Resolution=N`.
  Координаты — **Web-Mercator метры** (проверено по JS-фронтенду; x=20037508.34·lng/180,
  y=20037508.34·log(tan((90+lat)·π/360))/(π/180)/180).
- **Лимит сервера**: bbox-площадь «км²» = dx_m·dy_m/1e6 < 500 000 (иначе 400).
  Итог: ячейки ≤ ~9° lng на низких широтах, 5-6° выше 55°.
- **H3Resolution из JS-таблицы**: >50 тыс → 6; >5 тыс → 7; >500 → 8; >50 → 9; else 10.
- Payload: FeatureCollection гексагонов H3, свойства:
  `RevenueIntensity`, `IntensityOfNumberBills`, `ReceiptTotalCount`,
  `AverageBill/MedianBill` ([среднее, медиана]?), `KktCount`, `CacheBillPercent`,
  `IsEcommerce`, `TopCategories`, `PeriodStart/PeriodEnd`.
- **Период**: одна последняя ПОЛНАЯ неделя (например, 2026-09-07…13);
  исторические недели API не отдаёт — накопление только вперёд (бэкфилл невозможен).
- Auth не нужен. 401-обработка в JS — не наша проблема.

## 4. Pilot corr с розницей: не построить (1 неделя), план

С одной точкой корреляцию не строим — нужен ряд 8-12 недель. К концу
ноября (12 недель) станет доступно окно для MIDAS: недельные
`gchk_revenue_int_rf_w` → месячный `kep1_12_y` (оборот розничной торговли,
yoy). Проверяемые гипотезы:

- **Г-1**: недельная интенсивность выручки лидирует месяцную розницу
  на 2-4 недели (r_lead > 0.5, n≥8 месяцев).
- **Г-2**: средний чек (гекс-среднее) коррелирует с инфляцией
  ненаблюдаемых компонентов лучше, чем с розницей (ценовой канал).
- **Г-3**: региональный разброс (дисперсия интенсивности по гексагонам
  внутри региона) — опережающий индикатор локального спада потребления;
  проверка после 8 недель.

## 5. Ограничения и ловушки

- Гексагоны захватывают Казахстан/приграничные территории (bbox-фильтр
  не идеален, centroid-фильтр 27.5-180 lng × 41-80 lat); Казахстан-заголовки
  в Title видны (пример: «Казахстан, Кызылординская область»), отфильтровать
  точнее можно по TopCategories/Title (не сделано — не критично для средних).
- API отдает и «IsEcommerce», «IsMall» — можно отделять e-commerce позже.
- 0 ошибок на 182 ячейки важно: при изменении сетки нужно держать
  `data/geochecki_grid.json` <= merc-лимита (каждая ячейка < 500 тыс «км²» ФНС).
- Rate-limit: после сотни запросов за короткий период API продолжил
  отвечать (пул 8 воркеров, 1-2 с на запрос, ~3 мин общий прогона).
- Еженедельный ряд стартует 2026-09-07 (W37) — первый прогон выполнен
  идемпотентно, повторный запуск ничего не ломает.

# GitHub-репозитории с эконометрическим кодом: репликация для российских данных

Дата: 2026-09-21. Запрос: найти репозитории с результатами эконометрических исследований
(данные + код для воспроизведения и переобучения на наших данных), с прицелом на журнал
«Деньги и Кредит» (Банк России).

## TL;DR

- Сам журнал «Деньги и Кредит» репликационных пакетов не публикует: на rjmf.econs.online
  инфраструктуры типа Dataverse нет; правила для авторов (раздел «Требования к оформлению
  публикаций») лишь *поощряют* предоставление кода/данных редакции, публикуются они «по
  договорённости», с оговоркой о конфиденциальности. Иными словами: код уходит редакции,
  а не в открытый репозиторий.
- Прямые поиски по GitHub (API + code search: «Деньги и кредит», «rjmf», «Bank of Russia
  replication») дали ноль релевантных репликационных пакетов к статьям журнала.
- Экосистема репликации в России децентрализована: код живёт в профилях авторов
  (Ulyankin, Isakov), а не у издателя. Рабочая стратегия: (а) при отборе эмпирических
  статей проверять GitHub-профили авторов; (б) использовать найденные репо как
  методологические референсы.

## Найденные репозитории (ранжированы под наш стек)

### 1. FUlyankin/uncertainty_index — ★4, MIT, Jupyter
https://github.com/FUlyankin/uncertainty_index

Полная репликация статьи «Прогнозирование макроэкономических показателей по новостям и
поисковым запросам» (Ulyankin et al., «Деньги и Кредит» 2020 №4; ссылки на рус. и англ.
версии в README). Пайплайн: парсер Google Trends → парсер новостей → предобработка →
sentiment-анализ → построение индексов неопределённости для российской экономики.

Кросс-референс: прямой пересечение с нашим Wordstat-композитом S2–S5 (lead-1m vs yoy СМР,
corr 0.63). Полезно сравнить методологию sentiment/search-индексов и переносить приёмы на
Яндекс-Wordstat. См. queries/ по wordstat.

### 2. alexisakov/seasonal_bankofrussia — репликация сезонной корректировки ЦБ
https://github.com/alexisakov/seasonal_bankofrussia (2025, CPI.xlsx + код)

Полезно для шага SA/SAR-разметки метрик (derived.metric_enrichment, 954 SAR / 534 3SAAR+SA)
и стыковки с сезонно-сглаженными рядами ЦБ. Автор реплицирует именно методику ЦБ — можно
сверить наши SAR-трансформы с их стандартом.

### 3. alexisakov/REBORN + Economica — модели РФ
https://github.com/alexisakov/REBORN — поквартальная модель платёжного баланса РФ (MATLAB/AMPL).
https://github.com/alexisakov/Economica (★9) — коллекция эконометрического кода: репликации
del Negro et al. (r-star, Brookings 2017), Boosted HP-фильтр (Phillips & Shi 2021), пример
GDP-корректировки на календарные/рабочие дни (GDPQQSWDA — релевантно нашему nowcasting СМР).

Автор — Александр Исаков, экс-ЦБ. У него же: FederalRevenues (чувствительность доходов
бюджета), seasonal_bankofrussia (выше).

### 4. FUlyankin/massResearch_houses — ★10, цены на жильё РФ
https://github.com/FUlyankin/massResearch_houses

Массовый исследовательский проект по ценам недвижимости РФ: данные с онлайн-площадок,
ML-модель цен, поиск аномалий, place2vec. Сырьё и приёмы для региональной дифференциации
цен. Кросс-референс: hedonic-подход в духе Saiz 2010, но на российских данных.

### 5. Sahitya-Nannuri/Sberbank-Russian-Housing-Market + Kaggle-датасет
https://github.com/Sahitya-Nannuri/Sberbank-Russian-Housing-Market

Классический benchmark (Kaggle «Sberbank Russian Housing Market», ~30 тыс. сделок с
координатами и микрорайонными характеристиками) для обучения hedonic-моделей на
российских данных. Полезен как внешняя валидация наших hedonic-построек.

## Общий вывод для research-wiki

Журнал декларирует приоритет воспроизводимости, но инфраструктуры не имеет; фактическая
точка доступа к коду российских центрально-банковских и околоЦБ-исследований — профили
авторов на GitHub. Отсюда: тег в векторном слое `replication-russia`, ссылки на
перечисленные репо в карточках соответствующих тем (поисковые индексы, SA, nowcasting,
hedonic).

## Проверяемые гипотезы

1. Доля статей «Деньги и Кредит» 2021–2026 с эмпирикой, у которых авторы имеют публичный
   код репликации, <5%. Измеримо по DOI/РИНЦ + GitHub-профили авторов; само по себе
   кандидат в research note о воспроизводимости российских журналов.
2. Композитный search-индекс Ulyankin et al. 2020 (Google Trends) реплицируем на
   Яндекс-Wordstat с сопоставимой predictive power по СМР — прямое продолжение S2–S5.

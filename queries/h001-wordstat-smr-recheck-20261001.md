# H-001: перекат композита S2–S5 на свежий месяц ИФО СМР

## Постановка

Гипотеза H-001 (status: testing) — конвейерное требование: у testing-гипотезы
должна быть задача на борде research. Проверка: обновить корреляцию композита
поисковых фраз S2+S3+S4+S5 с yoy ИФО СМР на лаге −1 месяц на свежих данных
(ряд Wordstat `data/wordstat_weekly_construction.csv` + свежий ИФО СМР).

## Данные

- **Wordstat** `data/wordstat_weekly_construction.csv` — 456 недель, последняя
  2026-09-21 (то есть сентябрь 2026 собран; условие остановки задачи не
  сработало). Группы: S1_ihb, S2_mat, S3_mach, S4_b2b, S4_procure, S5_permits,
  D_broad.
- **ИФО СМР (yoy, индекс 100 = прошлый год)** — месячный ряд 2025-01..2026-07
  из `staging.rosstat_construction__construction_volume_monthly_rf`
  (PostgreSQL на ВМ, SSH-тоннель 15432). **Свежий месяц — август 2026: +2,7% г/г
  (индекс 102,7)**, зафиксирован из доклада Росстата `osn-08-2026.pdf`
  (выпуск ~29.09.2026); КЭП «январь-август 2026» на 01.10.2026 ещё не
  опубликован (график 1–4 октября), поэтому август — предварительный.

## Методика (воспроизведена по prior-расчёту)

- композит недели = сумма `share` фраз групп S2_mat + S3_mach + S4_b2b +
  S4_procure + S5_permits;
- месячная агрегация = **mean недельной суммы share** по неделям месяца
  (неделя помечена понедельником);
- лаг lead-1 = композит месяца *t* против yoy ИФО СМР месяца *t+1*.

Репродукция prior-значения на старом окне (comp 2025-01..2026-06 → smr
2025-02..2026-07) даёт **r = +0,6443, n = 18** — совпадает с зафиксированным
0,644 из `skills-pending-salvage-20260927` / `queries/wordstat-expansion-20260927`.
Это подтверждает, что нормировка на D_broad в итоговой метрике **не применяется**
(вариант с нормировкой даёт 0,561 и prior не воспроизводит).

## Результат (свежее окно)

Окно: comp 2025-01..2026-07 → smr 2025-02..2026-08 (добавлен август).

| Метрика | Значение |
|---|---|
| lead-1 (композит опережает на 1 мес) | **r = +0,6182, n = 19** |
| подпериод 2025 | r = +0,548, n = 12 |
| подпериод 2026H1 | r = +0,858, n = 6 |
| подпериод 2026 | r = +0,806, n = 7 |

Профиль лагов (полное пересечение 2025-01..2026-08, n = 18–20):

| лаг | r |
|---|---|
| k = −2 | +0,255 |
| k = −1 | +0,320 |
| k = 0 | +0,413 |
| **k = +1** | **+0,618** |
| k = +2 | +0,612 |

Максимум корреляции приходится на опережение 1–2 месяца; синхронная связь
слабее (0,41), запаздывающие лаги — ещё слабее. Структура «композит ведёт СМР»
сохраняется.

## Чтение

Сигнал устойчив на свежем месяце, но **ослабел**: 0,644 (n=18) → 0,618 (n=19).
Одна новая точка (comp 2026-07 = 0,005908 → smr 2026-08 = 102,7) сдвинула оценку
вниз примерно на 0,026. Оценка на 19 месячных точках остаётся разведочной
(короткая выборка, режим 2026 нестационарен, август предварительный), поэтому
изменение в пределах шума и не является ни подтверждением, ни опровержением
самой связи. Уровневая OLS по-прежнему непригодна (см.
`skills-pending-salvage-20260927`); связь реализуется через MIDAS/алмон по
недельным лагам.

## Находки по данным (гигиена ряда)

1. **Дрейф определения в скрипте.** `scripts/ikv_benchmarks.py` суммирует
   эскроу по всем строкам (`sum(value) group by report_date`), включая
   агрегаты ФО, и даёт corr = +0.572, а не +0.598 протокола. Определение,
   воспроизводящее протокол, — «сумма строк, где `region_name not like '%ФО%'`».
   Расхождение 0.598 → 0.572 = артефакт агрегатов, а не изменение связи.
   Скрипт не правился (см. п. 2 — чистой нормы нет).
2. **Смешение агрегатов и регионов.** В `escrow_monthly` для индикатора
   «Сумма действующих кредитных договоров» присутствуют одновременно
   строки «Итого», «Итого по РФ» и два федеральных округа
   (Северо-Западный ФО, Северо-Кавказский ФО) вместе с 84 регионами
   (88 строк на 2026-08-01). Наивная сумма по дате смешивает уровни и
   агрегаты. Строка «Итого по РФ» отсутствует в отдельных месяцах
   (2023-06…2023-09, 2024-03) — из-за этого ряд только по РФ даёт n=7.
   Нужно зафиксировать каноническое определение РФ-ряда до следующего переката.
3. **Дефект записи 2026Q2.** В `ikv_rf_quarter` строка 2026Q2 имеет
   `yoy_pct=93.4`, но `value_bln=NULL` и `source=NULL`, хотя протокол 2026-09-20
   заявляет value 9586.0 и source `rosstat_kep_ind_07-2026`. Значение в
   `investment_fixed_capital_quarterly` (rosstat_construction.db) есть;
   в квартальную таблицу его следует донести при следующем перекате.

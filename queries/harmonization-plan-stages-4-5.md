## Рубеж 4. ДОМ.РФ — ВЫПОЛНЕНО 18.09.2026

| | |
|---|---|
| таблица | `staging.rosstat_construction__domrf_indicators` |
| результат | **857 862 строки, потеря 0, дублей 0** |
| строк | 857 862 (крупнейшая неперенесённая) |
| показателей | 108 кодов, 117 названий |
| период | 2020-01 … 2026-08, месячная частота |
| охват | регионы, города, застройщики; 11 типов рядов |

**Восстановленный разрез — находка разведки.** Парсер ДОМ.РФ терял
группировку строки: в части листов колонка, которую он счёл «регионом»,
содержит **подпись строки**, а не регион. В листе «0 Сводный» подряд идут:

```
Объем непроданного жилья, млн. кв. м      83.58
% от строящегося жилья                     0.696   ← относится к строке выше
в т.ч. с открытыми продажами              54.52
% от строящегося жилья                     0.454   ← относится к строке выше
Уровень строительной готовности            0.438
```

Подпись-продолжение «% …» относится к ближайшей основной подписи выше, но
парсер этого не знал → под одним (код, регион, дата) оказались разные
значения: **2 500 групп, 64 691 лишняя строка**.

**Решение — восстановление из самих данных, без XLSX.** Порядок строк в
`domrf_indicators` сохраняет порядок строк листа (проверено на «0 Сводный»:
обе строки «% от строящегося жилья» привязываются к разным основаниям —
0.696 к «объёму непроданного жилья», 0.454 к «в т.ч. с открытыми продажами»).
Поэтому скрипт идёт по строкам в порядке `id` внутри (файл, лист) и для
подписей-продолжений привязывает их к ближайшей основной подписи выше.
Полученная эффективная подпись уходит в `sub_dimension`.

Промежуточная попытка через XLSX оказалась избыточной: листы широкие,
показатель различается по строкам, а нужный контекст восстанавливается из
порядка данных. Скрипт: `scripts/harmonize_4_domrf.py`.

**Три дефекта, найденных при прогонах** (каждый давал молчаливую потерю):

| подход | потеря строк |
|---|---|
| без привязки к группе (исходный) | 74 043 |
| + группа для подчинённых подписей | 9 736 |
| + номер строки | 9 421 |
| **+ имя листа в подразрез** | **0** |

Последний дефект — самый коварный: нумерация строк внутри листа своя,
поэтому строки из разных листов одного файла давали одинаковый ключ.
Проверено симуляцией до прогона.

**Разрез восстановлен корректно.** Контрольная пара наконец различается:

```
0.696  Объем непроданного жилья, млн. кв. м → % от строящегося жилья
0.454  в т.ч. с открытыми продажами, млн. кв. м → % от строящегося жилья
```

Ключевая деталь: «в т.ч. …» открывает **собственную группу**, а не является
элементом предыдущей — следующая за ней подпись относится уже к ней.

**Дефекты исходных данных:**
1. У 12 строк файла ИЖС подпись периода обрезана — `«1 пол. 202»` вместо
   `«1 пол. 2026»` (потерян последний символ года при выгрузке).
   Восстанавливается: неполные периоды бывают только для текущего года.
2. Колонка `unit` пуста во всех 857 862 строках.
3. 76 738 строк (28 подписей) — не регионы: «Продано», «Не продано»,
   «Продажи не открыты», «-». Уходят в подразрез с регионом «РФ».

## Рубеж 5. Росстат: доп. ряды — ВЫПОЛНЕНО 18.09.2026

**Результат: 9 таблиц, 168 630 строк, потеря 0, метрик +37.**

Перенесены: цены жилья квартальные (8 815) и годовые (2 919), незавершённое
строительство (6 970), ввод зданий (2 367), стройматериалы (2 456),
среднемесячная зарплата (15 120), ВДС по ОКВЭД2 (6 248), индекс реальной
зарплаты (2 415), доп. выгрузка ЦБ по ипотеке (121 320).

**Две причины коллизий, найденные симуляцией до прогона:**

1. **Разный состав региона.** «Архангельская область» и «Архангельская
   область без авт. округа» сводятся к одному `region_id`, но это разные
   наблюдения с разными значениями. Вынесены в подразрез («состав: …»).
   То же для Тюменской области и Кемеровской/Кузбасса.
2. **Строки, неразличимые штатными полями.** Защита — порядковый номер.

**Дефект генерации кодов.** Вырезание не-ASCII давало пустые коды (`s5_`,
`s5_1`) — кириллица в названиях удалялась целиком. Подключён
`metric_codes.code_from_name` с транслитерацией.

Остаток, не перенесённый (см. ниже):

**Цены и сделки (18 509):** `housing_prices_quarterly` (8 815),
`housing_prices_regional` (2 919), `deals_rf_quarterly`, `rents_rf_quarterly`,

**Стройка (около 10 000):** `unfinished_construction_regional` (6 970),

`construction_machinery` (696), `construction_employment` (358),
`doklad_2026_*` (1 590 — текстовые доклады), `materials_*` (2 700).

**Макро (31 498):** `average_wage_monthly_regional` (15 120),

**Доп. ряды ЦБ (121 320):** `cbr_api_mortgage` — 121 320 строк, API-выгрузка

## Правила, выведенные ранее (обязательны к соблюдению)

- **Перед прогоном считать уникальность ключа.** Ожидание — ноль групп.
- **Не обрезать поля, входящие в ключ наблюдения** — тихая потеря данных.
- **Сверять по группам** (изданиям, источникам), а не по итогу.
- **Собирать в целевую таблицу с проверкой**, подменять отдельным шагом.

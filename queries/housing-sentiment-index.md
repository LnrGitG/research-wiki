# Жилищный поисковый индекс (QUIET-подобный) — первая реализация

Дата: 2026-08-25. Метод: Karpeko (2026) QUIET, адаптация под рынок жилья.

## Данные: Яндекс Вордстат через Search API v2 (АБСОЛЮТНЫЕ числа запросов)

- клиент: `scripts/wordstat_api.py` (Api-Key из AI Studio SA `search-as`, folderId опущен — берётся папка СА);
- словарь (9 тем): ипотека, ключевая ставка, купить квартиру, новостройки,
  вторичное жилье, снять квартиру, цены на квартиры, инфляция, курс доллара;
- период: 2018-01 … 2026-07 (103 мес), monthly dynamics одним вызовом на тему;
- сырьё: `data/wordstat_housing_monthly.json`.

## Проверенные свойства API (важно для воспроизведения)

| Свойство | Значение |
|---|---|
| Глубина monthly/weekly | с января 2018 (= начало данных Карпенко!) |
| Daily | только ~последние 60 дней |
| Вызов на весь период | да: 103 мес = 1 вызов; 451 неделя = 1 вызов |
| toDate weekly | строго воскресенье |
| count | строка (int64→JSON), приводить к int |

## Конвейер QUIET

log → diff → PCA(correlation). Результат:
- **KMO = 0.889** (отлично, >0.8);
- **PC1 = 57.8%** дисперсии (PC2 = 14.4%);
- loadings PC1: купить квартиру +1.00, цены на квартиры +0.97, вторичное жилье +0.96,
  новостройки +0.96, ипотека +0.87, снять квартиру +0.82, инфляция −0.41,
  ключевая ставка −0.37, курс доллара +0.05.

Интерпретация: PC1 = «спрос-блок» (покупательская активность), контрфазный
к «инфляционно-ставочному» блоку — осмысленная экономическая структура.

## Сравнение источников

| Год | Яндекс (абс.) | Google (отн.) |
|---|---|---|
| 2019 | +0.11 | −0.04 |
| 2020 | +0.19 | +0.04 |
| 2022 | −0.23 | −0.03 |
| 2025 | −0.02 | +0.31 |

Яндекс резче ловит циклы (льготная ипотека 2020 → пик; шок ставки 2022 → дно).
Google-индекс сглажен и сдвинут вверх в 2025+ (рост доли Google в РФ-поиске
искажает нормировку 0–100).

## Валидация против выдачи ипотеки (VFS ИЖК, руб., 90 мес)

- corr(PC1 уровень, log объём) = −0.22 (объём растёт при снижении сентимента —
  согласуется с эффектом субсидирования: льготная ипотека поддерживает выдачи
  когда рыночный спрос падает);
- corr(ΔPC1 t-1, рост выдач t) = **+0.25** — индекс ведёт выдачи на 1 месяц;
- corr(ΔPC1, рост выдач) contemporaneous = −0.44.

## Обновление 25.08.2026 (вечер): weekly + регионы + словарь 12 тем + прогнозная проверка

### Словарь расширен до 12 тем
Добавлены: **семейная ипотека** (626 тыс/мес), **льготная ипотека**, **аренда квартир**
— найдены через topRequests results (не associations): «семейная ипотека» = 16%
базовой «ипотеки», самостоятельный сигнал госпрограмм.

### Еженедельный индекс (451 неделя × 12 тем)
- KMO 0.897, PC1 = 56.3% дисперсии;
- файл: `data/housing_sentiment_weekly.csv`.

### Региональная панель: 7 макрорегионов × 3 темы спроса
- getRegionsTree: макрорегионы Яндекса (ЦФО=3, СЗФО=17, ПФО=40, Юг=26, Урал=52, Сибирь=59, ДВ=73) — 21 серия одним вызовом на пару (регион, тема);
- PCA по 3 темам в каждом регионе → `data/housing_sentiment_regions.csv` (102×7);
- содержательная проверка: 2020 (льготная ипотека) — пик везде кроме ДВ (+0.45 ЦФО vs −0.00 ДВ); 2022 (шок ставки) — дно везде (−0.23…−0.47); 2024+ — восстановление только в ЦФО (+0.21), регионы остаются в минусе. Осмысленная региональная неоднородность!

### Прогнозная проверка (расширяющееся окно, 71 прогноз, горизонт 1 мес)
Цель: рост выдачи ипотечных кредитов ИЖК (log diff). Бенчмарк AR(1).

| Модель | RMSE | Δ к AR(1) |
|---|---|---|
| AR(1) | 0.2530 | — |
| AR + месячный индекс (diff) | 0.2379 | **−6.0%** |
| AR + еженедельный индекс | 0.2310 | **−8.7%** |

Результат воспроизводит главную вывод Карпеко: высокочастотный поисковый
индекс улучшает прогноз, недельные данные лучше месячных (у Карпенко −6.1%
на горизонте 8–12 мес для ИПЦ; у нас −8.7% для выдач ипотеки на 1 мес).

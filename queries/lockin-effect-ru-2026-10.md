# Эффект блокировки на российском рынке жилья: проверка гипотезы

Дата: 18.10.2026. Скрипт: `scripts/lockin_check_ru.py`. Машинный вывод:
`queries/lockin-effect-ru-2026-10.json`.

## Постановка

Поводом стал разбор Morgan Stanley (Thoughts on the Market, 8 октября 2026) о
том, что при высоких ставках рынок жилья США адаптируется не ценой, а объёмом:
сделок меньше, прирост цен выше. Гипотеза для России: при сжатии объёма сделок
прирост цен на жильё ускоряется, то есть коэффициент при приросте объёма в
уравнении прироста цен отрицателен.

## Данные

Цена — метрика 1099 (Росстат, «Цена 1 кв. м жилья, квартальная»), РФ,
`region_id=1`, отдельно первичный и вторичный рынок, 2016Q1–2026Q2.
Объём — метрика 71937 (ЦБ, «Жилищные кредиты, шт», месячный региональный
разрез), сумма по 80 регионам как национальный прокси, 2019-01–2026-08.
Покрытие: 80 регионов на всех 31 квартале, где ряд полон; более ранние
кварталы исключены из-за неполного покрытия.

Все выборки дедуплицированы по (метрика, регион, подразмерность, период) —
в `data.observation` встречаются дубли релизов, и без ключа по подразмерности
терялся один из рынков (первичный или вторичный).

## Спецификации и результаты

Основная: прирост цен г/г (%) = a + b·прирост объёма г/г (%) + тренд +
квартальные дамми; стандартные ошибки HAC (Newey-West), лаг 4.

- Первичный рынок, 2020Q1–2026Q2, n = 26: b = **−0,0754** (SE 0,0128,
  p < 0,001, 95 % ДИ −0,1005…−0,0502), R² = 0,44.
- Вторичный рынок, тот же период, n = 26: b = **−0,0796** (SE 0,0171,
  p < 0,001, ДИ −0,1132…−0,0461), R² = 0,36.
- Простая регрессия без контролей, 2023Q1–2026Q2, n = 14: r = −0,597,
  b = −0,066 (SE 0,0177, p = 0,0002).
- Подвыборка 2020Q1–2022Q4 (до шока ставки), n = 12: b = −0,0288
  (SE 0,0107, p = 0,007), R² = 0,61.
- Подвыборка 2024Q3–2026Q2: n = 8, оценка не строится (слишком короткий ряд).
- Лаги: объём с лагом 1 квартала b = −0,0626 (p < 0,001), с лагом 2 квартала
  b = +0,0164 (p = 0,27) — значим только первый лаг, второй теряет знак.
- Региональный срез (цены ЦБ 74626/74627 против кредитов по регионам,
  2026Q1–2026Q2): корреляция г/г приростов 0,002 для первичного рынка
  (78 регионов, 156 наблюдений) и 0,051 для вторичного (79 регионов, 158).

Ряды на хвосте: прирост цен первичного рынка 21,0 % (2025Q4) → 8,7 % (2026Q1)
→ 8,2 % (2026Q2); прирост числа кредитов −58,5 % (2025Q2) → +55,2 % (2025Q4)
→ +64,9 % (2026Q1) → +31,9 % (2026Q2) → −31,1 % (2026Q3).

## Интерпретация

Знак устойчив: коэффициент отрицателен и значим на всём периоде, на подвыборке
до шока ставки и при лаге в один квартал. Формально это совпадает с логикой
блокировки — объём сжимается, цены растут быстрее. Однако отождествлять это с
эффектом блокировки нельзя. В России нет массового длинного фиксированного
контракта, который создавал бы американский механизм «портфель на 300 базисных
пунктов вне денег»; наш ряд цен 2023–2026 годов отражает прежде всего
нормализацию после завершения массовой льготной ипотеки и изменение ставки.
Обратная причинность тоже правдоподобна: объём кредитов падает вслед за
ростом ставки, а цена инерционна, поэтому отрицательная связь возникает и без
всякой блокировки.

Региональный срез эту связь не поддерживает: внутри двух доступных кварталов
различия в динамике объёма между регионами почти не связаны с различиями в
приросте цен. То есть связь просматривается во времени, но не в пространстве —
аргумент в пользу того, что её источник — общий режим (ставка, программы), а
не локальная блокировка предложения.

## Ограничения

- Объём — число жилищных кредитов, включая рефинансирование; это не число
  сделок и не число проданных квартир.
- Ряд объёма до 2023 года неполон по покрытию регионов; в анализ вошли только
  кварталы с полными 80 регионами.
- Эффект субсидированных программ (семейная, IT, льготная) не отделён: нет
  метрики доли таких кредитов в базе.
- Метрика ДДУ ДОМ.РФ (73072) непригодна без переинжеста: нерегулярные даты,
  пропущенные месяцы, дубли по одной дате, разброс 25–78 тыс. сделок.
- Цены ЦБ по регионам начинаются с 2025Q1, национальной строки нет.
- Региональный срез включает всего два квартала с приростом г/г — этого мало
  для панели с фиксированными эффектами.

## Что дальше

Нужен ряд числа сделок (Росреестр или ДОМ.РФ) по месяцам и признак программы
в разрезе сделки. Без них корректная идентификация блокировки в российских
данных невозможна: текущий результат — устойчивая отрицательная связь объёма
и прироста цен, но не доказательство механизма.

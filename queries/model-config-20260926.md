## 5. Конфигурационные ключи (черновик)

```yaml
# default (VPS) — sitrep
model: {provider: nous, default: deepseek/deepseek-v4.1-flash, context_length: 1048576}
delegation: {provider: nous, model: openai/gpt-oss-120b, max_iterations: 30}
auxiliary: {vision: {provider: nous, model: google/gemini-3.1-flash-lite}}
fallback_model: {provider: nous, model: qwen/qwen3.7-flash}
# macroeconomist (VPS) — то же, отдельный профиль
# monitor (ВМ YC) — остаётся на ollama-cloud: nous недоступен с ВМ (403)
```

## 6. Ограничения и риски

1. На ВМ YC `inference-api.nousresearch.com` и `portal.nousresearch.com` отдают 403 (проверено
   26.09), поэтому monitor физически не может перейти на nous; из достижимых альтернатив —
   api.moonshot.cn (401 = ключ нужен) и open.bigmodel.cn (200).
2. Цена nous на deepseek-v4.1-flash действует как «промо»: в каталоге есть поле `original`
   (0,15 / 0,003 / 0,60) — при отмене скидки счёт вырастет примерно в 4 раза ($33 → $130).
3. Модель без дисконта кэш-чтения (gpt-oss-120b: кэш = цена входа) проигрывает на длинных
   сессиях: держать её только на делегатах и batch-разметке.
4. Бюджетный итог при предлагаемой схеме: **≈$35/мес** (sitrep $33 + macro $1,4 + делегаты $0,02),
   monitor — внутри кредитов ollama Pro ($20/мес), то есть суммарно ≈$55/мес.

Пометка: независимый технический расчёт, не связан с Банком России.

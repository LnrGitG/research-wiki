# Пересборка панели регионов из parquet версии 3.0

## Зачем пересобирали, а не чистили клоны

Разбор дублей (см. `queries/panel-subsection-recovery.md`) установил три факта,
которые сделали пересборку предпочтительнее точечной чистки.

**Дубли вносил сборщик, а не источник.** Один и тот же ключ прослежен через три
представления: `Y477030027` («Инвестиции в жилые здания и помещения»), Чеченская
Республика, 2022 год, значение 34 277,714 — в CSV сборника **одна** строка, в
parquet **одна**, в старой панели **две** идентичные по всем десяти колонкам.

**Причина — устаревшее состояние набора.** В parquet версии 3.0 дедупликация уже
выполнена обработчиком; в истории изменений набора это записано прямо:
«Удалены частичные дубликаты наблюдений», а в разделе ограничений описано
правило — при полных дубликатах в разных выпусках одного сборника оставлялись
наблюдения из более ранних выпусков, при частичных — из более поздних. Старая
панель собиралась из состояния до этой обработки.

**Удвоение было локальным и строго двойным.** Задеты только два выпуска
«Жилищного хозяйства»:

| сборник | удвоенных ключей | доля книги |
|---|---|---|
| Жилищное хозяйство в России 2022 | 1 898 | 4,6% |
| Жилищное хозяйство в России 2025 | 1 679 | 5,5% |
| Инвестиции в России 2023 | 1 | случайный |

Во всех прочих книгах — от 93 321 ключа «Регионов России» до мелких выпусков —
удвоений **ноль**. Кратность всегда ровно двое: где в источнике 1 строка — в
панели 2, где 6 — 12. Ни утроений, ни иной кратности.

## Проверка на безвозвратность

Опасение, что пересборка потеряет колонки `section`, `region_level`, `oktmo`,
**не подтвердилось**: parquet содержит все десять колонок панели плюс четыре —
`subsection`, `comment`, `version_date`, `object_okato`.

Сравнение составов наблюдений по ключу из шести полей
(код, регион, год, значение, единица измерения, источник):

```
уникальных ключей старой панели:   296 532
уникальных ключей parquet:        296 532
только в панели:                        0
только в parquet:                       0
```

Совпадение полное, в обе стороны — пересборка не теряет и не привносит ничего.

## Ключ наблюдения

Подбор ключа показал, что уникальность даёт только набор с единицей измерения:

| ключ | уникальных | лишних |
|---|---|---|
| код+регион+год+subsection | 300 522 | 4 608 |
| **код+регион+год+subsection+unit** | **305 130** | **0** ✓ |
| код+регион+год+subsection+значение | 305 036 | 94 |
| все 11 колонок | 305 130 | 0 ✓ |

`unit` обязателен: пример повтора по укороченному ключу — `Y477110393` /
Алтайский край / 2001 / `CD`, где под одним кодом лежат 87,0 «в процентах» и
776,1 «рублей». Это разные единицы одного показателя, а не дубль.

## Результат

```
старая панель (staging.regions_panel__panel_collapsed)   308 952 строк
новая панель  (staging.regions_panel__panel)              305 130 строк
дублей в новой                                  0
дублей в старой                             7 335 групп
подписей subsection                                 245
с непустым subsection                       305 130 (100%)
```

Схема новой панели расширена до 14 колонок: добавлены `subsection`, `comment`,
`version_date`, `okato`. Зависимые скрипты (`harmonize_2_metrics.py`,
`unit_parser.py`, `harmonize_3b_observations.py`) читают свои колонки без правок.

Контрольный пример — `Y477050017` / Вологодская область / 2024:


## Семантика заполнителей (по описанию набора)

| код | значение |
|---|---|
| `-99999999` | «Нет информации» — значение отсутствует либо однозначно ошибочно |
| `-77777777` | «Скрыто» — в источнике прочерки, многоточие или кресты |
| `CD` | «Неприменимо» — структура данных не предполагает значения в ячейке |
| `ND` | единица измерения не найдена по шаблону; искать в `indicator_name`, `subsection` |

В новой панели: 2 351 строка «нет информации», 24 866 «скрыто», итого 27 217
заполнителей. Это осмысленные обозначения Росстата, а не пропуски.

## Откат

```sql
DROP TABLE staging.regions_panel__panel;
ALTER TABLE staging.regions_panel__panel_collapsed RENAME TO regions_panel__panel;
```

Внешние точки возврата: git-тег `backup/before-panel-dedupe-20260917`; дампы
`panel_expanded.dump`, `panel_collapsed.dump` в `yc-s3:wiki-research/data/db/panels/`.

## 1. ЕИС в сфере закупок (zakupki.gov.ru) — ПЕРВИЧНЫЙ ИСТОЧНИК

- **URL**: https://zakupki.gov.ru (веб), интеграция https://int44.zakupki.gov.ru
- **Тип**: смешанный (44-ФЗ госзакупки + 223-ФЗ корпоративные + 615-ФЗ капремонт)
- **Объём**: ~2,9 млн открытых процедур 44-ФЗ за 1П2024; ~1,5 млн несостоявшихся закупок/год; полный реестр контрактов — десятки млн записей
- **Доступность**: открытый веб-поиск (без ЛК), но **массовая выгрузка — только через ЛК + токен/ЭЦП**
- **API/выгрузки**: 
  - **FTP-сервер ftp.zakupki.gov.ru ЗАКРЫТ с 01.01.2025** (исторические XML-архивы 2012–2024 остались у зеркал/парсеров)
  - Сейчас — **SOAP-сервис отдачи данных** (int44.zakupki.gov.ru/eis-integration/services/getDocsIP и др.), требует `individualPerson_token` (физлицо) или ЭЦП (юрлицо). Формат XML (XSD-схемы).
  - С 04.10.2025 — переход на новые защищённые домены с отечественными криптоалгоритмами (ГОСТ), что усложняет доступ с зарубежной инфраструктуры.
- **Строительная специфика**: полная — фильтр по ОКПД2 (раздел F: 41 здания, 42 сооружения/гражданское строительство, 43 специализированные СМР), ОКВЭД заказчика/поставщика, КТРУ. Есть отдельные реестры: контрактов, планов-графиков, планов закупок 223-ФЗ.
- **Глубина истории**: с 2011 (94-ФЗ) / 2014 (44-ФЗ) / 2012 (223-ФЗ)
- **Периодичность**: непрерывно (реальное время)
- **VPS (зарубежный IP)**: ⚠️ веб-поиск частично открыт, но **массовый SOAP-доступ и ЛК гео-чувствительны**; пользователи сообщают о проблемах входа из-за рубежа (нужен РФ-IP/VPN). Для автоматизации с VPS — практически нереализуемо без РФ-туннеля + ЭЦП.

## 2. «Госзатраты» (clearspending.ru) — ЛУЧШИЙ ОТКРЫТЫЙ API

- **URL**: https://clearspending.ru, API https://openapi.clearspending.ru/restapi/v3/
- **Тип**: смешанный (44-ФЗ, 94-ФЗ, 223-ФЗ) — общественный проект (КГИ «Госзатраты», ранее Инфокультура)
- **Объём**: **~69 млн контрактов 44-ФЗ/94-ФЗ + ~52,5 млн 223-ФЗ** (всего >120 млн записей)
- **Доступность**: открытый (бесплатный), нужен **api-key** (регистрация разработчика, бесплатно, лимиты по запросам, увеличение — индивидуально)
- **API**: REST/JSON (OpenAPI-спецификация). Эндпоинты: `/contracts/search/`, `/customers/search/`, `/suppliers/search/` и др. Фильтры по региону, заказчику, поставщику, сумме, дате, ОКПД2.
- **Строительная специфика**: есть фильтр по ОКПД2 (коды 41/42/43) и ОКВЭД; можно вытащить всех поставщиков-подрядчиков по СМР, суммы контрактов, заказчиков.
- **Глубина истории**: с 2011 (94-ФЗ), полная история
- **Периодичность**: еженедельное обновление (дампы БД)
- **VPS**: ⚠️ **сайт защищён Anubis (proof-of-work антибот)** — веб-скрейпинг затруднён; но **API openapi.clearspending.ru** — отдельный хост, доступен программно. Требует проверки с зарубежного IP (вероятно доступен, т.к. это публичный API). **Рекомендуется как основной источник для VPS.**
- **Дополнительно**: полные дампы БД в JSON публиковались (infoculture.ru, 2018); GitHub: github.com/clearspending.

## 3. OFDATA (ofdata.ru) — коммерческий API

- **URL**: https://ofdata.ru/api/contracts, API https://api.ofdata.ru/v2/contracts
- **Тип**: смешанный (44-ФЗ, 94-ФЗ, 223-ФЗ)
- **Объём**: полный реестр контрактов ЕИС
- **Доступность**: платный (тарифы, баланс в рублях), нужен API-ключ из ЛК
- **API**: REST/JSON. Параметры: `inn`/`ogrn`, `law` (44/94/223), `role` (customer/supplier), `limit`/`page`, `sort`. В ответе — заказчик, поставщики, объекты закупки с кодами **ОКПД2/ОКПД/ОКДП**, цена, даты.
- **Строительная специфика**: фильтр по ОКПД2 в объектах закупки; удобен для «все контракты конкретного застройщика/подрядчика по ИНН».
- **Глубина истории**: с 2011; **223-ФЗ поставщики отсутствуют с 2019** (ЕИС перестала публиковать).
- **Периодичность**: актуально (синхронизация с ЕИС)
- **VPS**: ✅ доступен (публичный HTTPS API, без гео-блока). Платный.
- **Бонус**: справочники ОКПД/ОКПД2 для скачивания — ofdata.ru/open-data.

## Рекомендации для пайплайна (VPS, зарубежный IP)

1. **Основной источник — clearspending.ru API** (openapi.clearspending.ru/restapi/v3/): бесплатный, JSON, полная история, фильтр по ОКПД2 41/42/43 и ОКВЭД F. Проверить доступность с VPS (сайт под Anubis, но API — отдельный хост).
2. **Резерв/обогащение — OFDATA API**: платный, но надёжный, фильтр по ИНН застройщика/подрядчика, коды ОКПД2 в объектах.
3. **Отраслевая аналитика — ТЭК-Торг**: готовые годовые отчёты по строительным закупкам (объёмы, конкуренция, НМЦК) — для калибровки/бенчмарка.
4. **ЕИС напрямую (SOAP) — НЕ рекомендуется с VPS**: требует РФ-IP, токен/ЭЦП, ГОСТ-криптографию; только через ручной handoff или РФ-туннель.
5. **Строительная специфика кодов**: ОКПД2 раздел F = 41 (здания/возведение), 42 (сооружения/гражданское строительство), 43 (специализированные СМР). ОКВЭД раздел F (41/42/43) — для фильтрации поставщиков-подрядчиков.

## Пробелы / риски
- **223-ФЗ поставщики скрыты с 2019** (ЕИС) — корпоративные договоры без данных исполнителя.
- **FTP-архивы ЕИС закрыты с 2025** — исторические XML-выгрузки доступны только через зеркала/парсеры (github.com/ForwardMoth/zakupki.gov и др.).
- **clearspending.ru веб** под Anubis-антиботом — только API.
- **Гео-блокировка** ЕИС/ЛК ЭТП с зарубежных IP — нужен РФ-туннель (xray, см. skill vps-xray-proxy).

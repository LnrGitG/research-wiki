# Статус: сработало правило остановки

Задача `t_24419848` — сверить зафиксированный прогноз по реформе
«Семейной ипотеки» 01.10.2026 с фактом за октябрь 2026 года. Проверка
выполнена 02.10.2026 05:45 UTC. **Данных за октябрь 2026 года нет ни в
одном из источников**, поэтому сверка по пунктам 1 и 2 прогноза
невозможна, а задача возвращается со статусом ожидания. Это не ошибка
сбора: на 2 октября не может существовать итог месяца, который в этот
момент ещё идёт.

# Что проверено напрямую

**Банк России, ИЖК под залог прав требования по ДДУ (файлы 02_15–02_17).**
В таблице `public.cbr_ihk_ddu` максимальный период — **2026-08**
(288 строк на период, глубина 2019-01…2026-08, 92 месяца); в
`public.cbr_ihk_izhs` — тот же максимум **2026-08** (32 месяца). Сырьевой
файл `02_15_Quantity_scpa_mortgage.xlsx` на сервере ЦБ отдаёт
`Last-Modified: Wed, 30 Sep 2026 08:29:16 GMT` и размер 129 629 байт — то
есть это та же выгрузка, что разобрана этапом 0 дизайна 01.10.2026, и она
содержит данные по август 2026 включительно. Сентябрьского месяца в
источнике ещё нет.

**ДОМ.РФ, недельные снимки.** В `public.domrf_lgot_mortgage` последний
снимок — **2026-09-20** (3 692 строки в снимке, всего 1 091 341 строка,
диапазон 2019-12-26…2026-09-20, тип отчёта `region`). Октябрьских недель
нет по определению.

**Дата замера.** 02.10.2026 — второй день октября; прогноз зафиксирован
01.10.2026 до данных (commit 5679d65), условие дизайна соблюдено.

# Когда ожидать данные

Наблюдаемый лаг источника: выгрузка от 30.09.2026 несёт август, то есть
месячный файл ЦБ закрывает месяц примерно через месяц после его конца.
Отсюда ожидаемая доступность:

- **сентябрь 2026** (ИЖК по ДДУ) — в выгрузке ЦБ конца октября 2026;
- **октябрь 2026** (ИЖК по ДДУ) — в выгрузке ЦБ конца ноября 2026;
- **недельные снимки ДОМ.РФ за октябрь** — по мере выхода недель, полный
  месяц — к началу ноября 2026.

Первичный триггер сверки — месячный файл ЦБ (пункты 1 и 2 прогноза
построены на числе ИЖК по ДДУ); недельные снимки ДОМ.РФ нужны для
разложения переноса (гипотеза H-028), а не для самого сопоставления.

# Что будет сверяться при разблокировке (без подгонки параметров)

1. Число ИЖК по ДДУ в октябре 2026 против сентября 2026 **с поправкой на
   сезонность**: ожидание — падение на 15–27 %.
2. Региональный разброс по S1-high: Свердловская −31,7 %, Пермский край
   −29,1 %, Башкортостан −28,9 % против Курганской −17,8 % (разница почти
   двукратная).

   разбор расхождения по компонентам (потеря доступа, рост ставки,
   переток в ИЖС, возврат переноса), а не пересчёт β и параметров
   микросимуляции. Параметры прогноза не подгоняются.

# Статус: прогноз зафиксирован до появления данных

Замер сделан **до публикации данных за октябрь 2026 года** — это обязательное
условие дизайна: прогноз, сделанный после появления факта, превращается в подгонку.
Ниже — числа, допущения и способ проверки.

# Схема переноса

Панельная модель с долей программы как регрессором отбракована (эндогенность,
см. `bektest-dizayna-2024-i-elastichnost-pervichki.md`). Прогноз строится на
конструкции с предопределённой экспозицией:

    Δ ln Q_r = β · A_r,

где **β = −1,045** — эластичность первичного рынка по числу ИЖК под залог прав
требования по ДДУ на единицу экспозиции (событие 01.07.2024, 78 регионов,
рандомизационный тест p = 0,002), а **A_r** — доля выдач региона, затронутая
реформой: доля семейной программы в общих выдачах региона (S_r) × доля программы,
которую реформа затрагивает.

Каналы, формирующие долю затронутого:

| Канал | Величина | Источник |
|---|---|---|
| Потеря доступа целиком | 25,1 % заёмщиков программы | микросимуляция: `lost_access / had_access` |
| Рост ставки для сохранивших право | +2,50 п.п. при прежней субсидии 6 п.п. → обесценение 41,6 %, применяется к 74,9 % | микросимуляция: `d_rate_cond` |
| Итого затронуто (S1-high) | 56,3 % программы | 25,1 % + 74,9 % × 41,6 % |

Доля семейной программы в общих выдачах региона: медиана 0,381, размах 0,005…1,000
(значения выше единицы отсечены: ДОМ.РФ считает по месту нахождения жилья, ЦБ — по
месту регистрации заёмщика, расхождение источников).

**Допущение о составе заёмщиков:** структура заёмщиков программы повторяет
структуру семей в регионе. Это допущение не проверяемо на открытых данных; при его
нарушении меняется величина A_r, но не знак результата.

# Сценарии

Эффект на число ипотечных кредитов на первичном рынке, национальный уровень
(взвешено по объёму кредитования регионов):

| Сценарий | Содержание | Затронуто | Национальный эффект | Разброс по регионам |
|---|---|---|---|---|
| **S1-low** | только потеря доступа | 25,1 % | **−12,1 %** | −23,0 % … −0,1 % |
| **S1-high** | потеря доступа + рост ставки | 56,3 % | **−25,2 %** | −44,5 % … −0,3 % |
| **S4** | S1-high с перетоком в ИЖС (20 % затронутого объёма уходит в индивидуальное строительство) | 45,0 % | **−20,7 %** | −37,5 % … −0,2 % |

Диапазон между S1-low и S1-high — не «погрешность», а разница между двумя
прочтениями поведения: если заёмщики реагируют только на исчезновение права,
эффект вдвое меньше, чем если они реагируют и на удорожание. Истина между ними.

Уральский макрорегион (эффект по числу кредитов на первичном рынке):

| Регион | Доля семейной программы | Потеря доступа | Рост ставки, п.п. | S1-low | S1-high | S4 |
|---|---|---|---|---|---|---|
| Свердловская область | 0,539 | 0,147 | +2,62 | −14,1 % | **−31,7 %** | −25,3 % |
| Пермский край | 0,495 | 0,166 | +2,48 | −13,0 % | −29,1 % | −23,3 % |
| Республика Башкортостан | 0,492 | 0,181 | +2,37 | −12,9 % | −28,9 % | −23,1 % |
| Челябинская область | 0,415 | 0,167 | +2,55 | −10,9 % | −24,4 % | −19,5 % |
| Оренбургская область | 0,398 | 0,181 | +2,40 | −10,4 % | −23,4 % | −18,7 % |
| Курганская область | 0,302 | 0,179 | +2,38 | −7,9 % | −17,8 % | −14,2 % |

Свердловская область — максимальная экспозиция среди уральских регионов за счёт
самой высокой доли семейной программы в выдачах; Курганская — минимальная.

# Траектория

Два варианта, потому что событие 2024 года и реформа 2026 года различаются
принципиально: там программа исчезала целиком, и эффект затухал по мере замещения
другими программами; здесь условия сохраняются постоянно, замещать нечем.

| Период | Базовый вариант (структурный уровень + возврат переноса) | Вариант с формой 2024 года |
|---|---|---|
| октябрь–декабрь 2026 | **−26,8 %** | −15,5 % |
| I квартал 2027 | −25,2 % | −5,4 % |
| II квартал 2027 | −25,2 % | −4,9 % |
| III квартал 2027 | −25,2 % | −3,7 % |
| с IV квартала 2027 | −25,2 % | −25,2 % |

Разница в первые месяцы велика: от −15 % до −27 %. Базовый вариант исходит из
того, что структурный эффект действует сразу; альтернативный — из того, что
эффект 2024 года был фронтально загружен и затем затухал. **Разрешить это можно
только по октябрьским данным**, и именно поэтому оба варианта фиксируются заранее.

Возврат перенесённого спроса (−2,2 % в месяц в октябре–декабре) получен из
измерения эффекта предвосхищения: около 6,4 тыс. заявок, или 6,5 % месячного
объёма, распределено на три месяца.

# Проверяемые предсказания

1. Число ИЖК по ДДУ в октябре 2026 ниже, чем в сентябре, **сильнее**, чем на
   сезонную величину: падение в диапазоне 15–27 % против сентября с поправкой на
   сезонность.
2. Регионы с высокой долей семейной программы (Свердловская, Пермский край,
   Башкортостан) падают сильнее, чем с низкой (Курганская): разница по S1-high —
   от −17,8 % до −31,7 %, то есть почти двукратная.
3. Доля ИЖС в первичном спросе растёт: ставка там сохранена (6 %), а в
   многоквартирном сегменте выросла на 2–4 п.п.
4. Доля отказов по заявкам на семейную программу растёт из-за сжатия сроков и
   роста платежа (механизм, не оценённый количественно).
5. Средний срок кредита по семейной программе смещается к 15 годам.

# Как проверять

Октябрьские данные: ИЖК по ДДУ по субъектам (ЦБ, файлы 02_15–02_17) и недельные
снимки ДОМ.РФ. Первое сравнение — по пунктам 1 и 2: если факт окажется вне
диапазона S1-low…S1-high, это означает, что либо каналы реформы измерены неверно,
либо эластичность переноса непригодна. Разбор расхождения — по компонентам, а не
подгонкой параметров.

# Ограничения

1. **Допущение о составе заёмщиков** (структура семей = структура заёмщиков) не
   проверено: доля заёмщиков с 2+ детьми без ребёнка младше 7 лет может отличаться
   от 25,1 %.
2. **Замещение в ИЖС задано, а не оценено**: 20 % затронутого объёма — допущение,
   подобранное без данных; после октября его можно будет измерить по рядам ИЖК на
   цели ИЖС.
3. **Эластичность перенесена с другого события**: в 2024 году программа исчезала
   целиком, здесь меняются её параметры. Перенос даёт верхнюю границу.
4. **Реакция банков на срок субсидирования** не наблюдается: сжатие срока до 15 лет
   и «обрыв» платежа на 16-м году дают разный рост платежа (+28…+82 % против
   +20…+65 %), и какой из них реализуется, покажет ряд средних сроков (файл ЦБ
   `02_13`, лист «срок в руб»), который в базу ещё не загружен.
5. **Общие условия не учтены**: траектория ключевой ставки, макропруденциальные
   лимиты и бюджетные программы действуют одновременно с реформой.
6. Прогноз построен по числу кредитов; объёмный эффект может отличаться, поскольку
   реформа меняет и размер кредита (лимиты выросли для многодетных).

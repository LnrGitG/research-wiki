# Ревью аномалий регионального среза (к докладу ГУ, цикл СД 23.10.2026)

Дата: 28.09.2026. Повод: этап I цикла СД — региональная часть факт-блока;
в плане цикла были названы три аномалии первого прогона. Ниже разбор каждой
по фактическим данным (`core.observation_v2`, схема `core`, не `v2`),
проверенный запросами, и правила использования среза в докладе.

Срез перегенерирован скриптом `scripts/region_slice_full.py`: 7 794 строки,
14 метрик, 85–86 регионов, период 2025-10 … 2026-08. Результат совпал с
предыдущим файлом строка в строку, значит новых публикаций с 27.09 не
добавилось и срез актуален на текущих данных.

## 1. Свердловская область, безработица (МОТ, квартальная) — подтверждённый выброс

Ряд по кварталам (метрика `emiss_43062_unemp_q`, статус `validated`):
1,7 (2024-Q3), 1,4 (2024-Q4), 1,7 (2025-Q1), 1,5, 1,3, 1,3, 1,5 (2026-Q1),
**2,7 (2026-Q2)**. Восемь кварталов держится коридор 1,3–1,7, затем рост
в 1,8 раза за один квартал.

Контекст по стране в том же периоде: медиана 1,9, минимум 0,9 (Калужская,
Нижегородская области), максимум 22,6. То есть скачок в Свердловской области
не объясняется общероссийским сдвигом — медиана не двигается.

Два вывода. Первый: значение 2026-Q2 требует сверки с публикацией Росстата
(ЕМИСС, показатель 43062) — либо это реальный сезонно-методологический сдвиг
(в 2026 году выборка обследования рабочей силы пересматривалась), либо
дефект загрузки. Второй, и он важнее для доклада: разброс 0,9–22,6 при
медиане 1,9 внутри одной метрики заставляет проверить однородность ряда —
нижний край (0,9–1,0) не похож на измерение по методологии МОТ, где
российский минимум обычно не опускается ниже двух процентов, и больше похож
на зарегистрированную безработицу. Пока это гипотеза, требующая сверки двух
конкретных регионов по первоисточнику.

**Для доклада:** ряды безработицы по регионам показывать с пометкой о
проверке; Свердловскую область не выводить как «ухудшение ситуации» без
подтверждения публикацией.

## 2. Тамбовская область, кредиты — аномалия снята, ряд в порядке

Текущий срез берёт по кредитам юрлицам метрику `zyi`, по физлицам `zkf`.
Обе — месячные, ровные: `zyi` 199 797 (2026-04) → 209 119 (2026-08), рост
4,7% за пять месяцев; `zkf` растёт монотонно без разрывов.

Аномалия первого прогона относилась не к этим рядам, а к прежним меткам
`vmd`/`vmnl`, которые несли ряды потребительского кредита из-за коллизии
подписей в `parse_cbr_lending.py`. Разбор и отзыв дефектных строк уже сделаны
(коммит `8e82918`, «vmd отозван; жилищные VFS для сопоставлений, ИЖК ЦБ для
актуализации»). В текущем срезе жилищный блок идёт двумя определениями рядом:
длинный ряд ВФС (`vhdt`, `vhlvt`, `vhrr`) для сопоставлений и исследований и
свежий ряд ЦБ по ИЖК (`vmd`, `oipflrrivrsrf`, `spsipflrrtmrsrf`) для
актуализации, что и было решением по этому дефекту.

**Для доклада:** аномалия закрыта, отдельных пометок не требует.

## 3. Малые регионы, ставка ИЖК — подтверждённый артефакт малых знаменателей

Метрика `spsipflrrtmrsrf` (средневзвешенная ставка по ИЖК, месячная), 86
регионов. В последнем периоде: максимум 14,84 (Ингушетия), 13,36 (Чеченская),
далее 12,7 и ниже; минимум 5,34 (Тыва), 5,53 (ЕАО), 5,66 (Якутия), 5,8
(Бурятия). Размах — 9,5 процентного пункта, что для ставки по одному продукту
в одной стране неправдоподобно как экономический факт.

Причина та же, что предполагалась в плане: в регионах с малым числом выданных
ипотечных кредитов средневзвешенная ставка определяется несколькими сделками,
в том числе льготными программами и ИЖС, и потому прыгает от месяца к месяцу.

**Для доклада:** правило прежнее и подтверждено — сглаживание три месяца и
порог по объёму выдачи; регионы ниже порога показывать отдельной строкой
«малая выборка», не в сравнении со средним по стране.

## Проверка ревизий (исполнено 28.09)

Внутренняя проверка базы дала однозначный ответ: значение 2,7 за 2026-Q2 не
является следствием повторной загрузки или наложения двух прогонов. По
Свердловской области в `core.observation_v2` ровно одна строка на период, все
шесть кварталов с 2025 года помечены `validated` и привязаны к одному релизу
(96); на каждый период по метрике приходится 85 строк и один релиз, то есть
ревизий внутри базы нет вовсе. Ряд выглядит так: 1,7 (2025-Q1), 1,5, 1,3,
1,3, 1,5 (2026-Q1), 2,7 (2026-Q2). Значит источник либо опубликовал именно
2,7, либо дефект возник на стороне ЕМИСС, а не в загрузке.

Побочно уточнилась картина по крайним регионам. Ингушетия даёт 25,5 → 23,6 →
22,6 — плавное снижение, правдоподобное для измерения по методологии МОТ.
Калужская область держит ровно 0,9 три квартала подряд, и вот это
неправдоподобие не в уровне, а в идеальной стабильности: такие ряды
характерны для регистрируемой безработицы, а не для выборочного обследования
рабочей силы. Гипотеза о смешении методологий внутри одной метрики от этого
только укрепилась.

## Внешняя сверка: путь заблокирован технически

Выгрузка значений с fedstat.ru из программы не проходит. Страница показателя
43062 отдаётся (200, 126 КБ), структура фильтров в ней есть, но данные
забираются только POST-запросом с полным набором идентификаторов выбора, а
наш порт клиента `scripts/emiss_client.py` нерабочий: разбор JS-блока падает
на этом показателе (`JSONDecodeError`), в коде не совпадают сигнатуры
(`build_post_body` вызывается с двумя аргументами при трёх), а переменная
`objs_map` в `get_data_ids` вообще не определена. Наивные варианты POST
возвращают HTML страницы, а не xlsx; прямой GET с `format=excel` — то же.
Порт писался под другой шаблон страницы и остался незавершённым.

Практический вывод: пока проверка идёт через ревизии и через сравнение
регионов между собой, значение помечено как непроверенное; для сверки с
первоисточником нужно починить клиент либо взять публикацию Росстата
напрямую.

# Региональный срез v0: ввод жилья по регионам (прототип формата «регион × переменная»)

Дата: 2026-09-25. Назначение: первый прогон регионального среза для
докладов ГУ на промежуточных совещаниях с ДДКП (карточка sitrep, блок
«Поддержка материалов для ДДКП и ГУ»). Данные: ЕМИСС 34118
«Введено в действие общей площади жилых домов (оперативные данные)»,
метрика `emiss_34118_vvod` в БД v2, 80 регионов + РФ, месяцы 2026-06 /
2026-07 / 2026-08, помесячный ввод (тыс. кв. м). CSV:
`data/region_slice_housing_202609.csv`.

## Методические пометки

- В ЕМИСС 34118 на регион-месяц приходится 7–8 значений
  (номенклатурные срезы: жилые/нежилые, полный/неполный круг).
  В observation_v2 номенклатуры не размечены — срез v0 берёт
  **максимум по номенклатурам = суммарный ввод (жилые + нежилые)**.
  Для жилищно-чистого ряда нужна догрузка по номенклатуре
  «Жилые здания» — TODO среза v1.
- «Архангельская область (с НАО)» и «(без НАО)» — два среза одного
  субъекта; в сводках использовать «(с НАО)» (полный круг), «(без
  НАО)» — контроль.
- Значения оперативные (flash assessment) — пересмотры возможны.

## Выводы для формата доклада ГУ

1. Формат «регион × переменная» работает: одна метрика → 79 строк,
   3 месяца, две колонки скорости. В докладе ГУ — только крупные
   регионы (топ-15) + региональные лидеры/аутсайдеры по скорости.
2. Ограничение: пока в БД только одна региональная метрика ЕМИСС
   (ввод жилья). Для полного среза блоков A/B/C/E/F нужен инжест
   региональных рядов Росстата (розница, зарплаты, безработица,
   ИПЦ по регионам) — это этап 1 плана пайплайна.
3. Помесячные данные по малым регионам шумные — докладывать
   сглаженные 3-месячные значения, а не помесячные скорости.

# Каталог базы данных regions_panel.db

**Файл:** `data/regions_panel.db` (SQLite, ~182 МБ)
**Источник:** Rosstat Collection 102 (v20260313) — открытые данные
**Период:** 2001–2025 (**только годовые наблюдения**)
**Уровни:** Регион (89 субъектов РФ) · Федеральный округ (8 ФО) · Страна (РФ)
**Записей:** 308,952
**Индикаторов:** 179 (по 15 секциям)

## Схема

```sql
CREATE TABLE panel (
    section         TEXT,   -- раздел статистики
    indicator_code  TEXT,   -- код показателя
    indicator_name  TEXT,   -- название показателя
    region_name     TEXT,   -- название региона
    region_level    TEXT,   -- 'Регион' | 'Федеральный округ' | 'Страна'
    oktmo           TEXT,   -- код ОКТМО
    year            INTEGER,-- год (2001–2025)
    value           REAL,   -- значение
    unit            TEXT,   -- единица измерения
    source          TEXT    -- источник данных
);

-- Индексы: region_name, year, section, indicator_name, (region_name, year)
```

## Примеры запросов

```sql
-- Ввод жилья по регионам (2024, топ-10)
SELECT region_name, value FROM panel
WHERE indicator_name='Ввод в действие жилых домов: Всего'
  AND region_level='Регион' AND year=2024
ORDER BY value DESC LIMIT 10;

-- Инвестиции в основной капитал (РФ, весь ряд)
SELECT year, value FROM panel
WHERE indicator_name='Инвестиции в основной капитал'
  AND region_name='Российская Федерация' ORDER BY year;

-- Цены на жильё (первичный рынок, РФ)
SELECT year, value FROM panel
WHERE indicator_name='Средние цены на первичном рынке жилья'
  AND region_name='Российская Федерация' ORDER BY year;

-- Панель для моделирования: ввод жилья + инвестиции + цены
SELECT h.year, h.region_name, 
       h.value as housing_input,
       i.value as investment,
       p.value as price_primary
FROM panel h
LEFT JOIN panel i ON h.region_name=i.region_name AND h.year=i.year
  AND i.indicator_name='Инвестиции в основной капитал'
LEFT JOIN panel p ON h.region_name=p.region_name AND h.year=p.year
  AND p.indicator_name='Средние цены на первичном рынке жилья'
WHERE h.indicator_name='Ввод в действие жилых домов: Всего'
  AND h.region_level='Регион'
ORDER BY h.region_name, h.year;
```

## Источники данных

| База | Файл | Тип | Период | Записей |

**regions_panel.db** — чистая панель для моделирования (годовые данные).
**rosstat_construction.db** — архив сырых данных (вкл. помесячные ДОМ.РФ и квартальные цены).

## Ограничения

- **Только годовые данные** — нет помесячных или поквартальных наблюдений
- Дубликаты по регионам: Архангельская обл. «с АО» и «без АО», Тюменская обл. «с АО» и «без АО»
- Некоторые индикаторы имеют данные только за часть лет (не полный панель)
- Секция «Производство продукции для строительства» — только 9 регионов (РФ + ФО)
- 2025 год: данные частично доступны (не по всем индикаторам)

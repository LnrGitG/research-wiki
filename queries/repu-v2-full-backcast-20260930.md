# REPU-РФ v2: повторный прогон по методу Chen-Mo-Tang-Li на снятом GDELT (30.09.2026)

Обновление пилота queries/repu-pilot-spec-20260929.md. В пилоте тройка
фильтров считалась на GKG-корпусе из шести сентябрьских дней 2026; теперь
тройной булев запрос выполняется на стороне GDELT DOC API на всём таймлайне
2017–2026 — ограничение «корпус 6 дней» снято. Ряд 2020-04 и 2020-11,
2022-03 остался недоступен по тону (API по отдельным годам не отдал
Средний тон — вернулись пустые значения), поэтому контроль закрытия 2024
полноценный, 2020/2022 — нет.

## Что сделано

1. scripts/repu_housing_doc_full.py — сборщик: тройной булев запрос
   «(housing OR mortgage OR "real estate") (policy OR regulation OR decree
   OR subsidy OR ban) (uncertainty OR uncertain OR unstable OR volatile
   OR unpredictable) Russia», режимы timelinevol + timelinetone по годам
   2017–2026, бэкофф на rate-limit. Выход daily 2 800 дней (2019-01-01 …
   2026-09-29), 2017/2018 API не отдал (объём по этим годам тоже пуст).
2. scripts/repu_housing_doc_aggregate.py — месячная агрегация по месяцам
   с полным (объём+тон): 93 месяцев в файле, из них 48 с repu_index.
3. Контрольные события по методу Chen: закрытие массовой льготной
   ипотеки 2024-06/07 — repu_index +0,20/+1,81 (пик всего ряда) — валида-
   ционный тест прошёл; 2023-01 (правки и анонс закрытия) −0,25 —
   не подтверждён.

## Результаты

- Топ-5 месяцев индекса: 2024-07 (+1,81), 2021-03 (+1,65), 2021-06 (+1,41),
  2025-08 (+1,22), 2021-05 (+1,22). Два из трёх верхних пиков — месяцы
  ключевых регуляторных решений по льготной/семейной ипотеке (закрытие
  массовой июль 2024, изменение условий июнь 2021) — соответствие методу.
- Средний тон по полным месяцам: mu = −1,595, sd = 0,230 (тон GDELT по
  тройному фильтру систематически негативнее общеэкономического mu −1,197:
  тема «жильё+регулирование+неопределённость» сама по себе негативная).

## Ограничения честности

1. Тон недоступен по 2019, 2020, 2022, 2026-09 (API отдал только объём) —
   не покрываются контрольные события 2020-04 (запуск льготной ипотеки),
   2022-03 (расширение семейной). Индекс считается на 48 месяцах 2021–2025.
2. Тон и объём по одному году отдаются в разных таймингах: месячный файл
   покрывает 2019–2026 (93 мес.), но repu_index — только там, где есть оба
   поля (48 мес.).
3. Проверка опережения (VAR vs ввод жилья/СМР) — по-прежнему следующий
   этап: 48 месяцев — мало для VAR, но уже достаточно для кросс-корреляций
   при лагах 1–4 месяца.

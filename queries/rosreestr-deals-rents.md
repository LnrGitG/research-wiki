# Росреестр: сделки (ДКП+ДДУ) и аренда по регионам

## Источник

Выгрузки Росреестра (квартальные срезы), папка Google Drive `Rosreestr_Data`
(https://drive.google.com/drive/folders/1JsrKqJESYeoCzcvdIjHJBuQsD1P4je0U).

Период: **2024q1 – 2026q2** (10 кварталов), 85 регионов.
Обработано: 2026-08-26.

## Базы данных

| База | Размер | Содержимое |
|---|---|---|
| `data/rosreestr_deals.db` | 144 КБ | Агрегаты: `deals_by_region_quarter`, `rents_by_region_quarter`, `deals_rf_quarterly`, `rents_rf_quarterly` |
| `~/rosreestr/rosreestr_deals_full.sqlite` | 1.5 ГБ | Полный массив: `deals` (7 574 311 строк), `rents` (485 724), локально, вне git |

Схема агрегатов сделок: `year, quarter, region_code, region, n_deals, n_dkp,
median_price_per_sqm, median_dkp_per_sqm, median_ddu_per_sqm`.
Аренда: `year, quarter, region_code, region, n_rents, median_rate_per_sqm, median_area`.

Медианы считаются по объектам как `deal_price / area` (₽/м²). В аренде
`deal_price` — ставка за период; при типичном договоре на год это ₽/м²/год.

## Предостережения по данным

1. **Коллапс ДДУ с 2025 года**: 669 606 записей ДДУ в 2024 → 31 509 в 2025.
   Либо резкое смещение рынка к ДКП после исчерпания льготной ипотеки,
   либо смена методологии выгрузки. Медианы ДДУ за 2025–2026 считать
   ненадёжными (малые выборки, выбросы: Москва 2025q1 — 861 ₽/м²).
2. **Разделитель CSV меняется между кварталами**: `;` (2024 q1–q3) или `~`
   (с 2024q4). Парсер должен детектировать разделитель по заголовку
   (`sniff_sep`). Возможны и другие вариации формата между выгрузками.
3. `period_start_date` — якорь квартала (например, 2026-04-01), не дата сделки.
4. Часть записей имеет пустые `street`/`wall_material_code`; `okato` смешанного типа.

## Пример запроса

```python
import sqlite3
con = sqlite3.connect('data/rosreestr_deals.db')
# динамика медианной цены ДКП, топ-10 регионов
pd.read_sql("""
SELECT year, quarter, region, median_dkp_per_sqm
FROM deals_by_region_quarter
WHERE region_code IN (77,78,23,66,16)
ORDER BY region_code, year, quarter""", con)
```

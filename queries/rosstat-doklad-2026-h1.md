## База данных

Таблица `doklad_2026_h1` в `data/rosstat_construction.db`:
- 630 записей
- 9 показателей
- ~70 регионов + ФО + РФ
- Источник: 6 ключевых .doc файлов

```sql
-- Ввод жилья по регионам
SELECT region_name, value FROM doklad_2026_h1 
WHERE indicator='housing_built_area' 
ORDER BY value DESC LIMIT 20;

-- Индексы цен на жильё
SELECT region_name, indicator, value FROM doklad_2026_h1 
WHERE indicator LIKE 'price_index_%' AND region_name='Российская Федерация';
```

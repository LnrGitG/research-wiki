## Технические заметки

- **unrar** установлен в user-space: `~/.local/bin/unrar` (UNRAR 7.00, извлечён из .deb)
- RAR-архивы содержат `.doc` файлы с таблицами (для федокругов) и `.xlsx/.xls` (для мониторинга)
- API Росстата: `GET /folder/11109/getPage?page=1` → JSON с HTML-контентом
- Все файлы `/storage/mediabank/` доступны через `curl -sk`

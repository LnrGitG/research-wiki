Ниже — практические пути получения таких рядов.

## Проверено на этом сервере (24.08.2026)

### 1. Google Trends через pytrends ✅ РАБОТАЕТ

```python
# venv: ~/.hermes/hermes-agent/venv (pip install pytrends)
from pytrends.request import TrendReq
pt = TrendReq(hl='ru-RU', tz=180, timeout=(10,25))
pt.build_payload(['ипотека'], timeframe='2019-01-01 2024-12-31', geo='RU')
df = pt.interest_over_time()          # недельный ряд
reg = pt.interest_by_region(resolution='REGION')   # 83 региона РФ!
```

Проверено:
- недельные ряды «ипотека» 2019–2024: 72 точки, годовые средние 45→71 (рост интереса);
- **interest_by_region: 83 региона РФ** — готовая региональная панель;
- related_queries: «семейная ипотека» 47, «льготная» 26, «сельская» 46 — темы для PCA.

Ограничения Google Trends:
- значения 0–100 = относительная интенсивность внутри периода запроса,
  НЕ абсолютное число запросов; при смене окна пересчитываются задним числом;
- лимиты: ~1 запрос/сек, при 429 нужен экспоненциальный backoff или прокси;
- длинный период (>5 лет) автоматически понижает частоту до месячной.

### 2. Яндекс Wordstat API v2 ⚠️ требует OAuth-токен и агентство/рекламный аккаунт

- endpoint: `https://api-wordstat.yandex.net/v2/reports` (JSON-RPC),
  DNS с этого сервера резолвится только через `api.wordstat.yandex.net`;
- нужны: регистрация приложения на oauth.yandex.ru → токен → привязка к
  рекламному кабинету. Бесплатный лимит: 1000 отчётов/сутки.
- выдаёт АБСОЛЮТНЫЕ числа показов запроса в месяц по регионам (гео-разрез встроен).

Веб-интерфейс wordstat.yandex.ru доступен (HTTP 200) без авторизации,
но без API парсить его против ToS.

### 3. Яндекс Suggest ✅ работает, но это подсказки, не частоты

`https://suggest.yandex.ru/suggest-ff.cgi?part=инфляция` — релевантность
подсказок можно использовать как прокси «что ищут», но числовых рядов нет.

### 4. Google Trends RSS ✅ работает

`trends.google.com/trending/rss?geo=RU` — ежедневные трендовые запросы
(без истории). Полезно для сентимент-мониторинга, не для рядов.

## Что рекомендую для research-wiki

**Двухуровневая схема:**

Уровень A — оперативный (уже работает): pytrends
- еженедельные ряды: инфляция, ипотека, новостройка, вторичка, аренда,
  доллар, ключевая ставка;
- interest_by_region ежемесячно → панель 83 региона × темы;
- cron-джоб раз в неделю → SQLite `data/search_trends.db`.

Уровень B — точный (нужно действие пользователя): Wordstat API
- зарегистрировать приложение https://oauth.yandex.ru → токен;
- абсолютные показы в месяц + гео до города;
- это то, что использовал Карпеко (2026): «данные Яндекс Wordstat».

## Темы запросов для жилья (стартовый словарь, по аналогии с QUIET)

| Блок | Запросы |
|------|---------|
| Ипотека | ипотека, семейная ипотека, льготная ипотека, рефинансирование ипотеки, калькулятор ипотеки |
| Покупка | купить квартиру, новостройки, вторичка, застройщик, ДДУ |

Метод QUIET: PCA по этим темам (ежемесячно/еженедельно) → индекс ожиданий →
MIDAS-прогноз ИПЦ и цен жилья.

  count приходит строкой (int64→JSON string); операторы !/+/[ ] не поддерживаются.
- proto: github.com/yandex-cloud/cloudapi .../searchapi/v2/wordstat_service.proto

## 1. Строительная инфляция

### 1.1 ИЦСП / индексы цен производителей на строительную продукцию — Росстат / ЕМИСС
- **Название:** Индексы цен производителей на строительную продукцию (ИЦСП); Индексы цен на продукцию (затраты, услуги) инвестиционного назначения
- **URL (проверены):**
  - `rosstat.gov.ru/statistics/price` — раздел «Цены, инфляция» → «Цены производителей» (работает)
  - `rosstat.gov.ru/free_doc/new_site/prices/ics_data.htm` — «Индексы цен и средние цены строительной продукции» (работает)
  - `rosstat.gov.ru/free_doc/new_site/prices/stroit/tab10.htm` — сводные индексы цен строительной продукции по РФ (с 1995)
  - `rosstat.gov.ru/free_doc/new_site/prices/stroit/tab11.htm` — индексы цен производителей в строительстве (СМР) по РФ (с 1995)
  - ЕМИСС: `fedstat.ru/indicator/57796` (ИЦСП с 2017), `fedstat.ru/indicator/57795` (инвестиц. назначения), `fedstat.ru/indicator/57709` (цены приобретения стройматериалов) — **403 Forbidden с VPS/дата-центра (гео-блок)**
- **Что даёт:** ИЦСП (сводный + СМР) по РФ и субъектам; индексы цен на продукцию инвестиционного назначения по ВЭД «Строительство» (с 2017); индексы цен приобретения стройматериалов (с 2017)
- **Периодичность:** ежемесячно (лаг ~1 мес)
- **Глубина истории:** с 1995 (сводные по РФ), с 2017 (региональные/детальные)
- **Формат:** HTML-таблицы (Росстат), XLSX/CSV (ЕМИСС, витрина данных)
- **Платно:** нет
- **Доступность:** открытый (Росстат), ЕМИСС — гео-блок с VPS (нужен туннель/ноутбук)
- **Примечание:** главный пробел по строительной инфляции. ЕМИСС-показатели 1.29.17. Зеркало-агрегатор: `kbresurs.ru/103-nmtsk/310-indeksy-tsen-na-produktsiyu.html` (собирает с fedstat+rosstat, XLSX с фильтрами по регионам, обновляется).

### 1.2 Индексы цен стройматериалов — НОСТРОЙ
- **URL:** `nostroy.ru/actual/tsenoobrazovanie-v-stroitelstve/monitoring-stoimosti-stroitelnykh-materialov/` (основной сайт 403 WAF с VPS; reestr.nostroy.ru 200)
- **Что даёт:** мониторинг цен на основные стройресурсы (арматура, бетон, раствор, цемент, кирпич, минвата, кровельные материалы, кабель, трубы, битум) — % изменения м/м и г/г
- **Периодичность:** ежемесячно (пресс-релизы «Мониторинг НОСТРОЙ цен»)
- **Глубина истории:** с ~2015
- **Формат:** HTML (пресс-релизы, таблицы)
- **Платно:** нет
- **Доступность:** открытый, но основной домен 403 WAF с VPS (нужен туннель)

### 1.3 Сметная стоимость / ФЕР-ГЕР-ТЕР / индексы изменения сметной стоимости — Минстрой / ФГИС ЦС
- **Название:** ФГИС ЦС (Федеральная государственная информационная система ценообразования в строительстве)
- **URL (проверены):**
  - `fgiscs.minstroyrf.ru/` — портал (работает)
  - `fgiscs.minstroyrf.ru/frsn/fsnb` — ФСНБ-2022/2020 (федеральная сметно-нормативная база, дополнения №1–19)
  - `fgiscs.minstroyrf.ru/prices` — сметные цены и индексы изменения сметной стоимости (по субъекту/ценовой зоне/кварталу)
  - `fgiscs.minstroyrf.ru/frsn/reference/indexes` — реестр индексов изменения сметной стоимости (2018–2026)
  - `minstroyrf.gov.ru/trades/tsenoobrazovanie/indeksy-izmeneniya-smetnoy-stoimosti/` — индексы Минстроя (гео-блок 000 с VPS)
- **Что даёт:** ФСНБ-2022 (ФЕР/ГЭСН), классификатор строительных ресурсов, мониторинг цен стройресурсов, сметные цены и индексы изменения сметной стоимости (поквартально, по регионам и ценовым зонам), индексы РИМ (ресурсно-индексный метод)
- **Периодичность:** ежеквартально (индексы), дополнения ФСНБ ~2 мес
- **Глубина истории:** индексы с 2018; ФСНБ-2022 с 2022 (дополнения №1–19)
- **Формат:** HTML-портал, XLSX/XML (ФСНБ в формате открытых данных), PDF (письма Минстроя)
- **Платно:** нет (открытый портал); полный доступ к сметным ценам — через ЛК
- **Доступность:** открытый (просмотр), ЛК для юрлиц (предоставление данных)
- **Примечание:** индексы изменения сметной стоимости СМР/ПИР также агрегируются КонсультантПлюс (`consultant.ru/document/cons_doc_LAW_39473/`) — поквартально с 2008, со ссылками на письма Минстроя/Минрегиона/Госстроя.

### 1.4 ЕГРЗ — сметная стоимость (проверка достоверности)

- **Доступность:** открытый поиск (расширенный поиск `egrz.ru/organisation/reestr-advance/latest`), полный API — ЛК
- См. раздел 3.

## 2. Финансирование строительства

### 2.1 ЦБ РФ — эскроу / проектное финансирование / ипотека
- **URL (проверены):**
  - `cbr.ru/banking_sector/equity_const_financing/` — финансирование долевого строительства (работает)
  - `cbr.ru/banking_sector/statistics/?CF.TagId=167` — статистика проектного финансирования (заключение кредитных договоров с застройщиками, счета эскроу)
  - `cbr.ru/statistics/bank_sector/mortgage` — ипотека (ИЖК, ДДУ, ИЖС, ставки) — уже в базе
- **Что даёт:** количество счетов эскроу (>1 млн), объём средств на эскроу (7,5 трлн ₽ на 01.07.2026), сумма кредитных договоров, текущая задолженность, динамика проектного финансирования (2019–2026, ежемесячно); квартальный обзор «О проектном финансировании строительства жилья» (PDF)
- **Периодичность:** ежемесячно (обследование), квартальный PDF-обзор
- **Глубина истории:** с 2019 (эскроу), ипотека с 2019
- **Формат:** HTML-графики (Highcharts), XLSX (ипотека), PDF (обзоры)
- **Платно:** нет
- **Доступность:** открытый

### 2.2 ДОМ.РФ — ипотека, льготные программы, аналитика
- **URL (проверены):**
  - `дом.рф/analytics` (xn--d1aqf.xn--p1ai/analytics) — аналитика
  - `дом.рф/analytics/mortgage` — ипотека
  - `наш.дом.рф` (ЕИСЖС, xn--80az8a.xn--d1aqf.xn--p1ai) — ипотечное кредитование, ввод жилья, эскроу, ДДУ
  - `дом.рф/api/v2/content/download/{id}/{hash}/` — download API (ипотека с 2006, еженедельные ставки)
- **Что даёт:** выдача ипотеки (льготные + рыночные программы), средняя сумма/срок кредита, объём задолженности, индекс цен первички по регионам, продажи новостроек, ввод жилья
- **Периодичность:** ежемесячно (ипотека), еженедельно (ставки топ-20 банков), ежеквартально (обзоры)
- **Глубина истории:** ипотека с 2006 (download API), цены с 2021
- **Формат:** HTML-дашборды, XLSX/PDF (download API)
- **Платно:** нет (базовая аналитика); API ЕИСЖС (бизнес.дом.рф) — платный тариф
- **Доступность:** открытый (аналитика), ЕИСЖС 403 WAF с VPS (нужен туннель/ЛК)

## 3. Базы экспертизы и проектной документации

### 3.1 ЕГРЗ (ГИС ЕГРЗ)
- **URL:** `egrz.ru` (работает); расширенный поиск `egrz.ru/organisation/reestr-advance/latest`; аналитика `egrz.ru/organisation/analytics`
- **Что даёт:** единый госреестр заключений экспертизы проектной документации и результатов инженерных изысканий; сведения о проектной документации, типовой проектной документации, проверка достоверности сметной стоимости
- **Периодичность:** непрерывно (по мере внесения заключений)
- **Глубина истории:** с 2018 (запуск ГИС ЕГРЗ)
- **Формат:** HTML-портал, XML (электронные документы)
- **Платно:** нет (открытый поиск)
- **Доступность:** открытый (поиск/просмотр), полный доступ — ЛК
- **Правовая база:** ПП РФ от 24.07.2017 № 878, приказ Минстроя от 22.02.2018 № 115/пр, ст. 50.1 ГрК РФ

### 3.2 open-api.egrz.ru — API ЕГРЗ
- **URL:** `open-api.egrz.ru/swagger` — **403/404 без авторизации** (требует ЛК/токен)
- **Что даёт:** REST API для доступа к реестру заключений (машиночитаемый)
- **Доступность:** ЛК (авторизация), не анонимно
- **Примечание:** swagger-эндпоинт недоступен анонимно; доступ по регламенту через ЛК ГИС ЕГРЗ. Зеркало-дамп: `data.apicrafter.ru/packages/egrzregistry` (177 473 записи, 327.9 MB, снимок 2021, CC-BY-SA).

### 3.3 Главгосэкспертиза России (ФАУ «Главгосэкспертиза»)
- **URL:** `gge.ru` (работает); `gge.ru/services/egrz/` — ЕГРЗ; `gge.ru/services/expertise/` — госэкспертиза
- **Что даёт:** государственная экспертиза проектной документации и результатов инженерных изысканий, проверка достоверности сметной стоимости; сервисы КПСР (комплексная проверка сметных расчётов), ВПЭ (взаимное признание экспертиз)
- **Периодичность:** непрерывно
- **Формат:** HTML, электронные сервисы, ЛК заявителя
- **Платно:** услуга платная (госпошлина/договор), просмотр реестра бесплатно
- **Доступность:** открытый (инфо), ЛК заявителя (услуги)

### 3.4 Региональные центры экспертизы
- **Примеры:** ГАУ «Госэкспертиза Кузбасса» (`uge42.ru/about/reestr-zaklyucheniya.php`), региональные ГАУ/ГБУ субъектов РФ
- **Что даёт:** региональные реестры заключений экспертизы (дублируются в ЕГРЗ)
- **Доступность:** открытый (реестры на сайтах регионов), но данные консолидируются в ЕГРЗ
- **Примечание:** для пайплайна достаточно ЕГРЗ как единой точки; региональные — резерв.

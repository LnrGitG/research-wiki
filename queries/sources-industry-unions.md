## 1. ДОМ.РФ Аналитика
- **URL**: https://дом.рф/analytics/ (punycode: xn--d1aqf.xn--p1ai/analytics/) — ✅ 200
- **Что даёт**: индекс цен первичного рынка жилья (совместно с Росреестром, по всем регионам, м/м и г/г, с 2021); выдача ипотеки ежемесячно (тыс. кредитов + млрд ₽, с ~2018); продажи новостроек; ввод жилья; квартальные обзоры; остатки на счетах эскроу; покрытие проектного финансирования.
- **Периодичность**: ежемесячно (ипотека/цены), еженедельно (ставки топ-20 банков), ежеквартально (обзоры).
- **Глубина истории**: цены с 2021, ипотека с ~2018 (через download API — с 2006).
- **Формат**: HTML-дашборды + PDF; download API `дом.рф/api/v2/content/download/{id}/{hash}/` → xlsx/pdf.
- **Платно**: нет.
- **Доступность**: ✅ 200 с VPS. Отдельно ЕИСЖС (наш.дом.рф) — ❌ 403 WAF, но есть официальный REST API (бизнес.дом.рф/api-еисжс, платный тариф, машиночитаемый).

## Состав реестра
138 позиций, 8 кластеров: Экономика 67, Финансовый рынок 37, Развитие НПС 12, ДКП 10,
Кредитно-депозитный 5, Инфляция 3, наличное обращение 3, ликвидность 1.
Источники: сайт ЦБ 48, ЕМИСС 30, Росстат 20, НСПК 8, Cbonds 5, ФНС 4, hh.ru/Работа России/

## Перекрытие с существующим покрытием
- **Уже покрыто:** сайт ЦБ (48 позиций — мониторинг, ДКП, ставки — наш универсальный API
  покрывает статистические из них; аналитические материалы — не для БД), Росстат-разделы

- **Новые для БД: 66 позиций.** Из них приоритет для nowcasting ИКВ/СМР — 47.

## Приоритетный инжест (сектор → источник → ЕМИСС id)
1. **Финансовое положение/результаты компаний** (прогнозирование по финансовому состоянию
   подрядчиков и девелоперов): прибыль до налогообложения 57732, рентабельность 58036,
   дебиторская задолженность 59584 + просроченная 57766, выручка 58018, оборот 57710.
   Ежемесячные, региональные.
2. **Рынок труда** (зарплатный канал СМР): номинальная ЗП 57824, фонд ЗП 57849, реальная ЗП
   43245, среднесписочная численность 57848; hh-индекс (stats.hh.ru), Работа России
   (trudvsem.ru opendata JSON).
3. **Потребительская активность** (спрос на жильё через доходы): розница ИФО 31066/57701,
   платные услуги 57788/58467, индекс потребительской активности ФНС
   (geochecki-vpd.nalog.gov.ru/businessActivity, ежедневный!).
4. **Промышленность/нацсчета**: ИПП 57806, отгружено 57722, ВРП 61483.
5. **ЕИСЖС**: «Основные показатели жилищного строительства» (жилая площадь, счета эскроу...)
   — частично дублирует domrf-метрики, сверить.
6. **МСП ФНС** (rmsp.nalog.ru): количество субъектов, занятость, самозанятые.
7. **Бюджет**: Электронный бюджет (budget.gov.ru) — исполнение бюджетов, региональный разрез.

## Не приоритетно для housing-исследования
НСПК (8 позиций — платёжная инфраструктура), Cbonds (рынок бумаг, платный API),
финансовая грамотность, туризм, сельское хозяйство, телеграм-каналы и журналы
(«Деньги и кредит», econs.online — источники для papers/, не БД).

# Спрос-первичен: spatial-поиск → фактический спрос → ввод. Плюс новые срезы ДОМ.РФ

**Дата:** 2026-09-21. **Статус:** постановка утверждена владельцем («Да»). Ревизия семантики spatial-разреза поискового спроса + карта новых источников.

## 1. Ревизия цепочки сопоставления

Старая постановка (сопоставлять поисковый спрос напрямую с вводом жилья) отклонена
владельцем. Причина: ввод — результат спроса 1,5–3-летней давности (цикл
«решение о покупке → стройка → ввод»); поиск коррелирует с текущей рыночной
активностью (подтверждено: композит S2–S5 r=0.644 с СМР, но ≈0.17 с ИКВ).

**Новая цепочка — двухступенчатая:**

1. **Короткая ступень:** поисковый спрос → фактический спрос (сделки, выдача
   ИЖК, продажи ДОМ.РФ). Ожидание: сильная связь, лид 0–1 мес.
2. **Длинная ступень:** фактический спрос → будущий ввод (застройщик видит
   продажи → запускает проекты). Ввод — валидация полной цепочки, а не прямой
   бенчмарк поиска.

## 3. Семантика spatial-сбора (13 фраз, 3 уровня)

- **L1 — жилищный спрос, 8 фраз, 94 субъекта (ядро):** «купить квартиру в
  новостройке», «купить квартиру в [город]», «новостройки от застройщика»,
  «купить квартиру в ипотеку», «ипотека [город]», «новостройки цена за м2»,
  «вторичка купить квартиру», «купить дом». Принцип: локальная привязка или
  локализуемость; якорь «ипотека» уже валидирован (wordstat_housing_regions.json,
  3 фразы × 7 ФО с 2018).
- **L2 — кредитный спрос, 2 фразы, 94 субъекта:** «ипотека в [банк]»,
  «ставка по ипотеке». «Рефинансирование» — вне набора (перераспределение,
  не новый спрос; гипотеза ортогональности — ниже).
- **L3 — B2B, 3 фразы, только 7 ФО:** «спецтехника купить», «аренда
  спецтехники», «экскаватор купить» (corr +0.51 lag0 с ИКВ на федеральном
  уровне). По субъектам не выживают статистически (нули/скачки).
- **Не включать:** «стройка», «строительство» (шум), «тендер на строительство»
  (доказанно не работает, +0.13), «смета на строительство».
- Объём: ~950 рядов «регион × фраза», недельная частота. Нормализация: хранить
  count И share (доля региона в РФ-объёме по фразе) — клиент `wordstat_api.py`
  пишет обе; share снимает эффект численности населения.

## 4. Приёмочные критерии и гипотезы

**Г-поиск:** региональный композит L1 опережает cbr_izhk_count_m того же
региона на 0–1 мес; контроль — FE регионов, share-нормализация. Критерий:
корреляция ≥ федерального бенчмарка на 5–6 крупных регионах.

**Г-насыщение:** отношение «поисковый спрос / количество объявлений» (индекс
насыщения) ведёт медианную цену сделки на 2–4 мес.

**Г-рефинансирование:** «рефинансирование ипотеки» ортогонально СМР при
контроле «ипотеки» (низкая частичная корреляция).

**Г-цикл (новая):** скорость движения строительной готовности по когортам
разрешений (permits → readiness → ввод) предсказывает ввод за 2–3 квартала.

**Г-цепочка (полная):** поиск t → сделки t+1 → ввод t+24–30; тестируется
ступенями.

## 5. Новые срезы ДОМ.РФ (разведка 2026-09-21, с ВМ)

- **Отраслевая платформа данных** (платформа.дом.рф, запущена 11.2025,
  19 наборов): метаданные открыты — `api/open/datasets/<uuid>`; файлы
  (CSV + SCHEMA JSON) за Yandex SmartCaptcha → скачивать руками из браузера.
  Целевые наборы: «Объекты строительства по регионам» (объекты, застройщики,
  **средняя этажность**, площади; ревизия 21.08.2026), «Квартирография»
  (помесячно, ~515 КБ), «Активность застройщиков», «Популярность характеристик
  домов».
- **Статистические ряды ДОМ.РФ**: sales/ddu-потоки по регионам — кандидат в v2
  (конвейер №6 M2); readiness — знаменатель прогресса для Г-цикл.
- **ЕРЗ (erzrf.ru)**: API живой с ВМ (префикс erz-rest/api/v1|v2), ТОП
  застройщиков («строится м²», «перенос срока», «уточнение срока, мес.»),
  база 60 000+ МКД с 2015 — трек developer financial health (стык с МСФО-
  панелью ПИК/ЛСР/Эталон через bo.nalog).
- **Длительность строительного цикла**: прямого показателя нет; вычислимая
  когортная величина permits(t) → ввод(t+Δ) по регионам, Δ фед. ≈ 18–30 мес.

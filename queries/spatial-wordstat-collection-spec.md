# ТЗ: spatial-сбор Wordstat — панель «регион × фраза»

**Дата:** 2026-09-21. **Статус:** к исполнению (конвейер №8).
**Приоритет:** Г-поиск (H-014), Г-насыщение (H-012) из queries/spatial-search-demand-semantics.md.

## Цель

Панель поискового спроса «регион × фраза × неделя» для сопоставления с
фактическим спросом (выдача ИЖК Т_16, продажи ДОМ.РФ, объявления СберИндекса)
— высокочастотный региональный опережающий индикатор.

## Семантика: 13 фраз × 3 уровня

- **L1 — жилищный спрос, 8 фраз, 94 субъекта:**
  «купить квартиру в новостройке», «купить квартиру в [город]» (7 топ-городов
  отдельными фразами), «новостройки от застройщика», «купить квартиру в ипотеку»,
  «ипотека [город]» (3-4 крупнейших), «новостройки цена за м2», «вторичка
  купить квартиру», «купить дом». Якорь «ипотека» уже валидирован
  (wordstat_housing_regions.json, 3 фразы × 7 ФО с 2018).
- **L2 — кредитный спрос, 2 фразы, 94 субъекта:** «ипотека в [банк]»
  (топ-4 банка), «ставка по ипотеке». Рефинансирование — вне набора (H-ортог).
- **L3 — B2B, 3 фразы, только 7 ФО:** «спецтехника купить», «аренда
  спецтехники», «экскаватор купить» (corr +0.51 lag0 с ИКВ, фед.).
- **Не включать:** «стройка», «строительство», «тендер на строительство»
  (+0.13), «смета на строительство».

## Технические параметры

- **Клиент:** scripts/wordstat_api.py (regions=subject_id; лимит 100 зап/час).
  Subject id: data/wordstat_subject_ids.csv (94 субъекта + ФО).
- **Частота:** недельная (PERIOD_WEEKLY); date_to = воскресенье (иначе HTTP 400);
  нулевые фразы → пустой list (подмена на живые фразы, известный питфолл).
- **Глубина:** с 2017-01 (L3 с 2019); хранить count + share (доля региона в
  РФ-объёме по фразе).
- **Объём:** ~950 рядов «регион × фраза» ≈ 0,3–0,5 млн точек. Лимит API:
  батчами, приоритет L1 → L2 → L3; чекпоинты после каждой фразы (idempotent).

## Приёмка

1. Покрытие: 94 субъекта × 8 фраз (L1) без пропусков; нулевых рядов <10%.
2. Кросс-чек: федеральный ряд «ипотека» совпадает с уже собранным (wordstat_*)
   с 2018 на >=95% недель (n>=12 — правило хеш-сверки).
3. Заливка в v2: домен search_leads, метрики ws_spatial_<slug> (parent: ws_phrases),
   region_id по v2.region; run_id-версионность; композит L1 = доля субъекта.
4. Тест Г-поиск: corr(comp, cbr_izhk_count_m) по 5-6 крупным регионам
   (Московская, Краснодарский, Татарстан, Свердловская, Белгородская, СПб),
   лид 0-1 мес; ≥ федерального бенчмарка.

## Не-цели

- Не собирать фразы вне 13; не менять федеральный композит S2–S5.
- Не тратить квоту API на отладку: пилот 1 фраза × 5 регионов × 4 недели.

# Очередь задач агента — реестр

Единственный источник правды по очереди. Обновлено 17.10.2026.

**Правило классов.** Класс **А** — обратимая техническая работа: есть точка
возврата (дамп в `attic/`, пометка статуса вместо удаления, git-коммит), эффект
не выходит за пределы репозитория, критерий приёмки выражается числом. Такие
задачи агент исполняет сам. Класс **Б** — меняет смысл ряда или выходит наружу:
нужно решение владельца. Класс **В** — заблокировано внешне (нет сырья),
ждёт не решения, а данных.

**Как читать.** Берём первую незакрытую строку класса А. Строка закрывается
только вместе с критерием приёмки, напечатанным числом, и записью в `log-tech.md`.
Вопросы класса Б всплывают в отчёте, когда до них доходит очередь, а не фоном.

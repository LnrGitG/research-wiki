# Источники данных для оценки СФП строительства и таблиц затраты-выпуск

> **Цель:** систематизация доступных источников данных для построения рядов совокупной факторной производительности (СФП) жилищного строительства и декомпозиции его вклада в экономический рост России.

---

## 1. Russia KLEMS — отраслевые ряды СФП для РФ

**Главная база для отраслевого growth accounting в России.** Используется ЦБ РФ (Вихарев и др., 2026) для декомпозиции ВДС на капитал, труд и СФП.

| Параметр | Значение |
|----------|---------|
| Период | 1995–2019 |
| Отраслей | 34 (ОКВЭД), включая «Строительство» (F) |
| Ряды | ВДС, капитал (поток услуг), труд (человеко-часы), СФП (остаток Солоу) |
| Методология | Совместима с EU KLEMS (O'Mahony & Timmer, 2009) |
| Доступ | Бесплатно |
| Сайт | http://rusklems.io/ |
| Цитата | Voskoboynikov I.B. (2017). Sources of Long Run Economic Growth of the Russian Economy Before and after the Global Financial Crisis. HSE WP BRP 179/EC/2017 |

**Что доступно по строительству:**
- ВДС строительства в постоянных ценах (1995–2019)
- Поток услуг капитала строительства (1995–2019)
- Человеко-часы в строительстве (1995–2019)
- СФП строительства — остаток Солоу (1995–2019)
- Промежуточное потребление: E (энергия), M (материалы), S (услуги)

**Ограничение:** последний релиз — 2019 г. (данные до 2019). Для 2020–2025 — достраивать из Росстат.

## 8. Стратегия построения рядов СФП строительства

### Этап 1: База (1995–2019) — Russia KLEMS
Использовать готовые отраслевые ряды СФП строительства как базу. Методология совместима с EU KLEMS.

### Этап 2: Достройка (2020–2025) — Росстат
- ВДС: квартальный ВВП по видам деятельности
- Капитал: PIM на основе П-2, с начальным значением из Russia KLEMS
- Труд: ВОРС (занятость, человеко-часы)
- Промежуточное потребление: SUT (если доступны) или интерполяция структуры затрат из 2021

### Этап 3: Межотраслевые связи — таблицы затраты-выпуск
Использовать симметричные таблицы (2011, 2016, 2021) для:
- Оценки αK (доля капитала) для строительства
- Структуры промежуточного потребления (цемент, сталь, труд, энергия)
- Вклада строительства в СФП других отраслей (через капитальное строительство как input)

### Этап 4 (опционально): Микроуровень — СПАРК/ЕИСЖС
Оценка СФП на уровне девелоперов:
- Production function estimation: Ackerberg-Caves-Frazer (2015), Levinsohn-Petrin (2003)
- Агрегация до отраслевой СФП
- Сравнение с макро-оценкой из Этапов 1–2

### Этап 5: Международное сопоставление
Сравнить СФП строительства РФ с:
- EU KLEMS (Европа, США, Япония) — Abdel-Wahab & Vogl (2011)
- WIOD (международные цепочки добавленной стоимости)
- Китай (Glaeser et al., 2017)

# Разбор публичного прогноза ВТБ (29.09.2026) и фиксация сущностей в БД v2

Источник: https://www.banki.ru/news/lenta/?id=11027698 — «В ВТБ
спрогнозировали решения ЦБ по ключевой ставке в октябре и до конца
года» (автор Мария Королева, Банки.ру, 29.09.2026).
Метка: **«Независимый расчёт, не связанный с Банком России»**.

## Факты из статьи

Спикер: Дмитрий Пьянов, первый заместитель президента — председателя
правления ВТБ.

1. Наиболее вероятный сценарий: ставка **не меняется на заседании
   23.10.2026** (вероятность по его личной оценке «40 на 60»), снижение
   на **−0,25 п.п. на декабрьском заседании (18.12.2026)** — «новогодний
   подарок».
2. Решения ЦБ зависят от (а) параметров нового трёхлетнего бюджета и
   (б) динамики базовой инфляции.
3. Структурный первичный дефицит по новому бюджетному правилу:
   **0,6% ВВП в 2027 и 0,2% ВВП в 2028** против ранее заложенных ЦБ
   **1% и 0,5%** — позитивный сигнал, но оговорка: Банк России может
   консервативнее Минфина оценить ненефтегазовые поступления, и тогда
   позитив может не сработать для возобновления смягчения в октябре.
4. Трёхмесячная скользящая средняя инфляции по базовым компонентам
   приблизится к **4% к декабрьскому**, но не к октябрьскому заседанию.
5. Контекст: сентябрьское заседание (11.09.2026) сохранило ставку 14%
   (meeting 104 в БД).

Решения моделирования: сценарий помечен `vtb_external` — внешние
прогнозы банков хранятся отдельно от консенсус-сценария base; событийные
series_code (key_rate_oct_action / key_rate_dec_action в bp_change)
фиксируют точечное решение по каждому заседанию; cpi_core_3m_sma —
новый тип ряда (3-мес СМА базовой инфляции), при регулярном разборе
внешних прогнозов вынести справочник series_code в meta-таблицу.

## Сопоставление с моделью ДДКП (анализ)

Модель: RS = 0.75·RS{−1} + 0.25·(RS_NEUTRAL + 1.5·E3_PIE4_DEV + 0.5·Y_GAP);
текущая ставка 14,00% (11.09.2026), инфляция текущая 11,6% (июль),
базовая 7,0%. Сценарий ВТБ (hold 23.10, −25 б.п. в декабре) консистентен
с моделью при медленном схождении E3_PIE4_DEV (отклонение инфляции от
цели на 3-летнем горизонте) к цели и около-нулевом Y_GAP: октябрьское
решение — hold, декабрьское — умеренное смягжение после подтверждения
тренда СМА базовой инфляции к 4%. Бюджетный канал (СПД 0,6/0,2 вместо
1/0,5) в модели отражается через инфляционный спрос — понижение СПД
ослабляет cost-push (давление издержек) и поддерживает декабрьский cut.

## Проверяемые гипотезы

- Г1: если 3-мес СМА базовой инфляции к 23.10.2026 остаётся выше 4% —
  решение 23.10 — hold (согласуется с ВТБ).
- Г2: если фактический СПД-2027 в финальном бюджете ≤0,2–0,6% ВВП и ЦБ
  разделяет оценку доходов Минфина — декабрьский cut 25 б.п. вероятен.
- Г3 (региональная): расхождение оценки ненефтегазовых доходов
  ВТБ/ЦБ коррелирует с региональной динамикой налоговых отчислений
  (ФНС-инжест: 436 882 кода, 110 отраслей) — данные в БД, связь
  строится через ОКВЭД-срез.
- Календарная проверка после 18.12.2026: dkp.v_forecast_error
  посчитает ошибку против фактического решения автоматически.

## Хвосты реализации

- RETURNING из db_tunnel.execute возвращает скаляр-int (не кортеж) —
  учтено в скрипте.
- v2.load_run: при создании run потребовался dataset_id NOT NULL →
  dataset 10 (dkp-forecast); случайно создали двойной run (59/60),
  дубль 60 удалён, все forecast перепривязаны на run_id=59.
- kb.document и core.document не связаны FK (две независимые схемы);
  kb-вариант нужен для векторного поиска, core — канон для dkp-statement.

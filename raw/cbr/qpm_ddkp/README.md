

## КПМ ДДКП (Банк России) — программный код с рынком труда (архив от пользователя, 29.08.2026)

**Источник**: Банк России, Департамент денежно-кредитной политики. Код к статье «Квартальная прогнозная модель России с рынком труда» + инструкция пользователя (4 стр., PDF+txt). Расположение: `raw/cbr/qpm_ddkp/` (model/, proc/, results/, instrukciya.txt).

### Состав
- `model/qpm_model.mod` (266 ур-й) — ядро: разрывы (gap ×100 упоминаний), инфляция, ТЕД, курс, премия за риск, нефть, экспорт/импорт, зарплаты
- `model/qpm_term_structure.mod` (107) — термин-структура ставок
- `model/qpm_fiscal_block.mod` (158) — бюджетный блок
- `model/external_model.mod` (145) — внешний блок (мировая экономика)
- `model/parameters_main.mod` (219) — калибровка
- `proc/` — steady state (growth rates), импульсные отклики
- `results/irf_*` — 5 наборов IRF в PNG: paper / no_capital_controls / monetary_hard / adaptive_expectations / user_params (по 6 рис.: df_gap, a_d_gap, rs, yf_gap, ltot_gap, wr_gap)

### Статус
- Полный ДСКGE-класс (Dynare .mod, MATLAB) — рабочая модель КСП/ССП ЦБ, « regularly используется для расчёта сценариев среднесрочного прогноза»
- Housing-блока НЕТ (grep по housing/жильё = 0 упоминаний). Ближайшие каналы: инвестиции/ВВП-разрыв, ставка (term structure), зарплаты (рынок труда — это версия «с рынком труда»)
- Лимит: Dynare/MATLAB не в стеке VPS; запуск существенный. Для Octave конверсия возможна, но дороже пользы сейчас

### Значение для FAVAR-MIDAS
- Это микромодель-«поставщик» механизмов propagation, не источник данных; для ours MIDAS — только калибровка сравнения (насколько наша сокращённая модель воспроизводит их IRF по ставке/ВВП)
- Рынок труда (wage, wr_gap) — кандидат в FAVAR-факторы (у нас вTIMER есть занятость стройки)
- Если когда-то понадобится оценить реакцию жилья на ДКП в общей равновесной рамке — это код готов к загрузке в Octave (dynare) на Mac Studio (M-серия потянет quicker Байес)


## Дополнение 29.08.2026: уравнения инвестиций и отраслей ВВП (разбор кода)

ГЛАВНОЕ: отдельных уравнений инвестиций (I) и отраслевого разреза ВВП в модели НЕТ. Спрос свёрнут, капитал входит только как услуги.

### 1. Производственный блок (qpm_model.mod, ~строки 306-345)
Формулировка в разрывах (gap = отклонение от равновесного пути):
- Y = (1-w_x)*YD + w_x*X  (внутренний выпуск + экспорт)
- YD_GAP = A_D_GAP + (1-alpha_m)*(alpha_d*L_D_GAP + (1-alpha_d)*CU_D_GAP) + alpha_m*M_Y_GAP
  производственная функция: TFP + труд + капитальные услуги CU_D + импортные промежуточные товары
- Kapitalnye uslugi (не фонд!): CU_D_GAP = L_D_GAP + sigk_d*((PW_GAP - RK_D_GAP) + SHCK_AC_K_GAP - AC_K_GAP); AC_K_GAP = chi_k*d(CU_D - YD); CU_D_GAP = eta_nu*RK_D_GAP
- Отдельный двухфакторный блок для ненефтяного экспорта (X_NO: sigk_x, chi_k_x)

### 2. Свернутый внутренний спрос (~строки 406-419)
- Y = w_d*D + w_x*X - w_m*M (ВВП по использованию)
- D_GAP = w_df*DF_GAP + (1-w_df)*M_Y_GAP
- DF_GAP = d_lead*E1_DF_GAP + d_lag*DF_GAP{-1} - d_rr*RRA_GAP + d_wr*(WR_GAP + N_GAP + d_ub*U_GAP) + d_tot*LTOT_GAP + FISC_STIM + SHCK_DF_GAP
  кривая Эйлера конечного спроса: реальная ставка + доход (зарплата/занятость/безработица) + условия торговли + фискальный импульс.
  НЕТ разложения DF = C + I + G: потребление и инвестиции агрегированы в одной межвременной кривой.

### 3. Фискальный блок (qpm_fiscal_block.mod)
- Правила расходов фед/региональных (EXPP_FED_ARAT, phi_cycl_fed, phi_debt_dev), фискальный импульс входит в DF_GAP как FISC_STIM. Госпроекты/гос.инвестиции отдельно не выделены.

### 4. Отраслевой разрез - только 2 сектора
- X = w_x_no*X_NO + w_x_o*X_O (нефтяной/ненефтяной экспорт) с собственными факторами (N_X, CU_X)
- M = M_Y + M_D (промежуточный/конечный импорт)
- Межотраслевой структуры нет: строительство и недвижимость как сектора в модели отсутствуют.

### Следствия
1. КПМ ДДКП нельзя использовать для анализа инвестиций в жильё без доработки (добавить I_RES в DF разложение + user-cost/q-канал).
2. Для FAVAR-MIDAS отраслевые ряды (стройка/ввод/материалы) остаются в самостоятельном reduced-form слое; КПМ дает макроядро ставка -> спрос -> зарплата.
3. Возможная модификация для жилья: расщепить DF_GAP на C_GAP + I_RES_GAP с отдельной эластичностью по ставке (ипотечный канал), сохранив шок RES_DF_GAP для прежней идентификации.

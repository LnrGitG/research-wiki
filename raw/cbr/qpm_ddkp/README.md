

## КПМ ДДКП (Банк России) — программный код с рынком труда (архив от пользователя, 29.08.2026)

**Источник**: Банк России, Департамент денежно-кредитной политики. Код к статье «Квартальная прогнозная модель России с рынком труда» + инструкция пользователя (4 стр., PDF+txt). Расположение: `raw/cbr/qpm_ddkp/` (model/, proc/, results/, instrukciya.txt).

### Состав
- `model/qpm_model.mod` (266 ур-й) — ядро: разрывы (gap ×100 упоминаний), инфляция, ТЕД, курс, премия за риск, нефть, экспорт/импорт, зарплаты
- `model/qpm_term_structure.mod` (107) — термин-структура ставок
- `model/qpm_fiscal_block.mod` (158) — бюджетный блок
- `model/external_model.mod` (145) — внешний блок (мировая экономика)
- `model/parameters_main.mod` (219) — калибровка
- `proc/` — steady state (growth rates), импульсные отклики
- `results/irf_*` — 5 наборов IRF в PNG: paper / no_capital_controls / monetary_hard / adaptive_expectations / user_params (по 6 рис.: df_gap, a_d_gap, rs, yf_gap, ltot_gap, wr_gap)

### Статус
- Полный ДСКGE-класс (Dynare .mod, MATLAB) — рабочая модель КСП/ССП ЦБ, « regularly используется для расчёта сценариев среднесрочного прогноза»
- Housing-блока НЕТ (grep по housing/жильё = 0 упоминаний). Ближайшие каналы: инвестиции/ВВП-разрыв, ставка (term structure), зарплаты (рынок труда — это версия «с рынком труда»)
- Лимит: Dynare/MATLAB не в стеке VPS; запуск существенный. Для Octave конверсия возможна, но дороже пользы сейчас

### Значение для FAVAR-MIDAS
- Это микромодель-«поставщик» механизмов propagation, не источник данных; для ours MIDAS — только калибровка сравнения (насколько наша сокращённая модель воспроизводит их IRF по ставке/ВВП)
- Рынок труда (wage, wr_gap) — кандидат в FAVAR-факторы (у нас вTIMER есть занятость стройки)
- Если когда-то понадобится оценить реакцию жилья на ДКП в общей равновесной рамке — это код готов к загрузке в Octave (dynare) на Mac Studio (M-серия потянет quicker Байес)

# Ручной экспорт ЕМИСС: месячные ряды ввода мощностей (инструкция)

ЕМИСС (fedstat.ru) заблокирован для VPS-IP → выгрузки делаются из браузера с домашнего/резидентного IP, файлы присылаются в чат для разбора.

## Главная карточка-показатель (одна на всё)

**57605 — «Введено в действие мощностей и объектов» (оперативная, с 2017 г.)**
https://www.fedstat.ru/indicator/57605
Это тот же массив, что и оперативные xlsx Rosstata (vv-mosh-oper): номенклатура мощностей × периоды (месяц/накопительно с начала года) × регионы. Одна выгрузка с фильтром «Российская Федерация» + все периоды закрывает месячный ряд по всем позициям сразу.

**Как выгрузить из неё месячный ряд:**
1. Открыть ссылку, дождаться таблицы (новая версия ЕМИСС 2.0)
2. В панели фильтров: «Период» = все месяцы (или январь–декабрь по каждому году), «Год» = 2017–2026, «Номенклатура мощностей» = отметить нужные: цемент, электростанции (турбинные, ГЭС, ВИЭ, дизельные), ЛЭП, зернохранилища/зерносушилки, теплицы, скважины, дороги, кирпич (если строка есть), «Помещения для КРС/свиней/птицы»
3. «ОКАТО» = Российская Федерация
4. Кнопка экспорта (xlsx, дискета/стрелка) — сохранить
5. Файл прислать в этот чат — далее автоматом: разбор в `rosreestr_deals.db` (таблица вида `emiss_capacity_monthly`) + data-summary + catalog + commit

## Альтернативные карточки (если 57605 неудобна)

- **34460**, **57726**, **57811** — родственные разрезы того же показателя (ответственные: Слюсарева Т.В., Шевченко А.Н. — Росстат, отдел ввода мощностей). 57811 и 57726, судя по сниппетам, — квартальные срезы «ввод в действие производственных мощностей и объектов капитального строительства»
- Месячные ряды **производства** (не мощности!) стройматериалов уже есть у нас в базе из сборников Росстата (materials_monthly, 967 строк) — из ЕМИСС их брать не нужно

## Что я сделаю после получения файла

1. Разбор xlsx → emiss_capacity_monthly (section, unit, year, month, value, new/recon если есть)
2. Проверка на стыке с квартальными рядами vv-mosh-oper (сверка H1-2026: цемент 650 тыс. т)
3. data-summary (prod_capacity_monthly) + catalog + commit
4. При желании — вкладка на GitHub Pages

Ограничение: если в карточке 57605 периодичность только квартальная (не исключено — номенклатура мощностей традиционно квартально-накопительная), месячности всё равно не будет ни в ЕМИСС, ни где-либо ещё, и останется наш текущий квартальный pipeline. Это покажет сама выгрузка.



## Проверка ЕМИСС (fedstat.ru) — 29.08.2026

Прямой доступ с VPS **заблокирован** (HTTP 403 на все пути):
- GET страницы индикатора (/indicator/<id>) → 403 (браузерные UA, Googlebot-скрытие не помогает)
- POST endpoint официального неофициального API fedstatAPIr (`/indicator/data.do?format=excel|sdmx`) → 403
- Пробные SPA-эндоинты новой версии → 403
- Блок IP-уровня VPS (84.42.88.209) — вероятно Антибаррикада/Cloudflare-стайл; Rosstat основной (rosstat.gov.ru) отвечает, только fedstat в отдельной защищённой зоне
- Firecrawl/Gateway также отдаёт Forbidden (гео-блок для RU-источников)

Косвенные каналы:
1. statkit.ru / alexstat.ru — сторонние платные API-надстройки к ЕМИСС (alexstat DNS не резолвится с этого VPS, statkit — по подписке, токен платный)
2. data.apicrafter.ru — метаданные показателей (6956 показателей) открыты, но витрины данных закрыты «Экспорт: нет»
3. fedstatAPIr (R) остаётся рабочим при запуске с RU-резидентного IP (у пользователя домашний, вероятно, пройдёт)

Вывод: месячные ряды ввода мощностей из ЕМИСС с текущего VPS недоступны. Альтернативы:
- (а) скачать вручную из браузера ЕМИСС (выгруженные xlsx прислать в чат — обработаю по pipeline);
- (б) крон на домашней машине/RU-IP (у Mac Studio после покупки — будет резидентный IP);
- (в) продолжать квартальный сбор из vv-mosh-oper (+ ежегодник для истории) — уже в базе (rosstat_production_capacity_vvod).
